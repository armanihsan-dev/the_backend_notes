What is the http module in Node.js?

Node.js has a built-in http module that allows you to create servers and handle HTTP requests and responses. It follows the event-driven and stream-based architecture of Node.js.

It can be used to:

  • Serve web pages
  • Send JSON APIs
  • Stream video/audio files
  • Handle REST APIs

2. Syntax for Creating a Basic HTTP Server

import http from "node:http";
// Create server
const server = http.createServer((req, res) => {
  // req = IncomingMessage (Readable stream)
  // res = ServerResponse (Writable stream)

  res.writeHead(200, { "Content-Type": "text/plain" });
  res.write("Hello, this is my first Node.js server!");
  res.end();
});
// Start server
server.listen(3000, () => {
  console.log("Server is running at http://localhost:3000");
});

Explanation:

  • http.createServer()
    • Creates an HTTP server.
    • Takes a callback function (req, res) that runs every time a client makes a request.
  • req → Incoming Request Object
    • Represents the client’s HTTP request.
    • It’s a Readable Stream (data flows from client → server).
  • res → Server Response Object
    • Represents what the server sends back.
    • It’s a Writable Stream (data flows from server → client).
  • server.listen(port, callback)
    • Starts the server on the given port.

3. Requests and Responses as Streams

Why Streams?

  • Requests (req) can be very large (like file uploads).
  • Responses (res) can also be large (like sending a video).
  • Instead of loading the whole thing into memory, Node.js uses streams to process data piece by piece.

👉 That’s why req is Readable Stream and res is Writable Stream.

4. Important Events

Both the server and the request/response streams emit events.

Server Events

server.on("request", (req, res) => {
  console.log("New request received");
});

server.on("close", () => {
  console.log("Server closed");
});

server.on("error", (err) => {
  console.error("Server error:", err);
});
  • request → Triggered whenever a client makes an HTTP request.
  • close → Triggered when the server shuts down.
  • error → Triggered if something goes wrong.

Request (req) Events

req.on("data", (chunk) => {
  console.log("Got data:", chunk.toString());
});

req.on("end", () => {
  console.log("Request ended");
});
  • data → Fired when a chunk of request body arrives (important for POST requests).
  • end → Fired when the request body is completely received.

Response (res) Methods & Events

res.on("finish", () => {
  console.log("Response fully sent to client");
});
  • finish → Fired when the response has been completely sent.
  • res.write(chunk) → Sends a piece of data.
  • res.end([data]) → Ends the response (optionally sending last piece).

5. Important Properties of the req Object

req (IncomingMessage) has many useful properties:

Property Description Example
req.method HTTP method used "GET", "POST"
req.url The URL/path requested "/about?name=Arman"
req.headers Request headers { "user-agent": "...", "content-type": "application/json" }
req.httpVersion HTTP version used "1.1"
req.socket TCP socket object Low-level info about connection

👉 Example:

const server = http.createServer((req, res) => {
  console.log("Method:", req.method);
  console.log("URL:", req.url);
  console.log("Headers:", req.headers);

  res.writeHead(200, { "Content-Type": "application/json" });
  res.end(JSON.stringify({ "message": "Check console for request details" }));
});

6. Full Practical Example

Handling GET and POST requests

import http from "node:http";
const server = http.createServer((req, res) => {
  if (req.method === "GET" && req.url === "/") {
    res.writeHead(200, { "Content-Type": "text/html" });
    res.end("<h1>Welcome to Home Page</h1>");
  }

  else if (req.method === "GET" && req.url === "/about") {
    res.writeHead(200, { "Content-Type": "text/plain" });
    res.end("About Page");
  }

  else if (req.method === "POST" && req.url === "/data") {
    let body = "";
    req.on("data", (chunk) => {
      body += chunk.toString();
    });

    req.on("end", () => {
      res.writeHead(200, { "Content-Type": "application/json" });
      res.end(JSON.stringify({ "received": body }));
    });
  }

  else {
    res.writeHead(404, { "Content-Type": "text/plain" });
    res.end("Not Found");
  }
});

server.listen(3000, () => {
  console.log("Server running at http://localhost:3000");
});

Try it:

  • Open browser → http://localhost:3000
  • Visit /about
  • Send POST request with Postman or curl:
curl -X POST http://localhost:3000/data -d "hello world"
