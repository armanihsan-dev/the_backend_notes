Node.js Networking Notes 🌐

Core Networking Capabilities of Node.js

1. TCP (Transmission Control Protocol)

Node.js uses the built-in net module to create raw TCP servers and clients. It's ideal for building custom protocols, chat servers, or multiplayer games. 

const net = require('net');
const server = net.createServer((socket) => {
  console.log('Client connected');
  socket.write('Hello from server!\n');

  socket.on('data', (data) => {
    console.log(`Received: ${data}`);
  });
});

server.listen(3000, () => {
  console.log('TCP server running on port 3000');
});

2. UDP (User Datagram Protocol)

The dgram module in Node.js handles UDP sockets. This is useful for applications that prioritize speed over reliability, such as DNS servers, streaming, real-time gaming, and IoT. 

const dgram = require('dgram');
const server = dgram.createSocket('udp4');

server.on('message', (msg, rinfo) => {
  console.log(`Message: ${msg} from ${rinfo.address}:${rinfo.port}`);
});

server.bind(41234);

3. HTTP / HTTPS

Node.js provides the http and https modules for creating web servers. The https module is used for secure connections and requires TLS/SSL certificates. 

const http = require('http');
const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Hello, HTTP!\n');
});

server.listen(8080, () => {
  console.log('HTTP server listening on port 8080');
});

4. TLS/SSL (Encryption & Secure Sockets)

The tls module allows Node.js to manage secure, encrypted TCP connections, forming the basis for protocols like HTTPS.

5. WebSockets

Node.js supports WebSockets, often with libraries like ws or frameworks like Socket.IO, for building real-time applications like chat and notifications. 

const WebSocket = require('ws');
const server = new WebSocket.Server({ port: 8080 });

server.on('connection', (ws) => {
  ws.send('Welcome!');
  ws.on('message', (message) => {
    console.log(`Received: ${message}`);
  });
});

6. DNS (Domain Name System)

The built-in dns module helps in resolving domain names, which is useful for creating networking tools or proxies.

7. HTTP/2 Support

Node.js includes the http2 module for building high-performance applications with features like multiplexing and header compression.

8. Clustering & Load Balancing

The cluster module allows Node.js to spawn multiple processes and utilize multiple CPU cores for better performance and scaling.

9. Proxy & Reverse Proxy

Node.js can be used to build proxy servers that forward requests and handle load balancing, often with libraries like http-proxy.

10. Low-Level Networking

Node.js's event-driven architecture makes it suitable for implementing custom protocols, VPNs, and peer-to-peer applications.

Why Node.js is Good for Networking 🚀

  • Non-blocking I/O: It can handle thousands of concurrent connections efficiently.
  • Event-driven: Perfect for real-time applications requiring instant updates.
  • Cross-platform: Works seamlessly on Linux, Windows, and macOS.
  • Huge Ecosystem: A vast collection of npm libraries simplifies networking tasks.
