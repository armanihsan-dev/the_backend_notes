Node.js HTTP Client

In Node.js, the built-in http module allows you to create an HTTP client to make requests to web servers. This is fundamental for applications that need to interact with APIs, fetch data, or communicate with other services.

Creating an HTTP Client with http.request()

The primary method for creating a client request is http.request(). This method returns a ClientRequest object, which is a writable stream. You write the request body (if any) to this stream and then call request.end() to signal that the request is complete and ready to be sent.

Syntax

http.request(options, callback)

options: An object containing request details like:

  • hostname: The server to make the request to (e.g., 'www.google.com').
  • port: The port of the server (default is 80 for HTTP).
  • path: The request path (e.g., '/api/data').
  • method: The HTTP request method (e.g., 'GET', 'POST').
  • headers: An object for request headers.

callback: A function that is executed once the response from the server is received. It takes a single argument, the response object.

The response Object as a Readable Stream

The response object passed to the callback is a readable stream. This means you don't receive the entire response body all at once. Instead, you listen for data events and process the data in chunks. This is highly efficient for large data transfers, as it prevents memory overload.

The response object inherits from stream.Readable, so it emits the following important events:

  • data: Fired when a chunk of data is received. This is where you collect the response body.
  • end: Fired when the entire response body has been received. This is the signal that the request is complete, and you can now process the full response.
  • error: Fired if there's an error with the request or response.

Practical Example: Client-Server Communication

Here's a complete, practical example demonstrating communication between a Node.js HTTP server and a client.

Step 1: Create the Server (server.js)

This server will listen for a GET request on /data and send back a JSON response. It will also listen for a POST request on /submit and echo the received data. 

// server.js
import http from 'node:http';

const server = http.createServer((req, res) => {
    if (req.url === '/data' && req.method === 'GET') {
        // Handle GET request
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ message: 'Hello from the server!', status: 'success' }));
    } else if (req.url === '/submit' && req.method === 'POST') {
        // Handle POST request
        let body = '';
        req.on('data', chunk => {
            body += chunk.toString();
        });
        req.on('end', () => {
            console.log('Received POST data:', body);
            res.writeHead(200, { 'Content-Type': 'application/json' });
            res.end(JSON.stringify({ received: body, status: 'acknowledged' }));
        });
    } else {
        // Handle other requests (e.g., 404 Not Found)
        res.writeHead(404, { 'Content-Type': 'text/plain' });
        res.end('Not Found');
    }
});

const PORT = 3000;
server.listen(PORT, () => {
    console.log(`Server listening on http://localhost:${PORT}`);
});

Step 2: Create the Client (client.js)

This client will make two requests to the server: a GET request to /data and a POST request to /submit. 

// client.js
import http from 'node:http';

const host = 'localhost';
const port = 3000;

// Function to handle the GET request
function makeGetRequest() {
    const getOptions = {
        hostname: host,
        port: port,
        path: '/data',
        method: 'GET',
    };

    const req = http.request(getOptions, (res) => {
        let data = '';

        // The response is a readable stream
        res.on('data', (chunk) => {
            data += chunk;
        });

        res.on('end', () => {
            console.log('GET Response Status:', res.statusCode);
            console.log('GET Response Headers:', res.headers);
            console.log('GET Response Body:', data);
        });

        res.on('error', (err) => {
            console.error('Error during GET request:', err.message);
        });
    });

    // End the request to send it
    req.end();
}

// Function to handle the POST request
function makePostRequest() {
    const postData = JSON.stringify({ name: 'Node.js', type: 'Client' });

    const postOptions = {
        hostname: host,
        port: port,
        path: '/submit',
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'Content-Length': Buffer.byteLength(postData),
        },
    };

    const req = http.request(postOptions, (res) => {
        let data = '';

        res.on('data', (chunk) => {
            data += chunk;
        });

        res.on('end', () => {
            console.log('\nPOST Response Status:', res.statusCode);
            console.log('POST Response Headers:', res.headers);
            console.log('POST Response Body:', data);
        });

        res.on('error', (err) => {
            console.error('Error during POST request:', err.message);
        });
    });

    // Write the request body and end the request
    req.write(postData);
    req.end();
}

// Run the requests
makeGetRequest();
makePostRequest();

Step 3: Run the code

Open your terminal.

Start the server: node server.js

In a new terminal window, run the client: node client.js

You will see the output in the client terminal first, followed by the server's console log, showing the received POST data.

Important Events

Event Fired on When it fires
response ClientRequest object (from http.request()) After receiving the full response headers from the server.
data response object When a chunk of the response body is available.
end response object When the entire response body has been consumed.
error Both ClientRequest and response objects If an error occurs (e.g., network failure, server not found).
timeout Both ClientRequest and response objects When the request or response times out.
close Both ClientRequest and response objects When the underlying connection is terminated.

Summary

The http module in Node.js provides a low-level API for creating clients. It's built on streams, allowing for efficient, non-blocking I/O. The http.request() method initiates the connection, and the ClientRequest object is a writable stream for the request body. The server's response is a readable stream, which you process by listening for data and end events to reconstruct the full response body. This streaming approach is a cornerstone of Node.js's performance.
