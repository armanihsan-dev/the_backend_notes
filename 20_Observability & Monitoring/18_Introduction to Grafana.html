Grafana: Complete Simple Introduction

Part 1: What is Grafana in One Sentence?

Grafana is a tool that turns your data into beautiful graphs and dashboards.

Part 2: The Problem Grafana Solves

Without Grafana

You have Prometheus with lots of numbers:

http_requests_total = 1,234
cpu_usage = 45.6%
error_rate = 2.3%
p99_latency = 0.456s

Question: Is my server healthy?
Answer: You have to look at 4 different numbers and guess.

You see THIS instead:

Part 4: How Grafana Works

┌─────────────────────────────────────────────────────────────┐
│                    HOW GRAFANA WORKS                         │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  Prometheus ──► Grafana ──► You see beautiful graphs        │
│  (has data)     (reads it)    (on dashboard)                │
│                                                              │
└─────────────────────────────────────────────────────────────┘

Simple flow:

  • Prometheus collects metrics from your server
  • Grafana asks Prometheus for those metrics
  • Grafana draws graphs on a dashboard
  • You look at the dashboard and understand instantly

Part 5: Key Use Cases for Grafana

Use Case 1: Server Monitoring Dashboard

See at a glance:

  • CPU, memory, disk usage
  • Request rate and errors
  • Response times
  • All on ONE screen

Use Case 2: Alert Visualization

See when things went wrong:

  • Graphs showing exactly when the outage happened
  • Compare before/after a deployment

Use Case 3: Business Metrics

Track business data:

  • Number of users signing up per day
  • Orders per hour
  • Revenue over time

Use Case 4: Infrastructure Monitoring

Watch your entire system:

  • All servers in one dashboard
  • Database performance
  • Network traffic

Part 6: Grafana vs Prometheus

Prometheus Grafana
Stores the data Shows the data
Answers queries Creates graphs
Has numbers Has pictures
Good for alerting Good for dashboards
Core Difference

Think of it as: Prometheus is the database, Grafana is the user interface.

Part 9: Getting Started with Grafana

Step 1: Install Grafana

# On Mac
brew install grafana

# On Linux
sudo apt-get install grafana

# Or download from https://grafana.com

Step 2: Start Grafana

grafana-server

or if you download as msi then it will be already running as a service in the backround

you can test the checksum to check if file is not interrupt in the middle 

import crypto from 'node:crypto';
import fs from 'node:fs';

const hash = crypto.createHash('SHA-256');
const stream = fs.createReadStream("C:\\Users\\Arman ihsan\\Downloads\\grafanassc.msi");

stream.on('data', chunk => hash.update(chunk));
stream.on('end', () => console.log(hash.digest('hex')));

Step 3: Open Grafana

  • http://localhost:3000
  • Login: admin / admin

Step 4: Add Prometheus as a Data Source

  • Click "Configuration" (gear icon)
  • Click "Data Sources"
  • Click "Add data source"
  • Choose "Prometheus"
  • URL: http://localhost:9090
  • Click "Save & Test"

Step 5: Create Your First Dashboard

  • Click "+" → "Dashboard"
  • Click "Add visualization"
  • Select your Prometheus data source
  • Enter a query: rate(http_requests_total[1m])
  • You see a graph!
