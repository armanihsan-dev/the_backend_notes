What are Exemplars? Exemplars are the missing link between your aggregated metrics and the individual traces that caused them . Think of them as "bookmarks" in your metric data that point directly to actual traces . 📌 The Core Concept Metrics give you the "what" (aggregated data, like average latency). Traces give you the "how" (detailed request path). Exemplars tell you "which specific request caused that metric spike" . Signal Question It Answers Granularity Metrics "Something is wrong" Aggregate view Traces "Where exactly is the problem?" Individual request Exemplars "Which trace caused that metric spike?" The link between them 🔗 How Exemplars Work When a metric measurement is taken (e.g., an HTTP request duration is recorded) and there is an active trace for that operation, the trace context (trace_id, span_id) is attached as an exemplar to that metric data point . Faster Debugging Instead of asking "Why is my latency high?", you can: Look at the metric spike Click on the exemplar (shown as a star ⭐ or diamond ◆ in Grafana) Jump directly to the actual trace that caused it See exactly what went wrong 2. Bridging Metrics and Traces text Traditional Approach: 1. See metric spike at 2:00 PM 2. Search logs for that time 3. Guess which trace is relevant 4. Open several traces hoping to find the right one ⏱️ Time: 15-30 minutes With Exemplars: 1. See metric spike at 2:00 PM 2. Click on the exemplar data point 3. Open the exact trace associated with that measurement ⏱️ Time: 30 seconds 3. Root Cause Analysis Exemplars help identify problematic requests by isolating them from aggregated metrics . For example, a histogram showing 500ms average latency may hide the fact that some requests took 5 seconds. Exemplars let you pinpoint and examine those high-latency outliers. ⚙️ Implementation: Your Node.js/Express App Step 1: In Your OpenTelemetry Setup javascript // tracing.js const { NodeSDK } = require('@opentelemetry/sdk-node'); const { getNodeAutoInstrumentations } = require('@opentelemetry/auto-instrumentations-node'); const sdk = new NodeSDK({ instrumentations: getNodeAutoInstrumentations({ '@opentelemetry/instrumentation-http': { enabled: true, // This is key: enable exemplars applyCustomAttributesOnSpan: (span, req, res) => { // Exemplars are automatically attached to metrics // when there's an active span context } } }) }); Step 2: Enable Exemplars in Prometheus yaml # prometheus.yml global: scrape_interval: 15s scrape_configs: - job_name: 'my-app' static_configs: - targets: ['localhost:9464'] # Important: Enable exemplars in scrape config exemplars: enabled: true Step 3: View in Grafana Go to Explore → Select Prometheus data source Query: http_request_duration_seconds_bucket Toggle "Exemplars" ON (star icon ⭐) You'll see stars appear on the metric graph.
