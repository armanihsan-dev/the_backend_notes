SENDING LOGS TO LOKI

A COMPLETE GUIDE TO PUSHING, STREAMING, AND QUERYING LOGS IN LOKI

WHAT IS LOKI?

Loki is a log aggregation system that only indexes labels — not the log content itself. Think of it like a filing cabinet where:

  • Labels = File folder names (fast to find)
  • Log content = Papers inside folders (only read when needed)

LOKI'S DATA COLLECTION: PUSH VS. PULL

Loki uses a PUSH model — it waits for data to be sent to it. It does NOT actively scrape or pull logs automatically.

The Simple Answer

Think of Loki like an API server — it sits and waits for data. You must send logs to it.

Method Does Loki support it? How it works
Push (Send) ✅ Primary method You send logs via HTTP POST requests to Loki's API
Pull (Scrape) ❌ Not directly Loki does NOT read log files itself

How to Get Logs into Loki

Since Loki only accepts pushed data, you send logs directly to Loki's HTTP API:

curl -H "Content-Type: application/json" \
  -X POST "http://localhost:3100/loki/api/v1/push" \
  --data-raw '{"streams": [{ "stream": { "app": "myapp" }, "values": [ [ "1570818238000000000", "log message" ] ] }]}'

PART 1: BASIC CONCEPTS

1.1 What is a Stream?

A stream = A group of logs that share the exact same labels.

Stream = {label1="value1", label2="value2", ...}

Example: All logs from the same service have {app="myapp", env="production"}

1.2 What is a Label?

Labels = Key-value pairs that Loki uses to index and group logs.

Label Meaning Example
app Application name {app="payment-service"}
level Log severity {level="error"}
env Environment {env="production"}
pod Kubernetes pod {pod="api-pod-xyz"}

1.3 The Log Entry Format

{
  "streams": [
    {
      "stream": { LABELS_GO_HERE },
      "values": [
        [ "TIMESTAMP_IN_NANOSECONDS", "LOG_MESSAGE_STRING" ]
      ]
    }
  ]
}

Step 3: Your First Log (Simple)

{
  "streams": [
    {
      "stream": {
        "app": "my-first-app",
        "level": "info"
      },
      "values": [
        ["1777274604038000000", "Hello Loki! This is my first log"]
      ]
    }
  ]
}
What this means
  • "app": "my-first-app" → Label: application name
  • "level": "info" → Label: log severity
  • "1777274604038000000" → Timestamp in nanoseconds
  • "Hello Loki!" → The actual log message

PART 3: HOW LOKI GROUPS LOGS

The Golden Rule: Same Labels = Same Stream

Loki creates ONE stream for logs with identical labels.

Example 1: Two logs, same labels → ONE stream

{
  "streams": [
    {
      "stream": { "app": "myapp", "level": "info" },
      "values": [
        ["1777274604038000000", "Log message 1"],
        ["1777274604039000000", "Log message 2"]
      ]
    }
  ]
}

Result: Both logs go to Stream 1 {app="myapp", level="info"}

Example 2: Different level → TWO streams

{
  "streams": [
    {
      "stream": { "app": "myapp", "level": "info" },
      "values": [["1777274604038000000", "Info log"]]
    },
    {
      "stream": { "app": "myapp", "level": "error" },
      "values": [["1777274604039000000", "Error log"]]
    }
  ]
}
  • Stream 1: {app="myapp", level="info"}
  • Stream 2: {app="myapp", level="error"}

Example 3: Missing a label → DIFFERENT stream

{
  "streams": [
    {
      "stream": { "app": "myapp" },
      "values": [["1777274604038000000", "No level label"]]
    },
    {
      "stream": { "app": "myapp", "level": "info" },
      "values": [["1777274604039000000", "With level label"]]
    }
  ]
}
  • Stream 1: {app="myapp"}
  • Stream 2: {app="myapp", level="info"} ← Different stream!

QUERYING YOUR LOGS

Filter by Service Name

GET http://localhost:3100/loki/api/v1/query_range?query={app="HTTTPie"}

Filter by Range Query (Recommended)

http://localhost:3100/loki/api/v1/query_range?query={label%3D"value"}&limit=10&start=1777271751761000000&end=1777275351757000000
Parameter Value
start Now() − 1 hour in nanoseconds
end Now() in nanoseconds

JS Code to Log the Timestamps

// Current time in nanoseconds
const nowNs = Date.now() * 1_000_000;
console.log(`Now: ${nowNs}`);

// One hour ago in nanoseconds
const oneHourAgoNs = (Date.now() - 3_600_000) * 1_000_000;
console.log(`One hour ago: ${oneHourAgoNs}`);
