WHAT IS AWS LAMBDA?

A serverless computing service that runs your code in response to events and automatically manages the underlying compute resources.

Key Concept

With Lambda, you don't provision or manage servers. You only pay for the compute time you consume — there is no charge when your code is not running.

LAMBDA FUNCTION

A self-contained piece of code (written in Node.js, Python, etc.) that:

  • Performs a specific task
  • Runs in a stateless container
  • Is triggered by events (HTTP requests, file uploads, etc.)
  • Scales automatically based on demand

Important

Lambda's filesystem is read-only except for /tmp. Data in /tmp disappears when the container stops. For production, always use DynamoDB — NO filesystem, NO /tmp.

STEP 1 — CREATE DYNAMODB TABLE

🧱 Setup Instructions

  1. Go to AWS Console → search DynamoDB
  2. Click Create table
  3. Fill in:
    Field Value
    Table name todos-table
    Primary key id → type: String
  4. Keep everything default
  5. Click Create table

🧠 Why is a Primary Key Needed?

DynamoDB is a key-value database. Every item MUST have a unique id.

Example Item:

{
  "id": "123",
  "title": "Learn AWS",
  "completed": false
}

STEP 2 — IAM PERMISSIONS

🪪 Give Lambda Access to DynamoDB

Common Failure Point

Most people fail here. Without proper IAM permissions, Lambda cannot access DynamoDB.

  1. Go to Lambda → your function → Configuration → Permissions
  2. Click the IAM role
  3. Attach policy: AmazonDynamoDBFullAccess
  4. Save

Now Lambda can access the database.

STEP 3 — AWS SDK SETUP

🧰 Install Dependencies

Note

If using Lambda console — SDK is already installed. Only needed for local development. 

npm install @aws-sdk/client-dynamodb
npm install @aws-sdk/lib-dynamodb

Import & Initialize:

import { DynamoDBClient } from "@aws-sdk/client-dynamodb";
import {
  DynamoDBDocumentClient,
  PutCommand,
  ScanCommand,
  DeleteCommand
} from "@aws-sdk/lib-dynamodb";
import crypto from "crypto";

const client = new DynamoDBClient({});
const db = DynamoDBDocumentClient.from(client);

const TABLE = "todos-table";

LAMBDA HANDLER CODE

📥 GET All Todos

async function getTodos() {
    const data = await db.send(new ScanCommand({
        TableName: TABLE
    }));

    return {
        statusCode: 200,
        body: JSON.stringify(data.Items || [])
    };
}

📝 CREATE Todo

async function createTodo(body) {
    const parsed = JSON.parse(body);

    const newTodo = {
        id: crypto.randomUUID(),
        title: parsed.title || "Untitled",
        completed: false,
        createdAt: new Date().toISOString()
    };

    await db.send(new PutCommand({
        TableName: TABLE,
        Item: newTodo
    }));

    return {
        statusCode: 201,
        body: JSON.stringify(newTodo)
    };
}

🗑️ DELETE Todo

async function deleteTodo(id) {
    await db.send(new DeleteCommand({
        TableName: TABLE,
        Key: { id }
    }));

    return {
        statusCode: 200,
        body: JSON.stringify({ message: "Deleted", id })
    };
}

⚡ Main Handler (Router)

export const handler = async (event) => {
    try {
        const method = event.requestContext?.http?.method;
        const path = event.rawPath;

        if (method === "GET" && path === "/todos") {
            return await getTodos();
        }

        if (method === "POST" && path === "/todos") {
            return await createTodo(event.body);
        }

        if (method === "DELETE" && path.startsWith("/todos/")) {
            const id = path.split("/")[2];
            return await deleteTodo(id);
        }

        return {
            statusCode: 404,
            body: JSON.stringify({ message: "Route not found" })
        };

    } catch (err) {
        console.error(err);
        return {
            statusCode: 500,
            body: JSON.stringify({ error: err.message })
        };
    }
};
