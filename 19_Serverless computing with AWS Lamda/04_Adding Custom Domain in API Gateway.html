ADDING CUSTOM DOMAIN IN API GATEWAY

MAP YOUR OWN DOMAIN TO AWS API GATEWAY FOR PRODUCTION-READY APIs

UNDERSTAND THE ARCHITECTURE

High-Level Flow

https://api.yourdomain.com
            ↓
      API Gateway
            ↓
    Lambda / Backend

Detailed Request Flow

User
 ↓
api.example.com
 ↓
DNS (Route53 / Cloudflare)
 ↓
API Gateway Custom Domain
 ↓
API Stage (prod)
 ↓
Lambda / Server
Three Things Must Exist
  • Domain — A registered domain name
  • SSL Certificate — Issued via AWS Certificate Manager
  • DNS Record — Pointing to API Gateway

SERVICES INVOLVED

Amazon API Gateway

Manages your API routes and custom domain configuration.

AWS Certificate Manager

Issues free SSL/TLS certificates for your domain.

Amazon Route 53

AWS DNS service to point your domain to API Gateway.

Domain Registrar

Route53, Namecheap, GoDaddy, or Cloudflare.

STEP 1 — GET A DOMAIN

You need a registered domain name. You'll typically use a subdomain for your API.

Domain

example.com

Subdomain We'll Use

api.example.com

You can buy domains from:

  • Route 53 — AWS native
  • Namecheap
  • GoDaddy
  • Cloudflare

STEP 2 — CREATE SSL CERTIFICATE

Go to AWS Console → Certificate Manager

Console Steps
  1. Click Request Certificate
  2. Add domain: api.example.com
  3. Choose DNS Validation (recommended)

AWS gives a DNS record to verify ownership:

Name:   _abcd.api.example.com
Value:  xyz.acm-validations.aws

Add this record to your DNS provider. After a minute or so:

✅ Status: Issued

Now AWS trusts your domain and the certificate is ready to use.

STEP 3 — OPEN API GATEWAY

Go to Amazon API Gateway in the AWS Console.

Console Steps
  1. In the left menu, click Custom Domain Names
  2. Click Create
  3. Fill in domain name: api.example.com
  4. Select certificate from ACM
  5. Set endpoint type: Regional (recommended)
  6. Click Create domain

STEP 4 — CREATE API MAPPING

Now connect the custom domain to your actual API.

Setting Value
Custom Domain api.example.com
API todo-api
Stage prod

Mapping Result

api.example.com → todo-api → prod

After creating the mapping, API Gateway gives you a Target Domain Name: 

d-abc123.execute-api.us-east-1.amazonaws.com
Important

You need this target domain name for the DNS configuration in the next step.

STEP 5 — CONFIGURE DNS

If Using Route 53

Create an Alias record:

Type:   A
Alias:  Yes
Target: API Gateway Domain

If Using Cloudflare / Namecheap / GoDaddy

Create a CNAME record:

Type:  CNAME
Name:  api
Value: d-abc123.execute-api
       .us-east-1.amazonaws.com

STEP 6 — WAIT & TEST

DNS propagation usually takes 1 – 5 minutes.

Test Your Custom Domain

https://api.example.com

or

https://api.example.com/todos

Your API should now respond through your custom domain.

REAL EXAMPLE

❌ Default AWS URL

https://abc123.execute-api
  .us-east-1.amazonaws.com
  /prod/users

Long, ugly, hard to remember.

✅ After Custom Domain

https://api.example.com/users

Cleaner and production-ready.

COMMON MISTAKES DEVELOPERS MAKE

1. Certificate Region Mismatch

Critical

For Regional APIs, the certificate must be in the same region as your API Gateway. 

API Gateway  → us-east-1
Certificate  → us-east-1  ✅

API Gateway  → us-east-1
Certificate  → eu-west-1  ❌

2. Wrong DNS Record

❌ Wrong

A → execute-api.amazonaws.com

✅ Correct

Alias → API Gateway domain

or

CNAME → target domain AWS gives

3. Stage Not Mapped

⚠️ Without mapping you get:

403 Forbidden

Always create the API mapping in Step 4 before testing.

BEST PRODUCTION SETUP

Domain Environment
api.example.com Production
dev-api.example.com Development
staging-api.example.com Staging
Why Separate Domains?

You never want dev code hitting production. Separate domains ensure complete isolation between environments.

BONUS — CLI METHOD (REAL DEV WAY)

Create Domain

aws apigatewayv2 create-domain-name \
  --domain-name api.example.com \
  --domain-name-configurations CertificateArn=ARN

Create Mapping

aws apigatewayv2 create-api-mapping \
  --domain-name api.example.com \
  --api-id abc123 \
  --stage prod

QUICK CHECKLIST

Before your custom domain works, make sure all of these are done:

Status Step
✔ Domain exists
✔ SSL certificate issued
✔ Custom domain created in API Gateway
✔ API mapping added
✔ DNS record created
Warning

Miss even one step and it fails. Go through the checklist carefully before debugging.
