🛡️ What Is Clickjacking? (Clear Definition)

Definition:

Clickjacking is an attack where the victim is tricked into clicking on something different from what they think they are clicking—usually because the real website is hidden inside an invisible iframe placed by the attacker.

Meaning:

  • You think you’re clicking a harmless button ➡️ but actually you're clicking a hidden button on another website (like “Delete account”, “Send money”, “Like this page”).

This works because:

  • ✔ attacker loads target website inside an iframe
  • ✔ attacker makes it transparent
  • ✔ attacker positions fake UI over it
  • ✔ victim clicks
  • ✔ hidden iframe receives the click

🎯 Why Is Clickjacking Dangerous?

These hidden clicks can trigger:

  • Bank transactions
  • Changing account settings
  • Following someone on social media
  • Upvoting posts
  • Deleting accounts
  • Allowing permissions

If the user is logged in to the real site, the browser sends cookies ➡️ attack becomes very powerful.

🔍 How Clickjacking Works (Step by Step)

Let’s say:

  • victim website = http://localhost:4000
  • attacker website = http://localhost:3000

1️⃣ Attacker embeds victim inside an iframe:

<iframe src="http://localhost:4000" style="opacity:0.01; position:absolute; top:0; left:0;"></iframe>

2️⃣ Attacker shows a fake button:

<button style="z-index:10; position:relative;">
  Click to win iPhone!</button>

3️⃣ But the iframe is on top of the button:

iframe {
  pointer-events: auto;
}button {
  pointer-events: none;
}

Now the victim thinks they are clicking the fake button…

But the click actually goes to the hidden iframe.

🚀 Let's Build a REAL Clickjacking Attack (Express.js)

We will create two servers:

🧨 Victim App (port 4000)

This simulates a real app with a dangerous button.

Create: victim.js

import express from "express";
const app = express();

app.get("/", (req, res) => {
  res.send(`
    <h1>Victim Website</h1>
    <form action="/delete-account" method="POST">
      <button style="font-size:24px;">Delete Account</button>
    </form>
  `);
});

app.post("/delete-account", (req, res) => {
  console.log("⚠️ VICTIM: Account deleted!");
  res.send("<h1>Account Deleted!</h1>");
});

app.listen(4000, () => console.log("Victim running on 4000"));

Run:

node victim.js

🎭 Attacker App (port 3000)

Create: attacker.js

import express from "express";
const app = express();

app.get("/", (req, res) => {

app.listen(3000, () => console.log("Attacker running on 3000"));

🔐 How to Protect Against Clickjacking (Express.js)

Use X-Frame-Options or Content-Security-Policy.

✔ Strongest protection (use this):

app.use((req, res, next) => {
  res.setHeader("Content-Security-Policy", "frame-ancestors 'none'");
  next();
});

✔ Or classic header:

app.use((req, res, next) => {
  res.setHeader("X-Frame-Options", "DENY");
  next();
});

This stops attackers from embedding your site in any iframe.
