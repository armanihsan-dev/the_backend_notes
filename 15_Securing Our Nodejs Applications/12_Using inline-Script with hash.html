🔒 Implementing Inline Scripts with a Hash

A script hash works by telling the browser: "Only execute inline scripts whose content, when hashed with the specified algorithm (e.g., SHA-256), matches this hash value."

---

1. ⚙️ How inline-scirpt with Hashing Works

The core idea is to create an allow-list for your inline scripts by their content, not by their source.

  • Generate Hash: You take the exact textual content of the inline JavaScript code (everything between the <script> tags, including spaces and newlines).
  • Calculate SHA-256 Hash: This content is put through a cryptographic hashing function, usually SHA-256, which produces a unique, fixed-length output (the hash).
  • Base64 Encode: This output is then Base64 encoded because the CSP header only accepts Base64 strings.
  • CSP Header Inclusion: You place this hash value into the Content-Security-Policy header using the format: script-src 'sha256-THE_HASH_VALUE'.
  • Browser Validation: When the browser encounters an inline script, it calculates the hash of that script's content and compares it against the list of hashes provided in the CSP header. If they match, the script executes; otherwise, it's blocked.
---

2. 📝 Syntax Definition

The CSP header format for allowing a specific inline script is:

Content-Security-Policy: script-src 'sha256-Base64EncodedHashValue';
Component Description
Content-Security-Policy: The HTTP response header name.
script-src The directive that specifies valid sources for JavaScript
'sha256-' Identifies the hash algorithm used (SHA-256).
Base64EncodedHashValue The Base64 encoded result of hashing the exact script content.
---

3. 🖥️ Express.js Example (Manual Header)

A. Calculate the Hash

We will use Node.js's built-in crypto module to generate the hash for this specific script: 

import {crypto} from 'crypto';

const scriptHash = crypto
  .createHash('sha256') // Use the SHA-256 algorithm
  .update(inlineScriptContent.trim()) // Hash the exact script content
  .digest('base64'); // Get the output in Base64 encoding

// The final CSP hash value you need to include in the header
const cspHashValue = `sha256-${scriptHash}`;

B. Express Implementation

In your Express application, you'll set the Content-Security-Policy header on the response using res.set(). 

const cspHeader = `default-src 'self'; script-src 'self' ${cspHashValue};`;
 res.set('Content-Security-Policy', cspHeader);

})
