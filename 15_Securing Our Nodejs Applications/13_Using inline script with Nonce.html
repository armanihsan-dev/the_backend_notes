🔑 Using Inline Scripts with a Nonce

A **nonce** is a random, cryptographically strong, **single-use token** that is generated on the server for every page request. The browser is instructed, via the CSP header, that it is allowed to execute any inline script **only if** that script tag includes the **exact matching nonce value**.

That's an excellent next step! While hashing is great for static scripts, a **nonce** (Number used ONCE) is the perfect solution for allowing **dynamically generated inline scripts** securely, as it avoids the limitations of hashing.

Here is a guide to using inline scripts with a Nonce, complete with clear syntax and an Express.js example.

---

1. ⚙️ How Nonce Works

The core idea is to create an **allow-list** for your inline scripts by their **content**, not by their source.

  • Server Generates Nonce: For every HTTP request, the server generates a new, unique, and **unpredictable random string** (the nonce).
  • CSP Header: The server sends the nonce in the Content-Security-Policy header using the nonce- prefix.
  • HTML Injection: The server then injects that **same exact nonce** into the nonce attribute of every single inline <script> tag that it intends to allow.
  • Browser Validation: When the browser encounters an inline <script> tag, it checks two things:
    1. Does the <script> tag have a nonce attribute?
    2. Does the value of the nonce attribute match the value specified in the script-src directive of the CSP header?
    If both match, the script runs. If not, it's blocked.

This approach is **secure** because an attacker cannot guess or predict the random nonce value to inject their own malicious scripts.

---

2. 📝 Syntax Definition

The **Nonce** must be included in two places: the **HTTP Response Header** and the **HTML script tag**.

A. CSP Header Syntax

The nonce value must be **Base64 encoded**.

Content-Security-Policy: script-src 'nonce-Base64EncodedNonceValue';
Component Description
script-src The directive for valid script sources.
'nonce-' The prefix indicating a nonce is being used.
Base64EncodedNonceValue The random string generated by the server, securely Base64 encoded.

B. HTML Script Tag Syntax

The same nonce value must be placed in the script tag's nonce attribute. 

<script nonce="Base64EncodedNonceValue">
    console.log('hii i am safe js file');
</script>

3. 🖥️ Express.js Example (Manual Nonce Generation) 

import express from "express";
import mongoose from "mongoose";
import { createHash } from 'crypto'
import crypto from 'crypto'
import { readFile } from "fs/promises";

const app = express();

app.use(express.json());
const hash = createHash('sha256').update("console.log('hii');").digest('base64')
// console.log(hash);

await mongoose.connect(
  "mongodb://admin:admin@localhost/socialApp?authSource=admin"
);

const postSchema = new mongoose.Schema({
  content: String,
  createdAt: { type: Date, default: Date.now },
});

const Post = mongoose.model("Post", postSchema);
app.use(async (req, res, next) => {
  const nonce = crypto.randomBytes(16).toString('base64')
  if (req.headers.accept?.includes('text/html')) {
    res.setHeader(
      'Content-Security-Policy',
      `default-src 'self';\
        script-src 'self' 'nonce-${nonce}';\
        style-src 'self';\
        connect-src 'self';\
        report-uri /csp-report;\
        `
    )
  }
  if (req.url === '/') {
    const indexHTMLFile = await readFile('./public/index.html', 'utf-8')
    return res.send(indexHTMLFile.replace('nonce="${nonce}"', `nonce="${nonce}"`))
  }
  next()
})
app.use(express.static("./public"));


// Routes
app.get("/posts", async (req, res) => {
  const posts = await Post.find().sort({ createdAt: -1 });
  res.setHeader("Set-Cookie", "loginSecret=hdxhw7yrx.k;");
  res.json(posts);
});

// Route to receive violation reports
app.post("/csp-report", express.json({ type: "application/csp-report" }), (req, res) => {
  console.log("📢 CSP VIOLATION REPORT RECEIVED:");
  // console.log(JSON.stringify(req.body, null, 2));
  res.status(204).end(); // No response needed
});

app.post("/posts", async (req, res) => {
  const post = new Post({ content: req.body.content });
  await post.save();
  res.status(201).json(post);
});

// Start server
app.listen(4000, () => console.log("Server running on http://localhost:4000"));
