Deployment: Node.js Backend on AWS EC2

Deployment refers to the process of making your Node.js application accessible and running on a live server that users can access over the internet. AWS EC2 (Elastic Compute Cloud) is a virtual server in the cloud where you can install and run your application.

What Happens During Deployment

1. Server Provisioning

  • Create an EC2 instance (virtual machine)
  • Choose OS (usually Linux like Ubuntu or Amazon Linux)
  • Configure security groups (firewall rules)
  • Set up SSH access

2. Environment Setup

# Example setup commands
sudo apt update
sudo apt install nodejs npm
sudo npm install -g pm2 # Process manager

3. Application Transfer

  • Copy your code to the server (using Git, SCP, or deployment tools)
  • Install dependencies: npm install
  • Set up environment variables

4. Running the Application

# Start your Node.js app
pm2 start server.js
pm2 save
pm2 startup # Auto-start on reboot

5. Configuration

  • Set up Nginx/Apache as reverse proxy
  • Configure SSL certificates (HTTPS)
  • Set up domain name (Route 53)
  • Configure monitoring and logging

Typical Architecture

User Request → Domain Name → Route 53 → EC2 Instance → Nginx (Port 80/443) → Node.js App (Port 3000)

Key Components

Component Description
EC2 Instance Your virtual server
Security Groups Control inbound/outbound traffic
Elastic IP Static IP address for your instance
PM2/Nodemon Process management
Nginx/Apache Web server and reverse proxy
RDS/other services Database (optional, can be on EC2 or separate)

Common Deployment Methods

  • Manual Deployment: SSH into server and manually set up
  • Using Scripts: Automation with bash scripts
  • CI/CD Pipeline: GitHub Actions, Jenkins, AWS CodeDeploy
  • Containerization: Docker + ECS/EKS
  • Using AMIs: Create custom machine images

Why Deploy on EC2?

  • Full Control: Complete access to the server
  • Scalability: Easy to resize instance or use Auto Scaling
  • Cost-Effective: Pay only for what you use
  • Integration: Works with other AWS services
  • Flexibility: Install any software you need

Basic Flow Example

# 1. Connect to EC2
ssh -i key.pem ubuntu@ec2-public-ip

# 2. Clone your code
git clone https://github.com/your-repo.git

# 3. Install dependencies
npm install

# 4. Set environment variables
export DATABASE_URL="your-db-url"
export PORT=3000

# 5. Start application
node server.js

This makes your Node.js backend accessible via the EC2 instance's public IP or domain name, serving API requests from clients (web/mobile apps).
