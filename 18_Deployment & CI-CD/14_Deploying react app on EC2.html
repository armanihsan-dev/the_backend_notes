EC2 INSTANCE SETUP

🚀 Launch EC2 Instance

  1. Choose AMI: Ubuntu Server 22.04 LTS
  2. Instance Type: t2.micro (free tier) or t3.small
  3. Key Pair: Create or select existing SSH key
  4. Security Group: Allow HTTP (80), HTTPS (443), SSH (22)
  5. Storage: 8-20 GB gp3 (depending on app size)

🔐 Security Group Configuration

Type Protocol Port Source Purpose
SSH TCP 22 Your IP Remote access
HTTP TCP 80 0.0.0.0/0 Web traffic
HTTPS TCP 443 0.0.0.0/0 Secure web traffic

🔌 Connect to Instance

# Connect via SSH
ssh -i "your-key.pem" ubuntu@your-ec2-public-ip

# Update system packages
sudo apt update && sudo apt upgrade -y

NGINX CONFIGURATION

⚙️ Main Nginx Configuration

# /etc/nginx/nginx.conf
user www-data;
worker_processes auto;
pid /run/nginx.pid;

events {
    worker_connections 768;
}

http {
    sendfile on;
    tcp_nopush on;
    tcp_nodelay on;
    keepalive_timeout 65;
    types_hash_max_size 2048;
    
    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    # Gzip Settings
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/plain text/css text/xml text/javascript 
               application/javascript application/xml+rss 
               application/json;

    include /etc/nginx/conf.d/*.conf;
    include /etc/nginx/sites-enabled/*;
}

🌐 Site-specific Configuration

# /etc/nginx/sites-available/your-domain.com
server {
    listen 80;
    listen [::]:80;
    server_name your-domain.com www.your-domain.com;
    
    root /home/ubuntu/your-react-app/build;
    index index.html index.htm;
    
    # Security headers
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    
    # Gzip compression
    gzip_static on;
    
    location / {
        try_files $uri $uri/ /index.html;
        
        # Cache static assets
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
            expires 1y;
            add_header Cache-Control "public, immutable";
            try_files $uri =404;
        }
    }
    
    # Block hidden files
    location ~ /\. {
        deny all;
        access_log off;
        log_not_found off;
    }
    
    # Custom error pages
    error_page 404 /index.html;
    error_page 500 502 503 504 /50x.html;
    
    location = /50x.html {
        root /usr/share/nginx/html;
    }
}

🔗 Enable the Site

# Create symlink to sites-enabled
sudo ln -s /etc/nginx/sites-available/your-domain.com /etc/nginx/sites-enabled/

# Remove default site
sudo rm /etc/nginx/sites-enabled/default

# Test Nginx configuration
sudo nginx -t

# Reload Nginx
sudo systemctl reload nginx

💾 Add Swap Memory (for small instances)

# Create swap file
sudo fallocate -l 1G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# Make permanent
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

COMMON ERRORS & FIXES

🚫 Error 1: React Router 404 Errors

Problem

Issue: Direct URL access or refresh shows 404

Cause: Nginx tries to find the route as a file

# Fix: Add to location block
location / {
    try_files $uri $uri/ /index.html;
}

🎨 Error 2: MIME Type Issues

Problem

Issue: CSS/JS files served with wrong content-type

Cause: Missing mime.types or incorrect configuration 

# Fix: Add to http block
http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;
    
    # Add specific types if needed
    types {
        application/javascript js mjs;
        text/css css;
    }
}

🔐 Error 3: Permission Denied

Problem

Issue: Nginx can't read build files

Cause: Incorrect file permissions

# Fix: Set proper ownership
sudo chown -R www-data:www-data /home/ubuntu/your-react-app/build
sudo chmod -R 755 /home/ubuntu/your-react-app/build

# Or give Nginx user access
sudo usermod -a -G ubuntu www-data

🌐 Error 4: CORS Issues

Problem

Issue: API requests blocked

Cause: Different domains/ports

// Fix: Configure API server CORS or use Nginx reverse proxy
// For development only:
{
  "proxy": "http://localhost:5000"  // In package.json
}

💾 Error 5: Memory Issues on Small Instances

Problem

Issue: Nginx or Node crashes

Cause: Insufficient memory

# Fix: Add swap and optimize Nginx
# Create swap (shown above)
# Optimize Nginx for micro instances
sudo nano /etc/nginx/nginx.conf
# Set: worker_processes 1;

DEPLOYMENT AUTOMATION

🤖 Complete Deployment Script

#!/bin/bash
# deploy.sh - Automated deployment script

# Update system
sudo apt update && sudo apt upgrade -y

# Install Nginx
sudo apt install nginx -y

# Install Node.js
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install nodejs -y

# Install PM2 for process management
sudo npm install -g pm2

# Clone or copy React app
cd /home/ubuntu
git clone https://github.com/yourusername/your-react-app.git
cd your-react-app

# Install dependencies and build
npm install
npm run build

# Configure Nginx
sudo rm /etc/nginx/sites-enabled/default
sudo cp nginx-config /etc/nginx/sites-available/your-app
sudo ln -s /etc/nginx/sites-available/your-app /etc/nginx/sites-enabled/

# Set permissions
sudo chown -R www-data:www-data /home/ubuntu/your-react-app/build
sudo chmod -R 755 /home/ubuntu/your-react-app/build

# Restart services
sudo nginx -t
sudo systemctl restart nginx
sudo systemctl enable nginx

echo "Deployment complete!"

MAINTENANCE & BEST PRACTICES

🔄 Regular Maintenance Tasks

  • Keep system updated: sudo apt update && sudo apt upgrade -y
  • Monitor disk space: df -h
  • Check memory usage: free -m
  • Review logs regularly: Check for errors and unusual activity
  • Backup configurations: Nginx config and build files

🛡️ Security Best Practices

  • Use SSH keys only (disable password authentication)
  • Keep system and packages updated
  • Configure firewall properly
  • Use HTTPS always
  • Regular security audits
  • Monitor access logs
  • Implement fail2ban for SSH protection
