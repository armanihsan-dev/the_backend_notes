PM2: The Complete Guide

What is PM2?

PM2 is a production process manager for Node.js applications that helps you keep your applications alive forever, reload them without downtime, and manage their performance.

Why NOT to use npm start in AWS EC2:

  • No process management: If your app crashes, it stays dead
  • No auto-restart: You need to manually restart after failures
  • No load balancing: Can't handle multiple CPU cores efficiently
  • No monitoring: No logs management or performance metrics
  • Terminates on logout: Process stops when SSH session ends

Basic PM2 Commands (Ubuntu)

Installation:

# Install PM2 globally
npm install -g pm2
# OR using yarn
yarn global add pm2

Starting & Managing Applications:

# Start your Node.js app
pm2 start app.js

# Start with a custom name
pm2 start app.js --name "my-api"

# List all running applications
pm2 list

# Monitor CPU/Memory usage
pm2 monit

# Stop an application
pm2 stop app_name

# Restart an application
pm2 restart app_name

# Delete from PM2 list
pm2 delete app_name

# View application logs
pm2 logs app_name

# Clear all logs
pm2 flush

Setting PM2 to Auto-Start on System Boot

Step-by-Step Setup:

# 1. Generate startup script
pm2 startup

# You'll see output like:
# [PM2] To setup the Startup Script, copy/paste the following command:
# sudo env PATH=$PATH:/usr/bin /usr/lib/node_modules/pm2/bin/pm2 startup systemd -u ubuntu --hp /home/ubuntu

# 2. Run the command provided by PM2
sudo env PATH=$PATH:/usr/bin /usr/lib/node_modules/pm2/bin/pm2 startup systemd -u ubuntu --hp /home/ubuntu

# 3. Save current PM2 processes
pm2 save

# 4. Test reboot behavior (optional - do in maintenance window)
sudo reboot

Verification:

# Check if PM2 service is enabled
sudo systemctl status pm2-ubuntu

# Manually test the startup script
sudo systemctl start pm2-ubuntu

Update PM2 processes after changes:

# After adding new apps or changes
pm2 save

Production Benefits of PM2

1. Zero Downtime Reloads:

# Reload app without downtime (for cluster mode)
pm2 reload app_name

# Graceful reload with 5-second timeout
pm2 gracefulReload app_name --timeout 5000

2. Cluster Mode (Load Balancing):

# Start app using all CPU cores
pm2 start app.js -i max

# Scale to specific number of instances
pm2 scale app_name 4

3. Monitoring & Logging:

# Real-time dashboard
pm2 dashboard

# JSON/CSV export of metrics
pm2 show app_name

# Log management with rotation
pm2 install pm2-logrotate
pm2 set pm2-logrotate:max_size 10M
pm2 set pm2-logrotate:retain 30

4. Application Configuration File (Ecosystem):

Create ecosystem.config.js:

module.exports = {
  apps: [{
    name: 'my-app',
    script: './app.js',
    instances: 'max',
    autorestart: true,
    watch: false,
    max_memory_restart: '1G',
    env: {
      NODE_ENV: 'development',
    },
    env_production: {
      NODE_ENV: 'production',
    }
  }]
};
# Start with ecosystem file
pm2 start ecosystem.config.js --env production

# Start and save to PM2
pm2 startOrRestart ecosystem.config.js --env production
pm2 save

Complete Example Workflow

Deploying a Node.js App on AWS EC2:

# 1. SSH into EC2 instance
ssh -i key.pem ubuntu@ec2-ip

# 2. Install Node.js and PM2
curl -sL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install nodejs
sudo npm install -g pm2

# 3. Clone your application
git clone https://github.com/your/app.git
cd app
npm install

# 4. Start with PM2
pm2 start server.js --name "api-server"

# 5. Setup auto-start on boot
pm2 startup
# Run the provided command
pm2 save

# 6. Setup Nginx as reverse proxy (optional)
sudo apt install nginx
sudo nano /etc/nginx/sites-available/default
# Add: location / { proxy_pass http://localhost:3000; }
sudo systemctl restart nginx

Key Advantages Over npm start:

Feature npm start PM2
Auto-restart on crash ❌ No ✅ Yes
Process management ❌ No ✅ Yes
Load balancing ❌ No ✅ Yes
Log management ❌ Manual ✅ Automatic
Monitoring ❌ No ✅ Built-in
Survives SSH logout ❌ No ✅ Yes
Startup on system boot ❌ Manual ✅ Automatic

Important PM2 Tips:

# View detailed info about an app
pm2 show app_name

# Reset restart count
pm2 reset app_name

# Generate static website for monitoring
pm2 serve /path 8080

# Update PM2
npm install -g pm2@latest
pm2 update

# Kill PM2 daemon
pm2 kill

Troubleshooting Auto-Start Issues:

# Check PM2 logs
pm2 logs

# Check systemd service status
sudo journalctl -u pm2-ubuntu -f

# Re-dump startup script
pm2 unstartup
pm2 startup
pm2 save

# Check saved processes
pm2 resurrect

PM2 transforms your Node.js deployment from fragile to production-ready with minimal configuration. It's the industry standard for running Node.js applications in production environments.
