PART 1: WHAT IS ALL THIS?

What is CI/CD?

  • CI (Continuous Integration): "Every time you save code, automatically test it."
  • CD (Continuous Deployment): "If tests pass, automatically deploy to server."
Real-Life Analogy

Without CI/CD: Write code → Save files → Run tests manually → Deploy manually (type many commands) → Check if it works.

With CI/CD: Write code → Push to GitHub → 🤖 MAGIC HAPPENS AUTOMATICALLY (Tested, Built, Deployed).

WHAT ARE GITHUB WEBHOOKS?

Think of it as GitHub calling your phone when something happens:

  • You push code → GitHub calls your server (HTTP POST)
  • You create a pull request → GitHub calls your server
  • You merge code → GitHub calls your server

PART 2: HOW IT ALL WORKS TOGETHER

You Push Code to GitHub
        ↓
GitHub Sends a Webhook (HTTP POST)
        ↓
Your Node.js Server Receives It
        ↓
Server Runs Your Pipeline Script
        ↓
Pipeline: Test → Build → Deploy
        ↓
Server Reports Back to You

PART 5: SETTING UP GITHUB WEBHOOK

Expose Local Server

Since your server is localhost, GitHub can't reach it. Use ngrok. 

ngrok http 3000
# Copy the URL: https://abc1234.ngrok.io

GitHub Steps:

  1. Go to Repository Settings → Webhooks.
  2. Click Add webhook.
  3. Payload URL: https://abc1234.ngrok.io/webhook
  4. Content type: application/json
  5. Events: Select "Just the push event".
  6. Click Add webhook.

PART 6: COMPLETE SERVER WITH SECURITY

Here is the robust `server.js` including signature verification (security) and deployment status tracking. 


import express from "express";
import { spawn } from "child_process";
import crypto from "crypto";

const app = express();
const PORT = 5000;

/* ================================
   🔐 VERIFY GITHUB SIGNATURE
================================ */
function verifyGitHub(req) {
  const signature = req.headers["x-hub-signature-256"];
  const secret = "cicdsec@123"; // MUST match GitHub webhook secret

  if (!signature) return false;

  const hash =
    "sha256=" +
    crypto.createHmac("sha256", secret).update(req.body).digest("hex");

  const sigBuffer = Buffer.from(signature);
  const hashBuffer = Buffer.from(hash);

  if (sigBuffer.length !== hashBuffer.length) return false;

  return crypto.timingSafeEqual(sigBuffer, hashBuffer);
}

/* ================================
   ⚠️ IMPORTANT MIDDLEWARE ORDER
   raw body FIRST for webhook
================================ */
app.use("/githubwebhook", express.raw({ type: "*/*" }));

// normal json middleware for other routes
app.use(express.json());

/* ================================
   HOME ROUTE
================================ */
app.get("/", (req, res) => {
  res.send("🚀 CI/CD Server running");
});

/* ================================
   🔥 GITHUB WEBHOOK ROUTE
================================ */
app.post("/githubwebhook", (req, res) => {
  console.log("📩 Webhook received");

  // verify request came from github
  if (!verifyGitHub(req)) {
    console.log("❌ Unauthorized webhook attempt blocked");
    return res.status(401).send("Not allowed");
  }

  console.log("✅ GitHub webhook verified");
  console.log("🚀 Starting deployment...");

  // run deploy script
  const bashChildProcess = spawn("bash", ['deploy.sh'], {
    cwd: '../'
  });

  // show logs in terminal
  bashChildProcess.stdout.on("data", (data) => {
    console.log(`📦 ${data}`);
  });

  bashChildProcess.stderr.on("data", (data) => {
    console.error(`❌ ERROR: ${data}`);
  });

  bashChildProcess.on("close", (code) => {
    if (code === 0) {
      console.log("✅ Deployment completed successfully");
    } else {
      console.log("❌ Deployment failed with code:", code);
    }
  });

  bashChildProcess.on("error", (err) => {
    console.error("❌ Failed to start deploy script:", err);
  });

  res.status(200).json({
    success: true,
    message: "🚀 Deployment started"
  });
});

/* ================================
   START SERVER
================================ */
app.listen(PORT, () => {
  console.log(`🚀 Server running on http://localhost:${PORT}`);
});

PART 8: DEPLOY YOUR CI/CD SERVER

To keep this server running forever on a VPS (like DigitalOcean or AWS).

Use PM2 (Process Manager)

# Install PM2
npm install -g pm2

# Start server
pm2 start server.js --name "ci-cd-server"

# Make it start on system boot
pm2 startup
pm2 save

# View logs
pm2 logs ci-cd-server

PART 10: TROUBLESHOOTING

1. Webhook not arriving?

# Check if server is accessible
curl http://localhost:3000

# Test webhook locally
curl -X POST http://localhost:3000/webhook \
  -H "Content-Type: application/json" \
  -d '{"repository":{"name":"test"}}'

2. Permission Denied?

# Give execute permission to scripts
chmod +x scripts/*.sh
