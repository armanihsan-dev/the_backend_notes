Serving JSON with a Status Code

The most common way to serve JSON is to chain the res.status() method with res.json(). The res.status() method takes a numeric HTTP status code as an argument and sets the response status. The res.json() method takes a JavaScript object or array as an argument, converts it to a JSON string, and sends it as the response body.

Here is a basic example:

JavaScript 
const express = require('express');
const app = express();
const PORT = 3000;

app.get('/api/data', (req, res) => {
  const data = {
    message: 'Data retrieved successfully!',
    user: 'John Doe',
    id: 123
  };
  
  // Set the status code to 200 (OK) and send the JSON response
  res.status(200).json(data);
});

app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`);
});

In this example, a GET request to /api/data will return the JSON object with a 200 OK status code.

Handling Different Status Codes

You can change the status code to reflect the outcome of the request. Here are some common examples:

201 Created 🟢

Used when a new resource is successfully created on the server, like after a POST request.

JavaScript 
app.post('/api/users', (req, res) => {
  const newUser = { id: 456, name: 'Jane Doe' };
  // A new user has been created
  res.status(201).json(newUser);
});

404 Not Found 🔴

Used when the requested resource doesn't exist.

JavaScript 
app.get('/api/item/:id', (req, res) => {
  const itemId = req.params.id;
  // Assume no item is found with this ID
  res.status(404).json({ error: 'Item not found.' });
});

400 Bad Request 🟠

Used when the client's request is invalid (e.g., missing data in the request body).

JavaScript 
app.post('/api/products', (req, res) => {
  if (!req.body.name) {
    res.status(400).json({ error: 'Product name is required.' });
    return;
  }
  // Process valid request...
});

The res.json() Method's Automatic Behavior

The res.json() method automatically sets the Content-Type header to application/json for you, so you don't need to set it manually. If you don't explicitly call res.status(), Express will use the default status code, which is 200 OK. However, it's a best practice to always set the status code to be explicit about the result of the API call.
