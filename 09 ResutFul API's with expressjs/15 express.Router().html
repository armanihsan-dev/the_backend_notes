Express.Router() Syntax and Methods

The Express.Router() is a function that creates a new router object. Once you have a router object, you can use methods on it to define routes, just like you would with the main app object. The key methods and syntax elements are:

1. Creating a Router Instance

You create a new router by calling the express.Router() function. This instance acts as a self-contained router that can be mounted on a specific path.

JavaScript

const router = express.Router()

2. Defining Routes with HTTP Methods

The router object has methods that correspond to HTTP verbs (e.g., GET, POST, PUT, DELETE). These methods are used to define route handlers.

Syntax: router.method(path, handler)

  • method: An HTTP verb (e.g., get, post, put, delete).
  • path: The URL path for the route, relative to where the router is mounted.
  • handler: The callback function that is executed when the route is matched. It receives the request (req) and response (res) objects.

Create the Route Files

Create two separate route files: users.js and products.js.

routes/users.js

This file will handle all routes related to users.

JavaScript

import { Router } from 'express'; const router = Router(); // Middleware for this router (optional) router.use((req, res, next) => { console.log('Time:', Date.now()); next(); }); // A route to get all users router.get('/', (req, res) => { res.send('Get all users'); }); // A route to get a user by ID router.get('/:id', (req, res) => { res.send(`Get user with ID: ${req.params.id}`); }); // Export the router using ES6 module syntax export default router;

routes/products.js

This file will handle all routes related to products.

JavaScript

import { Router } from 'express'; const router = Router(); // A route to get all products router.get('/', (req, res) => { res.send('Get all products'); }); // A route to get a product by ID router.get('/:id', (req, res) => { res.send(`Get product with ID: ${req.params.id}`); }); // Export the router using ES6 module syntax export default router;

3. Import and Use Routes in app.js

In your main app.js file, you will import the routers and use them with app.use().

app.js

JavaScript

import express from 'express'; import usersRouter from './routes/users.js'; import productsRouter from './routes/products.js'; const app = express(); const port = 3000; // Use the routers as middleware // The base path for all user routes will be '/users' app.use('/users', usersRouter); // The base path for all product routes will be '/products' app.use('/products', productsRouter); // A simple root route for the main app app.get('/', (req, res) => { res.send('Welcome to the homepage!'); }); app.listen(port, () => { console.log(`App listening at http://localhost:${port}`); });

How It Works

When you run the application, Express receives a request like http://localhost:3000/users/5. It first looks for a matching path in app.js. When it finds app.use('/users', usersRouter), it forwards the request to the usersRouter. The usersRouter then handles the remaining path (/ :id) and responds. This architecture keeps your routes organized and scalable.
