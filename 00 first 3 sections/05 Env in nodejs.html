Working with Environment Variables

Node.js Environment Variables

Accessing Environment Variables

// Read environment variables
const nodeEnv = process.env.NODE_ENV || 'development';
const port = process.env.PORT || 3000;

console.log(`Environment: ${nodeEnv}`);
console.log(`Server port: ${port}`);

Setting Environment Variables in Node.js

// Set environment variables (only affects current process)
process.env.API_KEY = 'abc123';
process.env.DEBUG_MODE = 'true';

// Set multiple variables
Object.assign(process.env, {
  DB_HOST: 'localhost',
  DB_PORT: '5432'
});

Deleting Environment Variables in Node.js

// Delete environment variables
delete process.env.TEMP_VAR;

// Alternative method
process.env.TEMP_VAR = undefined;

add user level env from nodejs directly

const process = require('node:process');

✅ SET system-level env var
exec(
  `powershell -Command "Start-Process cmd -Verb RunAs -ArgumentList '/c reg add \\"HKLM\\SYSTEM\\CurrentControlSet\\Control\\Session Manager\\Environment\\" /v ${key} /t REG_SZ /d ${value} /f'"`,
  (err) => {
    if (err) return console.error('❌ Error:', err.message);
    console.log('✅ System variable set!');
  }
);

🧱 Want to Delete It?
Replace the command in the script with:
exec(
  `powershell -Command "Start-Process cmd -Verb RunAs -ArgumentList '/c reg delete \\"HKLM\\SYSTEM\\CurrentControlSet\\Control\\Session Manager\\Environment\\" /v ${key} /f'"`,
  (err) => {
    if (err) return console.error('❌ Error:', err.message);
    console.log('🗑️ System variable deleted!');
  }
);
Note: Changes to process.env only affect the current Node.js process and won't persist after the process exits.

System-Level Environment Variables

Windows (PowerShell/CMD)

Add User-Level Environment Variable

# PowerShell
[System.Environment]::SetEnvironmentVariable("API_KEY", "abc123", "User")

# CMD
setx API_KEY "abc123"

Add System-Level Environment Variable (Admin Required)

# PowerShell (Admin)
[System.Environment]::SetEnvironmentVariable("API_KEY", "abc123", "Machine")

# CMD (Admin)
setx API_KEY "abc123" /M

# Using registry (Admin)
powershell -Command "Start-Process cmd -Verb RunAs -ArgumentList '/c reg add \"HKLM\\SYSTEM\\CurrentControlSet\\Control\\Session Manager\\Environment\" /v NEXT_PUBLIC_API_KEY /t REG_SZ /d abc123 /f'"

Update Existing Environment Variable

# PowerShell (Admin)
[System.Environment]::SetEnvironmentVariable("NAME", "kamran", "Machine")

# CMD (Admin)
setx NAME "kamran" /M

# Using PowerShell with elevation
powershell -Command "Start-Process powershell -Verb RunAs -ArgumentList 'setx name \"kamran\" /M'"

Delete Environment Variable

# PowerShell (User-level)
[System.Environment]::SetEnvironmentVariable("TEMP_VAR", $null, "User")

# PowerShell (System-level, Admin)
[System.Environment]::SetEnvironmentVariable("TEMP_VAR", $null, "Machine")

# Using registry (Admin)
reg delete "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment" /v TEMP_VAR /f
Warning: Modifying system-level environment variables requires administrator privileges and may affect all users on the system.

Linux/macOS

Add to Current Session

export API_KEY="abc123"

Add Permanently (User)

# Add to ~/.bashrc, ~/.zshrc, or ~/.profile
echo 'export API_KEY="abc123"' >> ~/.bashrc
source ~/.bashrc

Add System-Wide (Admin)

# Add to /etc/environment (Debian/Ubuntu)
echo 'API_KEY="abc123"' | sudo tee -a /etc/environment

# Or create a file in /etc/profile.d/
echo 'export API_KEY="abc123"' | sudo tee /etc/profile.d/my_vars.sh

Delete Environment Variable

# Current session
unset API_KEY

# Permanently - remove from relevant config file
sed -i '/export API_KEY/d' ~/.bashrc

Best Practices

Practice Description
Use .env files for development Store environment variables in a .env file (add to .gitignore)
Validate required variables Check for essential variables when application starts
Use different .env files .env.dev, .env.test, .env.prod for different environments
Never commit secrets Keep sensitive data out of version control
Use configuration objects Centralize environment variable access with type conversion
Tip: After modifying system-level environment variables, you may need to restart applications (including your terminal) for changes to take effect.
