Defining custom methods on mongoose documents

It's great you're diving into Mongoose custom methods! You can define custom **instance methods** directly on the Mongoose **Schema** using the .methods object. These methods become available on every **document** retrieved or created using that schema.

Here's a step-by-step guide:

Defining Custom Methods on a Mongoose Schema

You define your custom methods **before** creating the model.

1. Define the Schema

Start by requiring Mongoose and defining your schema.

JavaScript


const mongoose = require('mongoose');

// Define the User schema
const userSchema = new mongoose.Schema({
  name: {
    type: String,
    required: true
  },
  age: Number,
  email: String
});

2. Add Methods using .methods

Attach your custom functions to the userSchema.methods object. Inside these functions, this refers to the specific Mongoose **document** on which the method is called.

Example Methods:

JavaScript


// Add a custom method to get a user's initials
userSchema.methods.getInitials = function() {
  // 'this' refers to the specific user document
  const nameParts = this.name.split(' ');
  let initials = '';
  for (const part of nameParts) {
    if (part.length > 0) {
      initials += part[0].toUpperCase();
    }
  }
  return initials;
};

// Add a method to say a greeting
userSchema.methods.sayHello = function() {
  return `Hello! My name is ${this.name} and I am ${this.age} years old.`;
};

// You can also use async/await for methods that perform database operations
userSchema.methods.findSimilarAgeUsers = async function() {
  // Query the database for users with age close to this user's age
  const similarUsers = await mongoose.models.User.find({
    age: { $gte: this.age - 5, $lte: this.age + 5 }, // e.g., within 5 years
    _id: { $ne: this._id } // Exclude the current user
  });
  return similarUsers;
};

3. Create the Model

Create your Mongoose model using the defined schema.

JavaScript


// Create the Mongoose Model
const User = mongoose.model('User', userSchema);

module.exports = User;

Accessing Custom Methods in Node.js

Once you have defined the methods on the schema and created the model, you can access them on any **document instance**.

Example Usage:

JavaScript


const User = require('./userModel'); // Assuming your model file is 'userModel.js'

// ... (Connect to MongoDB here) ...

async function runExample() {
  // 1. Create a new document (instance)
  const newUser = new User({
    name: 'Jane Doe',
    age: 30,
    email: 'jane.doe@example.com'
  });

  // 2. Call the instance methods (they are available on the 'newUser' document)
  const initials = newUser.getInitials();
  console.log(`Initials: ${initials}`); // Output: JD

  const greeting = newUser.sayHello();
  console.log(`Greeting: ${greeting}`); // Output: Hello! My name is Jane Doe and I am 30 years old.

  // 3. Save the user
  await newUser.save();

  // 4. Retrieve a document from the database
  const retrievedUser = await User.findOne({
    name: 'Jane Doe'
  });

  // 5. Call the async instance method on the retrieved document
  const similarAgeUsers = await retrievedUser.findSimilarAgeUsers();
  console.log(`Found ${similarAgeUsers.length} users with similar age.`);
}

runExample();

Key Takeaway:

  • **Instance Methods (using .methods):** Used for logic specific to a **single document** (e.g., calculating a user's age, formatting a name, or finding related documents based on the current document's properties). They are called on a document instance (e.g., user.sayHello()).
  • For methods that operate on the **Model as a whole** (e.g., a custom search function that doesn't rely on a specific document's data), you'd use **Static Methods** with userSchema.statics.

The custom method is being defined inside the **Schema Options object**, which is the second argument passed to new Schema(). This is a clean, modern way to define **Instance Methods** in Mongoose.

1. Extracting and Teaching the Syntax

The key to defining custom methods in your provided schema lies in the **second argument** of the new Schema() constructor: the **Schema Options object**.

Custom Method Syntax

Part Code Example Description
Schema Definition new Schema(schemaDefinition, **options**) The Mongoose Schema constructor takes two arguments. We focus on the second one: options.
Methods Container methods: { ... } Inside the options object, you define instance methods using the methods property.
Method Name getSummary(...) This is the name you want the method to have on the document.
Method Function getSummary(**option**) { ... } This is the actual JavaScript function. It can take arguments (option in this case).
Document Access **this**.name Inside the method function, the keyword this refers to the specific **Mongoose Document** (or instance) on which the method is called. This allows you to access the document's fields like name, age, and hobbies.

In your code:

JavaScript


// Second argument to new Schema() is the options object
{ 
    strict: 'throw', 
    timestamps: true,
    // <--- THIS IS WHERE THE CUSTOM METHOD IS DEFINED --->
    methods: {
        getSummary(option) { 
            // 'this' refers to the document instance
            if (option === 'full') {
                return `I am ${this.name}. And i am ${this.age} years old. I am really intrested in ${this.hobbies.join(', ')}`
            } else {
                return `I am ${this.name}. And i am ${this.age} years old.`
            }
        }
    }
}

2. How to Access getSummary Later

The method getSummary is an **Instance Method**, meaning it's only available on a specific **document** retrieved from or created by the Mongoose Model, not on the Model itself.

Step 1: Create the Model

First, you need to create the Mongoose Model from your schema.

JavaScript


// Assume modelSchema is defined as above
const mongoose = require('mongoose');
const Model = mongoose.model('ModelName', modelSchema);

Step 2: Access a Document

You must either create a new document or retrieve an existing one from the database.

JavaScript


async function useCustomMethod() {
    // A. Retrieve an existing document (e.g., by finding one)
    const documentInstance = await Model.findOne({ name: 'John Doe' });

    // OR

    // B. Create a new document instance
    const newDocument = new Model({
        name: 'Jane Smith',
        age: 25,
        hobbies: ['coding', 'reading']
    });

    if (newDocument) {
        // ... proceed to call the method on the document instance
    }
}

Step 3: Call the Instance Method

You call getSummary directly on the **document instance** you retrieved or created, just like a regular object method.

Example Calls:

Call Type Code Output
Basic Summary newDocument.getSummary() Returns: I am Jane Smith. And i am 25 years old.
Full Summary newDocument.getSummary('full') Returns: I am Jane Smith. And i am 25 years old. I am really intrested in coding, reading
