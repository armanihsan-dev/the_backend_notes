Defining Static Methods on a Mongoose model

You define static methods using the .statics property of your schema.

The Syntax

JavaScript


// 1. Define the base Schema
const mySchema = new mongoose.Schema({ /* fields */ });

// 2. Attach the static methods
mySchema.statics.methodName = function(argument1, argument2) {
    // Inside a static method, 'this' refers to the Mongoose Model itself.
    // Therefore, 'this' can be used to call Model functions like find(), create(), etc.
    return this.find({ /* some query logic */ });
};

Key Difference: this Context

Method Type Used for this refers to Called on
Instance (.methods) Document-specific logic The individual **document** (instance) myDocument.sayHello()
Static (.statics) Model/Collection logic The **Model** (e.g., User or Product) User.findActive()

Example: Defining and Using Static Methods

Let's use a Product model to illustrate a common use case for static methods: custom search and filtering logic.

1. Schema Definition and Static Methods

JavaScript


const mongoose = require('mongoose');

// Define the Product schema
const productSchema = new mongoose.Schema({
    name: String,
    price: Number,
    inStock: { type: Boolean, default: true },
    category: String
});

// --- DEFINE STATIC METHODS ---

// Static Method 1: Find all products that are currently in stock
productSchema.statics.findInStock = function() {
    // 'this' refers to the Product Model
    return this.find({ inStock: true });
};

// Static Method 2: Find products by category, demonstrating argument passing
productSchema.statics.findByCategory = function(categoryName) {
    return this.find({ category: categoryName }).sort({ price: -1 }); // Sort by price descending
};

// Static Method 3 (Async): A more complex aggregate operation
productSchema.statics.getAveragePriceByCategory = async function(categoryName) {
    const result = await this.aggregate([
        { $match: { category: categoryName } },
        { $group: { _id: '$category', averagePrice: { $avg: '$price' } } }
    ]);
    // Return the average price, or null if no results
    return result.length > 0 ? result[0].averagePrice : null;
};

// Create the Model
const Product = mongoose.model('Product', productSchema);

module.exports = Product;

2. Accessing Static Methods in Node.js

Since static methods are defined on the Schema's .statics property, they are called directly on the compiled Mongoose **Model** (Product).

JavaScript


const Product = require('./productModel'); // Assuming the above code is in productModel.js

async function runStaticExamples() {
    // Note: We don't need a specific document instance to call these methods!

    // Example 1: Using findInStock()
    console.log('--- 🔎 Products In Stock ---');
    const stockItems = await Product.findInStock();
    console.log(`Found ${stockItems.length} products currently in stock.`);
    // Output: Found X products currently in stock.

    // Example 2: Using findByCategory('Electronics')
    console.log('\n--- 💻 Electronics Category (Sorted by Price) ---');
    const electronics = await Product.findByCategory('Electronics');
    console.log(electronics.map(p => `${p.name} ($${p.price})`).join('\n'));
    // Output: (List of electronic products, highest price first)

    // Example 3: Using getAveragePriceByCategory() (Async)
    console.log('\n--- 💰 Average Price ---');
    const avgPrice = await Product.getAveragePriceByCategory('Books');
    if (avgPrice !== null) {
        console.log(`The average price for Books is $${avgPrice.toFixed(2)}.`);
    } else {
        console.log('No books found to calculate average price.');
    }
}

The Relationship Between Static Methods and the Model

Your schema example clearly illustrates two ways to add custom logic to a Mongoose setup: **Instance Methods** and **Static Methods**.

The static methods are being defined inside the statics property of the **Schema Options object** (the second argument to new Schema()).

How the Static Methods are Defined

The Mongoose Schema constructor accepts an optional second argument, which is an object for **Schema Options**. This is where the custom behavior is defined.

  1. The statics Property

    The statics property is a specific option object recognized by Mongoose. Any functions you attach to the statics object are added as methods directly to the compiled Mongoose **Model**.

    In your code:

    JavaScript

    
// ... inside the Schema Options object
statics: {
    // This function will become a method on the Model (e.g., 'Model.findOneByName()')
    findOneByName(name) {
        return this.findOne({ name })
    },
    // This function will become a method on the Model (e.g., 'Model.findByEmail()')
    findByEmail(email) {
        return this.findOne({ email })
    }
}

  2. The Context of this

    Inside a Mongoose static method, the keyword **this** refers to the **Mongoose Model** itself (e.g., if you named your model User, this inside the static method is the User object).

    • For findOneByName(name): It uses return this.findOne({ name }). Since this is the Model, this is equivalent to return Model.findOne({ name }). It's a convenient wrapper around Mongoose's built-in query functions.

1. Role of Static Methods

Static methods are essentially **custom query helpers** or utility functions that operate on the **collection** of documents, not a single one. They are suitable for tasks like:

  • **Custom Searches:** Finding all documents meeting complex criteria (Model.findActiveUsers()).
  • **Aggregation:** Calculating statistics across the entire collection (Model.getAveragePrice()).
  • **Convenience Wrappers:** Simplifying frequent queries, as seen in your example (Model.findOneByName('Alice')).

2. The Distinction: statics vs. methods

Property Method Type this Context When to Use Example Call
statics Static Method The **Mongoose Model** Logic concerning the whole collection (queries, aggregates). User.findOneByName('Bob')
methods Instance Method The **Mongoose Document** Logic concerning a single document's data (formatting, calculation). userDocument.getSummary('full')

3. Why it's inside the statics object

Mongoose uses the separate statics object within the **Schema Options** because it's defining methods on a **Mongoose Schema**, which is then **compiled** into a Model. By putting functions inside the statics object, you are explicitly telling the Mongoose compiler:

***"When you create the final Model, take all these functions and attach them directly to the Model constructor."***

This ensures the functions are available **before** you retrieve or create any document.

How to Use findByEmail Later

You can use the findByEmail static method by calling it directly on the **Mongoose Model** created from your schema. Static methods are available on the Model itself, not on individual documents.

1. Create the Model

First, you must compile your schema (modelSchema) into a Mongoose Model. Let's assume you name the model User:

JavaScript


const mongoose = require('mongoose');
// Assuming modelSchema is your defined schema with the statics method
const modelSchema = new mongoose.Schema({ /* ... your fields ... */ }, {
    statics: {
        findByEmail(email) {
            return this.findOne({ email });
        }
    }
});

// Compile the Model
const User = mongoose.model('User', modelSchema);

module.exports = User;

2. Accessing and Calling findByEmail

Once the Model (User) is created, you access the static method like any other method on the Model object. You need to await the call because findByEmail uses this.findOne(), which returns a promise.

JavaScript


const User = require('./userModel'); // Assuming your Model is exported from a file

async function findUserByEmailAddress(targetEmail) {
    try {
        // Call the static method directly on the Model
        const userDocument = await User.findByEmail(targetEmail);

        if (userDocument) {
            console.log(`✅ User found! Name: ${userDocument.name}, Email: ${userDocument.email}`);
            return userDocument;
        } else {
            console.log(`❌ No user found with email: ${targetEmail}`);
            return null;
        }

    } catch (error) {
        console.error("Error finding user:", error);
    }
}

// Example Calls:
// Note: You must ensure you are connected to MongoDB before running this.
findUserByEmailAddress('alice@example.com');
findUserByEmailAddress('nonexistent@test.com');

Summary of the Call

The custom static method call looks like this:

$$\text{ModelName}.\text{StaticMethodName}(\text{arguments})$$
$$\text{User}.\text{findByEmail}(\text{'some@email.com'})$$
