🧩 1. What Is an Index in MongoDB?

An index is a **data structure** that improves the speed of queries on a collection.

Think of it like an **index in a book** 📚: instead of reading every page, MongoDB can jump directly to where the data is.

  • Without an index → MongoDB must scan every document (COLLSCAN) — **slow** for large collections.
  • With an index → MongoDB jumps directly to matching documents (IXSCAN).

🔢 2. Types of Indexes

Type Purpose Example
Normal (non-unique) Speeds up queries on a field email, createdAt
Unique Ensures no duplicate values for that field _id, email (if you don’t want duplicate users)

⚙️ 3. Defining Indexes in Mongoose Schema

Mongoose lets you define indexes in two ways:

✅ Method 1: Inside Schema Field Definition

JavaScript
import mongoose from "mongoose";
const userSchema = new mongoose.Schema({
  name: {
    type: String,
    index: true, // normal index
  },
  email: {
    type: String,
    unique: true, // unique index
    required: true,
  },
  age: {
    type: Number,
  }
});
const User = mongoose.model("User", userSchema);

🔍 Explanation:

  • index: true → creates a **normal index**.
  • unique: true → creates a **unique index**, ensuring no duplicate values in that field.

✅ Method 2: Using .index() on the Schema

This gives more control and allows **compound indexes** (indexes on multiple fields).

JavaScript
userSchema.index({ name: 1 });          // normal ascending index
userSchema.index({ email: 1 }, { unique: true });  // unique index
userSchema.index({ age: -1, name: 1 }); // compound index

Here:

  • { name: 1 } → **ascending** order
  • { age: -1 } → **descending** order
  • { unique: true } → ensures **uniqueness**

📦 4. How Mongoose Creates Indexes

By default, when you first run your app, Mongoose automatically builds indexes defined in your schema.

When you call:

JavaScript
mongoose.model("User", userSchema);

→ Mongoose runs .ensureIndexes() in the background.

If you don’t want that automatic behavior (useful in production), disable it:

JavaScript
mongoose.connect(MONGO_URI, { autoIndex: false });

Then manually create indexes when needed:

JavaScript
await User.createIndexes(); // or
await User.syncIndexes();   // sync schema indexes with DB

🧠 5. Understanding syncIndexes() vs createIndexes()

Method Description
createIndexes() Creates indexes if not existing
syncIndexes() Drops indexes from MongoDB that aren’t defined in the schema and adds missing ones

Example:

JavaScript
await User.syncIndexes();
console.log("Indexes synced with schema!");

💥 6. Unique Index Example (with Duplicate Error Handling)

Schema:

JavaScript
const userSchema = new mongoose.Schema({
  email: {
    type: String,
    required: true,
    unique: true, // prevents duplicate emails
  },
  name: String,
});
const User = mongoose.model("User", userSchema);

Example:

JavaScript
try {
  await User.create({ name: "Arman", email: "arman@gmail.com" });
  await User.create({ name: "Kamran", email: "arman@gmail.com" }); // duplicate
} catch (err) {
  console.log("❌ Duplicate Error:", err.message);
}

Output:

❌ Duplicate Error: E11000 duplicate key error collection: test.users index: email_1 dup key: { email: "arman@gmail.com" }

🧹 7. How to Remove / Drop Indexes

You can drop indexes using:

JavaScript
await User.collection.dropIndex("email_1");

To check all indexes:

JavaScript
const indexes = await User.collection.indexes();
console.log(indexes);

To drop all indexes:

JavaScript
await User.collection.dropIndexes();

🧭 8. Full Practical Example

indexDemo.js

JavaScript
import mongoose from "mongoose";

await mongoose.connect("mongodb://127.0.0.1:27017/indexDemo");

const userSchema = new mongoose.Schema({
  name: { type: String, index: true },
  email: { type: String, unique: true, required: true },
  age: Number,
});

// compound index: faster query for both name & age
userSchema.index({ name: 1, age: -1 });

const User = mongoose.model("User", userSchema);

// sync indexes with schema
await User.syncIndexes();
console.log("✅ Indexes created:", await User.collection.indexes());

// Insert docs
await User.create({ name: "Arman", email: "arman@gmail.com", age: 25 });

try {
  // duplicate email
  await User.create({ name: "Kamran", email: "arman@gmail.com", age: 30 });
} catch (err) {
  console.error("❌ Duplicate key error:", err.message);
}

// Query using index
const users = await User.find({ name: "Arman" }).explain("executionStats");
console.log("🔍 Query plan:", users.executionStats);

await mongoose.connection.close();

🧩 10. Key Takeaways

Concept Description
index: true Creates a simple index
unique: true Creates a unique index (no duplicates).
.index() Define normal or compound indexes manually
createIndexes() Builds missing indexes
syncIndexes() Makes DB indexes match schema
dropIndex() Removes an index manually
