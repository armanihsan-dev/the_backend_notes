📘 Node.js Buffer Notes

🔧 Common Properties

  • buffer.length – Total number of bytes allocated in the buffer.
  • Buffer.byteLength(string) – Returns byte size of a string (static method).
  • buffer.byteOffset – Offset from start of underlying memory (in views).

🛠️ Common Methods

buffer.toString([encoding], [start], [end])

Converts buffer content into a string.

buffer.write(string, [offset], [length], [encoding])

Writes a string into the buffer at a specific offset.

buffer.slice([start], [end])

Returns a shallow copy (view) of part of the buffer.

buffer.copy(target, targetStart, sourceStart, sourceEnd)

Copies data from one buffer to another.

buffer.equals(otherBuffer)

Returns true if two buffers have the same contents.

buffer.fill(value, [offset], [end], [encoding])

Fills part or all of a buffer with a value.

buffer.readUInt8(offset) / buffer.writeUInt8(value, offset)

Read/write unsigned 8-bit integer at specific byte.

buffer.readInt16LE(offset) / buffer.writeInt16LE(value, offset)

Read/write signed 16-bit integer in little-endian format.

buffer.subarray([start], [end])

Creates a sub-view (not a copy) of the buffer.

buffer.includes(value, [offset], [encoding])

Returns true if the buffer contains the value.

🔁 Byte Swap Methods

  • buffer.swap16() – Swap every 2 bytes (16-bit values).
  • buffer.swap32() – Swap every 4 bytes (32-bit values).
  • buffer.swap64() – Swap every 8 bytes (64-bit values).
