Storing and Serving an ArrayBuffer from Node.js to a Browser

This guide demonstrates how to generate binary data in Node.js, save it to disk, serve it via an HTTP server, and then fetch and decode it correctly on the frontend.

✅ STEP 1: Generate ArrayBuffer in Node.js (Main Memory)

Purpose: To create raw binary data in the server's main memory (RAM).

Code:

const a = new ArrayBuffer(5); // Creates a 5-byte ArrayBuffer
const uint8Array = new Uint8Array(a); // Creates a Uint8Array view of the ArrayBuffer

uint8Array[0] = 0x41; // A (ASCII/UTF-8 hexadecimal representation)
uint8Array[1] = 0x72; // r
uint8Array[2] = 0x6d; // m
uint8Array[3] = 0x61; // a
uint8Array[4] = 0x6e; // n

Explanation:

  • new ArrayBuffer(5): Allocates a contiguous block of 5 bytes in memory. An ArrayBuffer is a generic, fixed-length raw binary data buffer. It's just a raw block of memory; you can't directly manipulate its contents.
  • new Uint8Array(a): Creates a "view" on top of the ArrayBuffer. A Uint8Array treats each byte in the ArrayBuffer as an unsigned 8-bit integer (0-255). This view allows you to read and write individual bytes to the ArrayBuffer.
  • uint8Array[index] = value;: Populates the ArrayBuffer byte by byte with the hexadecimal values corresponding to the ASCII characters 'A', 'r', 'm', 'a', 'n'.

Result: You have successfully created the string "Arman" as raw bytes in the Node.js process's memory.

💾 STEP 2: Save ArrayBuffer to Secondary Memory (Disk)

Purpose: To persist the ArrayBuffer data from volatile RAM to non-volatile disk storage as a binary file.

Code:

import fs from 'fs'; // Import Node.js File System module
const bufferToSave = Buffer.from(uint8Array.buffer); // Convert ArrayBuffer to Node.js Buffer
fs.writeFileSync('arman.bin', bufferToSave);         // Save the Buffer to a file named 'arman.bin'

Explanation:

  • import fs from 'fs';: Imports the built-in Node.js `fs` (File System) module, which provides methods for interacting with the file system.
  • Buffer.from(uint8Array.buffer):
    • uint8Array.buffer: Accesses the underlying ArrayBuffer from which the Uint8Array was created.
    • Buffer.from(...): Converts the JavaScript ArrayBuffer into a Node.js Buffer object. Node.js Buffers are designed to handle raw binary data more efficiently within the Node.js environment and are essential for file I/O operations.
  • fs.writeFileSync('arman.bin', bufferToSave);:
    • writeFileSync: A synchronous method from the `fs` module that writes data to a file.
    • `'arman.bin'`‍: The name of the file to create or overwrite. The `.bin` extension indicates a binary file.
    • bufferToSave: The Node.js Buffer containing the binary data to be written.

Why?: `Buffer.from(arrayBuffer)` is necessary because Node.js's file system operations (like `writeFileSync`) primarily work with Node.js Buffer objects, not directly with browser-like ArrayBuffers. `writeFileSync()` ensures the data is written as raw binary, not as a text file (which might introduce encoding issues).

Result: A file named `arman.bin` will be created in your project directory, containing the raw bytes representing "Arman".

🌐 STEP 3: Send ArrayBuffer to Frontend via HTTP

Purpose: To create a Node.js HTTP server that reads the saved binary file and serves it to a client browser.

Code:

import http from 'http'; // Import Node.js HTTP module
import fs from 'fs';   // Import Node.js File System module

// (Code from Step 1 & 2 for generating and saving the ArrayBuffer, included for completeness)
const a = new ArrayBuffer(5);
const uint8Array = new Uint8Array(a);
uint8Array[0] = 0x41; uint8Array[1] = 0x72; uint8Array[2] = 0x6d; uint8Array[3] = 0x61; uint8Array[4] = 0x6e;
const nodeBuffer = Buffer.from(uint8Array.buffer);
fs.writeFileSync('arman.bin', nodeBuffer);

// Start HTTP server
const server = http.createServer((req, res) => {
  if (req.url === '/binary') { // Check if the request URL is '/binary'
    const fileBuffer = fs.readFileSync('arman.bin'); // Read the binary file from disk

    res.writeHead(200, {
      'Content-Type': 'application/octet-stream', // MIME type for arbitrary binary data
      'Access-Control-Allow-Origin': '*',        // Allow requests from any origin (CORS)
    });

    res.end(fileBuffer); // Send the binary file content as the response body
  } else {
    // Serve a simple HTML page for any other URL
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end(`<h1>Visit <a href="/binary">/binary</a> to download buffer</h1>`);
  }
});

server.listen(3000, () => {
  console.log('Listening on http://localhost:3000'); // Server listens on port 3000
});

Explanation:

  • import http from 'http';: Imports the built-in Node.js `http` module, which provides functionality to create HTTP servers.
  • http.createServer((req, res) => { ... });: Creates an HTTP server instance. The callback function is executed for every incoming HTTP request.
    • req: The request object, containing information about the incoming request (e.g., URL, headers).
    • res: The response object, used to send data back to the client.
  • if (req.url === '/binary'): This condition checks if the client is requesting the `/binary` endpoint.
    • const fileBuffer = fs.readFileSync('arman.bin');: Reads the entire `arman.bin` file from disk synchronously into a Node.js Buffer.
    • res.writeHead(200, { ... });: Sets the HTTP response header:
      • `200`: HTTP status code indicating "OK".
      • `'Content-Type': 'application/octet-stream'`: This crucial header tells the client's browser that the response body is raw binary data (an arbitrary stream of bytes), not text or an image, etc. This is essential for the browser to handle the data correctly.
      • `'Access-Control-Allow-Origin': '*`': This is a Cross-Origin Resource Sharing (CORS) header. It allows requests from any origin (domain) to access this server. This is necessary if your frontend is served from a different domain/port than your Node.js server (e.g., frontend on `localhost:8080` fetching from `localhost:3000`).
    • res.end(fileBuffer);: Sends the `fileBuffer` (the contents of `arman.bin`) as the response body and signals that the response is complete.
  • else { ... }: For any other URL, a simple HTML page with a link to `/binary` is served.
  • server.listen(3000, () => { ... });: Starts the server, making it listen for incoming connections on port 3000.

Result: Your Node.js server will now serve the `arman.bin` file as raw binary data when accessed at `http://localhost:3000/binary`.

🧑‍💻 STEP 4: Frontend Fetches and Decodes ArrayBuffer

Purpose: To fetch the binary data from the Node.js server on the client-side (browser) and correctly decode it back into a human-readable string.

Code:

<script>
fetch('http://localhost:3000/binary') // Make an HTTP GET request to the Node.js server
  .then(res => res.arrayBuffer())     // Parse the response body as an ArrayBuffer
  .then(data => {
    const uint8 = new Uint8Array(data);       // Create a Uint8Array view of the received ArrayBuffer
    const decoder = new TextDecoder();        // Create a TextDecoder instance (defaults to UTF-8)
    const text = decoder.decode(uint8);       // Decode the bytes to a UTF-8 string
    console.log('Text from server:', text);   // Output the decoded text to the console
  });
</script>

Explanation:

  • fetch('http://localhost:3000/binary'): Initiates a `fetch` request to the specified URL. `fetch` is a modern browser API for making network requests.
  • .then(res => res.arrayBuffer()):
    • The first `.then()` block receives the `Response` object (`res`).
    • res.arrayBuffer(): This is a crucial method. It reads the entire response body and returns a Promise that resolves with the content as an ArrayBuffer. This is how the raw binary data sent by the server is received on the frontend.
  • .then(data => { ... }): The second `.then()` block receives the ArrayBuffer (`data`) that was resolved by `res.arrayBuffer()`.
    • const uint8 = new Uint8Array(data);: Just like on the Node.js side, we create a Uint8Array view to interpret the raw bytes within the ArrayBuffer. This allows us to work with individual bytes.
    • const decoder = new TextDecoder();: Instantiates a `TextDecoder` object. By default, it decodes using UTF-8, which is the standard and what we used to encode "Arman" (ASCII characters are a subset of UTF-8). You can specify other encodings if needed (e.g., `new TextDecoder('utf-16')`).
    • const text = decoder.decode(uint8);: The `decode()` method of `TextDecoder` takes a `TypedArray` (like `Uint8Array`) or an `ArrayBufferView` and converts the bytes into a JavaScript string based on the decoder's specified encoding.
    • console.log('Text from server:', text);: Prints the decoded string to the browser's developer console.

Result: The browser will successfully fetch the binary data, interpret it as an ArrayBuffer, and then decode it into the string "Arman", which will be logged to the console.

🔄 Final Recap

Step Purpose Key Tools/Concepts
🧠 In-Memory Hold binary data temporarily in RAM. ArrayBuffer, Uint8Array
💾 To Disk Persist binary data from RAM to a file on secondary storage. Buffer.from() (Node.js Buffer conversion), fs.writeFileSync()
🌐 To Browser Serve the stored binary file over HTTP. http.createServer(), fs.readFileSync(), res.writeHead() (with `Content-Type: application/octet-stream`), res.end()
📥 On Frontend Fetch the binary data from the server and convert it to a string. fetch().then(res => res.arrayBuffer()), Uint8Array, TextDecoder().decode()
