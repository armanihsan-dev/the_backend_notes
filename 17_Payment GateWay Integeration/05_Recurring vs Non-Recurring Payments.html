Recurring vs Non-Recurring Payments

Simple notes to understand payment types, subscriptions, and when to use each.

1. Non-Recurring Payment (One-Time Payment)

A non-recurring payment is a payment that happens only once. After payment, the transaction ends and there is no automatic future charge.

  • User pays one time
  • No renewal or rebilling
  • No stored billing agreement
  • Access or benefit is fixed
Example:
Pay once → Get 100GB storage → Use forever → No more charges

2. Recurring Payment

A recurring payment is a payment that happens automatically on a schedule (monthly, yearly, etc.) until the user cancels.

  • Automatic repeated charges
  • Payment method is stored
  • Continues until cancellation
  • Access depends on time
Example: Pay monthly → Access service → Charged again next month

Example

Netflix monthly plan

The user subscribes to a plan and gets access for a fixed period. Once the plan expires, access ends and the user must renew to continue.

Billing cycle:
Pay → Access → Renew → Access → Renew → Access → ...

Example:
Pay for a monthly plan → Enjoy access for one month → Renew to continue

3. What is a Subscription?

A subscription is a business relationship, not just a payment. It means the user is paying to keep access over time.

  • Usually uses recurring payments
  • Access is time-based
  • Can be cancelled
  • Creates predictable revenue
Important:
Subscription ≠ Payment
Subscription = Ongoing access
Recurring payment = How money is collected

4. Recurring vs Non-Recurring (Comparison)

Feature Non-Recurring Recurring / Subscription
Payment frequency Once Repeated
Automatic billing No Yes
Access type Permanent / fixed Time-based
Cancellation Not applicable User can cancel
Revenue predictability Low High

5. Common Mistake

Do NOT create a subscription if:
  • User pays once
  • Access does NOT expire
  • No future billing is intended

Words like “Pro plan” or “Upgrade” do NOT automatically mean subscription.

6. Final Rule (Remember This)

If access depends on time → use subscription
If access depends on entitlement → use one-time payment
