What Are Discount Codes?

Discount codes (coupon codes, promo codes) are **alphanumeric strings** that customers enter at checkout to receive:

  • Reduced prices
  • Free shipping
  • Special offers
  • Limited-time deals

Why Businesses Use Discount Codes:

Marketing & Sales Goals:

  • Drive Sales: Encourage purchases during slow periods
  • Clear Inventory: Sell old/overstocked items
  • Customer Acquisition: Attract new customers
  • Reward Loyalty: Thank repeat customers
  • Test Pricing: See how price changes affect sales
  • Segment Offers: Target specific customer groups

How to Create Discounts in Lemon Squeezy

Step-by-Step Guide:

1. Access Discount Section:

  • Go to your Lemon Squeezy dashboard
  • Click "Discounts" in the left sidebar
  • Click "Create Discount"

2. Discount Configuration:

A. BASIC SETTINGS:
  • Discount Name: Internal name (you see this)
  • Example: "Summer Sale 2024"
  • Discount Code: What customers enter
  • Tips:
    • Uppercase only
    • No spaces/special chars
    • Memorable: "SUMMER25", "SAVE20"
    • Avoid: "discount", "coupon" (too generic)
  • Discount Amount Type:
    • // text
Percentage: "20% OFF"
Dollar Amount: "$10 OFF"
B. DISCOUNT TYPE OPTIONS:
  1. Percentage Discount:
    • Example: 20% off total
    • Best for: Clearance sales, seasonal promotions
    • Maximum Discount: Set cap if needed
    • Example: "20% off, max $50 discount"
  2. Fixed Amount Discount:
    • Example: $25 off total
    • Best for: High-value items, specific price points
    • Pro Tip: Combine with minimum purchase
  3. Free Shipping:
    • Example: "FREESHIP"
    • Only covers standard shipping
    • Customer still pays for expedited if chosen
C. RESTRICTIONS & RULES:
  • Valid For: 
    ☑ All Products & Subscriptions
☐ Specific Products Only
☐ Specific Variants Only
  • Usage Limits:
    • Total Uses: "Can be used 100 times total"
    • Per Customer: "Each customer can use 1 time"
    • Minimum Purchase: "Order must be at least $50"
    • Maximum Discount: "Max $100 discount per order"
  • Date Restrictions:
    • Start Date/Time
    • End Date/Time
    • Timezone-aware
  • Customer Eligibility: 
    ☑ All Customers
☐ New Customers Only
☐ Existing Customers Only

3. Advanced Discount Types:

A. BUNDLE DISCOUNTS:
  • Buy X, get Y% off
  • Example: "Buy 2 courses, get 25% off total"
B. SUBSCRIPTION DISCOUNTS:
First Payment Only: "50% off first month"
Recurring: "20% off every payment"
Fixed Time: "10% off for 6 months"
C. BULK/QUANTITY DISCOUNTS:
  • Not native in Lemon Squeezy
  • Workaround: Create variant with bulk pricing

Creating Your First Discount: Practical Example

Scenario: "Back to School" Sale
  • Name: Back to School 2024
  • Code: SCHOOL25
  • Type: Percentage (25%)
  • Products: All eligible products
  • Limits:
    • Total uses: 200
    • Per customer: 1 use
    • Minimum: $30
    • Dates: Sep 1 - Sep 30, 2024
    • Customers: All customers

Result: Customers enter "SCHOOL25" to get 25% off orders over $30.

API Method for Creating Discounts:

// Create discount via Lemon Squeezy API
const createDiscount = async () => {
  const response = await fetch('https://api.lemonsqueezy.com/v1/discounts', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.LEMON_API_KEY}`,
      'Content-Type': 'application/vnd.api+json',
      'Accept': 'application/vnd.api+json'
    },
    body: JSON.stringify({
      data: {
        type: 'discounts',
        attributes: {
          name: 'Welcome Discount',
          code: 'WELCOME10',
          amount: 10,
          amount_type: 'percent',
          is_limited_to_products: false,
          is_limited_use: true,
          max_uses: 100,
          duration: 'once',
          starts_at: '2024-12-01T00:00:00.000Z',
          expires_at: '2024-12-31T23:59:59.000Z'
        }
      }
    })
  });
  
  const data = await response.json();
  return data;
};
