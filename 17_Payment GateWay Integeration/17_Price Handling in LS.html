Lemon Squeezy Money Handling Guide

1️⃣ Clear definition (no fluff)

Lemon Squeezy stores all money values in the smallest currency unit.

For USD, that unit is cents.

1 USD = 100 cents

So:

  • $1.00 $\rightarrow$ 100
  • $9.99 $\rightarrow$ 999
  • $25.00 $\rightarrow$ 2500

This is intentional, not a bug.

2️⃣ Why Lemon Squeezy (and Stripe) use cents

Because floating-point numbers are dangerous for money.

Example:

0.1 + 0.2 === 0.3 // ❌ false

Money must be:

  • exact
  • predictable
  • consistent across systems

Using integers (cents) guarantees this.

👉 Rule: Never store or calculate money using floats.

3️⃣ Where devs get confused (very common mistakes)

❌ Mistake 1: Sending dollars instead of cents 

amount = 9.99 // ❌ WRONG

Lemon Squeezy will interpret this as:

$0.09

❌ Mistake 2: Converting twice

amount = 999 * 100 // ❌ WRONG

Result:

$999.00 instead of $9.99

❌ Mistake 3: Trusting frontend values 

// frontend
price = 9.99

Never trust this. Frontend can be edited.

4️⃣ Correct mental model (lock this in)

Think like this:

  • Frontend shows dollars.
  • Backend stores and sends cents.
  • Lemon Squeezy decides the final amount.

5️⃣ Proper conversion rules (memorize this)

Dollar $\rightarrow$ Cents (Backend only)

const dollars = 9.99;
const cents = Math.round(dollars * 100); // 999
  • ✔ Always use Math.round
  • ✔ Never use parseInt
  • ✔ Never do this on frontend

Cents $\rightarrow$ Dollars (for display only)

const cents = 999;
const dollars = (cents / 100).toFixed(2); // "9.99"
  • ✔ Display only
  • ❌ Never send back to payment APIs

6️⃣ Lemon Squeezy real example (checkout flow)

Product price in Lemon Squeezy dashboard

You set:

$9.99

Internally Lemon Squeezy stores:

999

Backend creates checkout

await lemonSqueezy.createCheckout({
  variant_id: 123456, // price already locked
})

⚠️ Notice:

  • You do NOT send amount
  • Lemon Squeezy already knows the cents value
  • Price cannot be overridden

7️⃣ Webhook example (important)

When payment succeeds, Lemon Squeezy sends:

{
  "total": 999,
  "currency": "USD"
}

You should store:

amount_paid_cents = 999;
currency = "USD";

For UI:

$9.99

8️⃣ Golden rules (print-worthy)

  • 🟢 Always store money as integer cents
  • 🟢 Convert dollars $\rightarrow$ cents once
  • 🟢 Never calculate price on frontend
  • 🟢 Never trust client values
  • 🟢 Lemon Squeezy owns the final amount

9️⃣ One-line explanation (interview-ready)

Lemon Squeezy stores amounts in cents to avoid floating-point errors. Prices are defined server-side, converted once if needed, and never trusted from the frontend.
