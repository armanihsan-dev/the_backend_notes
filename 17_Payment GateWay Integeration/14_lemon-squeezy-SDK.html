Lemon Squeezy SDK

Complete documentation for Node.js & JavaScript integration.

Initial Setup

First, you need to set up the SDK with your API key.

config.js 
import { lemonSqueezySetup } from '@lemonsqueezy/lemonsqueezy.js';

// Initialize the SDK
const config = lemonSqueezySetup({
    apiKey: 'your-api-key-here',
    onError: (error) => {
        console.error('Lemon Squeezy Error:', error);
    }
});

console.log('SDK initialized successfully');

Under the Hood

High-level summary: lemonSqueezySetup() stores your API key in a shared internal client, and every SDK function automatically uses that client.

How it works internally

It does not call the API immediately. It simply stores the config in memory.

internal-logic.js (Pseudo Code) 
// PSEUDO CODE (simplified)
let INTERNAL_CONFIG = {
  apiKey: null,
  onError: null,
};

// When you call lemonSqueezySetup:
INTERNAL_CONFIG.apiKey = apiKey;
INTERNAL_CONFIG.onError = onError;

// The request helper uses this implicitly:
function request(url, options) {
    return fetch("https://api.lemonsqueezy.com" + url, {
        ...options,
        headers: {
            "Authorization": `Bearer ${INTERNAL_CONFIG.apiKey}`,
        },
    });
}

A Note on Pricing

Lemon Squeezy stores prices in minor currency units (integers).

  • 1 USD = 100 cents.
  • $2.99 = 299
  • $699.00 = 69900

Why? To avoid floating point rounding errors (e.g., 0.1 + 0.2 ≠ 0.3). Always convert before displaying:

utils.js 
function formatPrice(cents) {
  return (cents / 100).toFixed(2);
}

const priceUSD = formatPrice(69900);
console.log(`$${priceUSD}`); // $699.00

        const subscription = await getSubscription(subscriptionId, {
            include: ['customer', 'order', 'product', 'variant']
        });
        console.log(subscription.data.data.attributes);
        return subscription
    } catch (error) {
        console.error('SDK Error:', error.message);
    }

// Cancel
async function cancelSubscriptionSDK(subscriptionId) {
  try {
    const subscription = await updateSubscription(subscriptionId, {
      cancelled: true
    });
    
    return subscription.data;
  } catch (error) {
    console.error('SDK Error:', error.message);
  }
}

License Key Functions

A License Key in Lemon Squeezy is a unique code that proves someone has legally purchased and is allowed to use a software product.

A License Key proves ownership of software.

The License Timeline

Imagine you sell a software app (desktop, CLI, downloadable tool).

Without license keys:

  • Anyone can copy the app
  • Share it with others
  • Use it without paying

You need a way to answer this question:

“Has this user actually paid for this software?”

A license key is the answer.

When is a license key generated? (very important)

A license key is generated automatically by Lemon Squeezy after a successful purchase.

Timeline

  1. Customer clicks Buy
  2. Payment succeeds
  3. Order is created
  4. LICENSE KEY IS GENERATED ✅

⚠️ No payment → no license key

You do NOT generate it yourself.

Only generated if you ENABLE it

A license key is generated only if:

Variant setting → "Has license keys" = true

If this is OFF:

  • No license key
  • Even if payment succeeds

What the customer gets

After purchase, customer receives:

  • Confirmation email
  • License key (example):
LS-8F29-A9QK-7Z3M

This key represents:

“I own this software”

When SHOULD you use license keys?

Use license keys if:

  • You sell software downloads
  • Your app runs outside your server
  • You want offline or device-based access control

Do NOT use them if:

  • You only have a web app with login
  • You control everything via server authentication

Note: You do not generate these manually via API usually; they are auto-generated upon purchase.

license-keys.js 
import { listLicenseKeys } from '@lemonsqueezy/lemonsqueezy.js';

async function getAllLicenseKeys() {
    const response = await listLicenseKeys({
        filter: { status: 'active' },
        include: ['customer', 'product']
    });
    
    response.data.data.forEach(license => {
        console.log(`Key: ${license.attributes.key_short}`);
        console.log(`Activations: ${license.attributes.instances_count}`);
    });
}

License Activation

Used inside your software to validate if a key is valid.

activation.js 
import { activateLicense, validateLicense } from '@lemonsqueezy/lemonsqueezy.js';

// 1. Activate (on user's machine)
async function activate() {
    const response = await activateLicense('LS-XXXX-XXXX', 'User Device Name');
    console.log('Activated:', response.data.activated);
}

// 2. Validate (on startup)
async function validate() {
    const response = await validateLicense('LS-XXXX-XXXX');
    console.log('Is Valid:', response.data.valid);
}
