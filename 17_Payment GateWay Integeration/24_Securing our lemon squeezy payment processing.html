Payment System Security

Critical security review for Lemon Squeezy integration. This document covers signature verification, replay protection, and infrastructure hardening.

1. Webhook Signature Verification

The Risk (Before) Your webhook endpoint POST /WH_orderCreated was public. Anyone could send fake order data to trigger credits without paying.

The Fix: HMAC SHA256

We implemented cryptographic verification using the secret only known to your server and Lemon Squeezy. 

const hmac = crypto.createHmac('sha256', secret);
const digest = hmac.update(req.body).digest('hex');

// Safe comparison
crypto.timingSafeEqual(sigBuffer, digestBuffer);

Why this is secure: Any body tampering breaks the signature. The secret key is never transmitted.

2. Raw Body Handling

❌ Vulnerable (Before)

Using express.json() globally. This mutates the request body (whitespace, formatting) before verification, making signatures unreliable.

✅ Secure (After)

Using express.raw({type: 'application/json'}) specifically for the webhook route. 

// Correct usage in route
app.use('/webhook', express.raw({ type: 'application/json' }), securityMiddleware);

Why: The signature must be computed on the exact bytes sent by Lemon Squeezy.

3. Replay Attack Protection

The Scenario An attacker captures a valid webhook request and resends it 100 times. Without protection, your server processes 100 orders and sends 100 emails/credits.

The Fix: Idempotency Keys

We track processed events using a unique key composition:

const eventKey = `lemon:${meta.event_name}:${data.id}`;

if (hasProcessed(eventKey)) {
    return res.status(200).json({ status: 'ignored' });
}
markProcessed(eventKey);

Why: Ensures each financial event is processed exactly once.

4. Stale Webhook Protection

Prevents an attacker from replaying a valid webhook captured days ago (Time-based attack). 

const eventTime = new Date(data.attributes.created_at).getTime();
// Reject if older than 5 minutes
if (Date.now() - eventTime > 5 * 60 * 1000) {
    return res.status(200);
}

5. Timing Attack Prevention

Standard string comparison (===) leaks how many characters matched before failing, allowing attackers to guess the signature byte-by-byte.

The Fix: Constant Time Comparison

// Always takes the same amount of time, regardless of match result
crypto.timingSafeEqual(sigBuffer, digestBuffer)

6. Rate Limiting & Proxy Trust

Webhook Specific Limiting

Protecting the webhook endpoint from DoS attacks while allowing legitimate retries. 

rateLimit({
  windowMs: 15 * 60 * 1000,
  limit: 3 // Strict limit for webhooks
})

Trust Proxy

Crucial for correct IP detection in cloud environments (Heroku, Vercel, AWS). 

app.set('trust proxy', 1); // Fixes IP detection

7 & 8. Logic Abuse Prevention

XSS Prevention - frontend (React)

Before: dangerouslySetInnerHTML with raw data.

Fix: Sanitize description HTML.

Product Whitelist

Fix: Validate against allowed set.

2. security/paymentSecurity.js (Middleware)

import crypto from 'node:crypto';
import redisClient from './../config/redis.js';


const FUTURE_SKEW_MS = 2 * 60 * 1000;//2 min
const STALE_WINDOW_MS = 5 * 60 * 1000; // 5 minutes
const REPLAY_TTL_SECONDS = 10 * 60;   // 10 minutes


export async function hasProcessed(redisKey) {
    const existingDocument = await redisClient.get(redisKey)
    return existingDocument ? true : false
}

export async function markProcessed(redisKey) {
    await redisClient.setEx(redisKey, REPLAY_TTL_SECONDS, '1')
}

const verifyWebhookSignature = async (req, res, next) => {
    try {
        const signature = req.headers['x-signature'];
        const secret = process.env.LEMONSQUEEZY_WEBHOOK_SECRET;

        if (!signature) {
            return res.status(401).json({ error: 'No signature' });
        }

        //Timing-safe signature verification

        const hmac = crypto.createHmac('sha256', secret);
        const digest = hmac.update(req.body).digest('hex');

        const sigBuffer = Buffer.from(signature, 'hex');
        const digestBuffer = Buffer.from(digest, 'hex');

        if (
            sigBuffer.length !== digestBuffer.length ||
            !crypto.timingSafeEqual(sigBuffer, digestBuffer)
        ) {
            return res.status(401).json({ error: 'Invalid signature' });
        }

        //Parse payload(ONLY after verification)
        const payload = JSON.parse(req.body.toString());
        req.parsedBody = payload;

        const { meta, data } = payload;
        const createdAt = data?.attributes?.created_at;
        //Stale-event protection
        const eventTime = new Date(createdAt).getTime();
        const now = Date.now();

        if (eventTime - now > FUTURE_SKEW_MS) {
            return res.status(400).json({ status: 'ignored', reason: 'future' });
        }

        if (now - eventTime > STALE_WINDOW_MS) {
            return res.status(200).json({ status: 'ignored', reason: 'stale' });
        }

        //replay attack prevention
        if (!createdAt) {
            return res.status(400).json({ error: 'Missing created_at' });
        }

        const redisKey = `lemon:${meta.event_name}:${data.id}`;
        const checkIsProcessed = await hasProcessed(redisKey)
        if (checkIsProcessed) {
            return res.status(200).json({ status: 'ignored', reason: 'replay' });
        }
        markProcessed(redisKey);
        next();
    } catch (err) {
        console.error('❌ Webhook verification error:', err);
        return res.status(500).json({ error: 'Webhook verification failed' });
    }
};

export { verifyWebhookSignature };
