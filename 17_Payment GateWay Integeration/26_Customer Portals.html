Customer Portals

A complete guide to implementing Lemon Squeezy-hosted billing portals. Enable customers to manage subscriptions, update payment methods, and view invoices without building billing UI.

1. Understanding Customer Portals

Concept The Customer Portal is a Lemon Squeezy-hosted billing portal that lets your customers manage their subscriptions without you needing to build anything.

Think of it as: "Stripe Customer Portal" but for Lemon Squeezy

Key Features Customers Get

  • View Subscriptions: See all active and past subscriptions.
  • Payment Methods: Update/Add/Remove credit cards.
  • Digital Assets: Download purchased products and license keys.
  • Invoices: View billing history and download PDF invoices.
  • Management: Upgrade/Downgrade, Pause/Resume, or Cancel plans.
  • Details: Update billing address and Tax IDs.

Three Ways to Access

1. Store-Specific Portal

https://[STORE].lemonsqueezy.com/billing

  • Shows only purchases from YOUR store.
  • Requires magic link sign-in.
  • Customizable appearance.

2. My Orders (Global)

https://app.lemonsqueezy.com/my-orders

  • Shows ALL purchases from ALL Lemon Squeezy stores.
  • Customer logs in with email + magic link
  • Global customer account.

3. Signed Portal URLs (Best for Developers)

Automatically authenticates customers. Allows one-click access from your app directly into the portal.

3. Getting Customer Portal URLs

The correct way to generate links that auto-login your users.

Method 1: From Subscription Object (Recommended)

// Get portal URL for a specific subscription
export async function getSubscriptionPortalUrl(subscriptionId) {
    try {
        const subscription = await getSubscription(subscriptionId, {
            include: ['customer'] // Include customer data
        });

        // The portal URL is in attributes.urls.customer_portal
        // Note: Use 'urls.customer_portal' in standard API response
        const portalUrl = subscription.data.data.attributes.urls.customer_portal;

        // This is a SIGNED URL that auto-authenticates the customer
        // Format: https://app.lemonsqueezy.com/billing?auth_token=xxxx

        return {
            portalUrl,
            subscription: subscription.data.data.attributes,
            customer: subscription.data.included?.find(item => item.type === 'customers')
        };
    } catch (error) {
        console.error('Error fetching subscription portal URL:', error);
        throw error;
    }
}

// Usage example
const portalData = await getSubscriptionPortalUrl('sub_12345');
console.log('Signed portal URL:', portalData.portalUrl);

4. Backend Implementation (Node.js)

Complete Portal Service

// backend/services/portalService.js
import LemonSqueezy from '@lemonsqueezy/lemonsqueezy.js';

class PortalService {
  constructor() {
    this.ls = new LemonSqueezy(process.env.LEMON_SQUEEZY_API_KEY);
    this.storeId = process.env.LEMON_STORE_ID;
  }
  
  /**
   * Get signed portal URL for a user
   */
  async getUserPortal(userId, userEmail) {
    try {
      // 1. Find customer in Lemon Squeezy by email
      const customers = await this.listCustomers({
        filter: { email: userEmail, storeId: this.storeId }
      });
      
      let customer;
      let portalUrl;
      
      if (customers.data.length > 0) {
        // Existing customer - use their signed portal URL
        customer = customers.data[0];
        portalUrl = customer.attributes.urls.customer_portal;
      } else {
        // New customer (no Lemon Squeezy record yet)
        portalUrl = `https://${process.env.LEMON_STORE_SUBDOMAIN}.lemonsqueezy.com/billing`;
      }
      
      // 2. Get user's subscriptions
      const subscriptions = await this.getUserSubscriptions(userEmail);
      
      // 3. Create audit log
      await this.logPortalAccess(userId, portalUrl);
      
      return {
        success: true,
        data: {
          portalUrl,
          customer: customer?.attributes || null,
          subscriptions,
          timestamp: new Date().toISOString()
        }
      };
      
    } catch (error) {
      console.error('Portal service error:', error);
      throw new Error(`Failed to get portal URL: ${error.message}`);
    }
  }
  
  /**
   * Get subscription-specific portal URL
   */
  async getSubscriptionPortal(subscriptionId) {
    try {
      const subscription = await this.getSubscription(subscriptionId, {
        include: ['customer', 'product', 'variant']
      });
      
      const portalUrl = subscription.data.attributes.urls.customer_portal;
      
      return {
        success: true,
        data: {
          portalUrl,
          subscription: {
            id: subscription.data.id,
            status: subscription.data.attributes.status,
            renewsAt: subscription.data.attributes.renews_at,
            price: subscription.data.attributes.price
          }
        }
      };
      
    } catch (error) {
      console.error('Subscription portal error:', error);
      throw error;
    }
  }
}

export default new PortalService();

Express API Routes

// backend/routes/portalRoutes.js
import express from 'express';
import PortalService from '../services/portalService.js';
import { authenticate } from '../middleware/auth.js';

const router = express.Router();

// Get user's portal URL
router.get('/portal', authenticate, async (req, res) => {
  try {
    const userId = req.user.id;
    const userEmail = req.user.email;
    
    const portalData = await PortalService.getUserPortal(userId, userEmail);
    res.json(portalData);
  } catch (error) {
    res.status(500).json({ error: true, message: error.message });
  }
});

// Get subscription-specific portal
router.get('/portal/subscription/:subscriptionId', authenticate, async (req, res) => {
  try {
    const { subscriptionId } = req.params;
    const userId = req.user.id;
    
    // Verify user owns this subscription
    const userOwnsSubscription = await verifySubscriptionOwnership(userId, subscriptionId);
    
    if (!userOwnsSubscription) {
      return res.status(403).json({ message: 'Access denied' });
    }
    
    const portalData = await PortalService.getSubscriptionPortal(subscriptionId);
    res.json(portalData);
  } catch (error) {
    res.status(500).json({ error: true, message: error.message });
  }
});

export default router;

Webhook Handler

Handle events triggered by user actions inside the Customer Portal.

// backend/webhooks/lemonWebhooks.js
import express from 'express';
import crypto from 'crypto';

const router = express.Router();

// Verify webhook signature
const verifyWebhook = (req, res, next) => {
  const signature = req.headers['x-signature'];
  const secret = process.env.LEMON_WEBHOOK_SECRET;
  
  // Create HMAC using raw body
  const hmac = crypto.createHmac('sha256', secret);
  const digest = hmac.update(JSON.stringify(req.body)).digest('hex');
  
  if (signature !== digest) return res.status(401).send('Invalid signature');
  next();
};

router.post('/webhook/lemon', verifyWebhook, async (req, res) => {
  const event = req.body;
  const eventName = event.meta.event_name;
  const data = event.data;
  
  try {
    switch (eventName) {
      case 'subscription_updated':
        // Handle upgrades/downgrades
        await handleSubscriptionUpdate(data);
        break;
        
      case 'subscription_cancelled':
        // Handle cancellation
        await handleSubscriptionCancellation(data);
        break;
        
      case 'subscription_payment_method_updated':
        // Log update
        console.log('Payment method updated:', data.id);
        break;
    }
    res.status(200).send('Webhook processed');
  } catch (error) {
    res.status(500).send('Error');
  }
});

export default router;

Portal Hook

// frontend/hooks/useCustomerPortal.js
import { useState, useCallback } from 'react';
import { useAuth } from './useAuth';

export const useCustomerPortal = () => {
  const { token } = useAuth();
  const [loading, setLoading] = useState(false);

  const openPortal = useCallback(async (subscriptionId = null) => {
    setLoading(true);
    try {
      let endpoint = subscriptionId 
        ? `/api/portal/subscription/${subscriptionId}` 
        : '/api/portal';
        
      const response = await fetch(endpoint, {
        headers: { Authorization: `Bearer ${token}` }
      });
      
      const data = await response.json();
      
      // Open portal in new window
      const portalWindow = window.open(
        data.data.portalUrl,
        'lemon_squeezy_portal',
        'width=800,height=700,resizable=yes,scrollbars=yes'
      );
      
      // Listen for closure to refresh data
      const checkClosed = setInterval(() => {
        if (portalWindow.closed) {
          clearInterval(checkClosed);
          // Trigger data refresh in your app
          window.dispatchEvent(new Event('subscriptionsUpdated'));
        }
      }, 1000);
      
    } catch (err) {
      console.error('Portal error:', err);
      // Fallback
      window.open(`https://${process.env.STORE_URL}/billing`, '_blank');
    } finally {
      setLoading(false);
    }
  }, [token]);

  return { openPortal, loading };
};

6. Best Practices & Security

1. Always Verify Subscription Ownership

Security Critical Before generating a portal URL via getSubscriptionPortalUrl, you MUST verify the current logged-in user actually owns that subscription ID. 
async function verifyOwnership(userId, subscriptionId) {
  // Method 1: Check your local database
  const ownership = await db.subscriptions.findOne({
    userId: userId,
    lemonSubscriptionId: subscriptionId
  });
  
  if (ownership) return true;

  // Method 2: Fallback to checking email match via API
  const sub = await lemonSqueezy.getSubscription(subscriptionId, { include: ['customer'] });
  const customerEmail = sub.included.find(i => i.type === 'customers').attributes.email;
  const user = await db.users.findById(userId);
  
  return user.email === customerEmail;
}

2. "Test Mode" Reality Check

Important: Test Mode Limitations

The Customer Portal DOES NOT work in Test Mode.

If you try to open a portal URL for a test mode subscription, you will often see a 404 or a "Store not found" error. This is by design.

What Works vs What Doesn't

✅ Works in Test Mode

  • API requests
  • Creating products
  • Test payments (4242 card)
  • Webhooks

❌ Does NOT Work

  • Customer Portal
  • Customer-facing invoice pages
  • Update payment method pages

Why? The portal exposes legal billing info and allows financial actions. Lemon Squeezy only enables this for activated stores with live payments and payout setups complete.
