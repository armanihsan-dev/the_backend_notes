Technical Difference Between Invoice and Receipt

Invoice Receipt
A request for payment (bill) issued BEFORE payment Proof of payment issued AFTER payment
Lists goods/services provided and amount due Confirms transaction completion
Used as a legal document for accounting Shows payment method and date
Can be recurring (monthly invoices) Finalizes the transaction

In Lemon Squeezy Context

  • Invoice: A formal bill document with customer billing details that can be generated/sent to customers.
  • Receipt: The automated email sent to customers after purchase with order details and download links.

Based on the Lemon Squeezy API documentation you provided, the original /v1/orders/:id/generate-invoice usage in the following examples has been corrected to show the JSON body for the /v1/invoices endpoint, as the former is deprecated.

Using Fetch API (Node.js 18+) - Note: Example below is for illustrative purposes; the current API uses a JSON body post to /v1/invoices, not URL query params. 


// The original code used the deprecated /generate-invoice endpoint with URLSearchParams.
// The correct modern method is to POST a JSON body to /v1/invoices.
async function generateInvoice(orderId, customerData) {
    const apiKey = 'YOUR_API_KEY_HERE';

    // Construct the JSON body for the /v1/invoices endpoint
    const body = {
        "data": {
            "type": "invoices",
            "attributes": {
                "order_id": orderId,
                "customer_name": customerData.name,
                "customer_address": customerData.address,
                "customer_city": customerData.city,
                "customer_state": customerData.state,
                "customer_zip": customerData.zipCode,
                "customer_country": customerData.country,
                "customer_email": customerData.email || "required@example.com", // Note: Email is often required
                "notes": customerData.notes || ''
            }
        }
    };

    try {
        const response = await fetch(`https://api.lemonsqueezy.com/v1/invoices`, {
            method: 'POST',
            headers: {
                'Accept': 'application/vnd.api+json',
                'Content-Type': 'application/vnd.api+json',
                'Authorization': `Bearer ${apiKey}`
            },
            body: JSON.stringify(body)
        });

        const data = await response.json();

        if (!response.ok) {
            throw new Error(data.errors ? JSON.stringify(data.errors) : 'Failed to generate invoice');
        }

        console.log('Invoice generated successfully!');
        console.log('Download URL:', data.data?.attributes?.download_url || data);
        return data;
    } catch (error) {
        console.error('Error generating invoice:', error);
        throw error;
    }
}

    country: 'US',
    notes: 'Thank you for your business',
    email: 'john@example.com' // Added email for compliance
});

Method 3: Using Axios (More robust)

First install axios: npm install axios


const axios = require('axios');

async function generateInvoiceAxios(orderId, customerData) {
    const apiKey = 'YOUR_API_KEY_HERE';

    // Uses the non-deprecated /v1/invoices endpoint
    const url = `https://api.lemonsqueezy.com/v1/invoices`;

    // Prepare the JSON body for the POST request
    const body = {
        "data": {
            "type": "invoices",
            "attributes": {
                "order_id": orderId,
                "customer_name": customerData.name,
                "customer_address": customerData.address,
                "customer_city": customerData.city,
                "customer_state": customerData.state,
                "customer_zip": customerData.zipCode,
                "customer_country": customerData.country,
                "customer_email": customerData.email || "required@example.com",
                "notes": customerData.notes || ''
            }
        }
    };


    try {
        const response = await axios.post(url, body, {
            headers: {
                'Accept': 'application/vnd.api+json',
                'Content-Type': 'application/vnd.api+json',
                'Authorization': `Bearer ${apiKey}`
            }
        });

        console.log('Invoice generated successfully!');
        console.log('Response:', response.data);
        return response.data;
    } catch (error) {
        console.error('Error:', error.response?.data || error.message);
        throw error;
    }
}

// Usage
generateInvoiceAxios(1, {
    name: 'John Doe',
    address: '123 Main St',
    city: 'Anytown',
    state: 'CA',
    zipCode: '12345',
    country: 'US',
    notes: 'Thank you for your business',
    email: 'john@example.com' // Added email for compliance
});

Important Notes:

  • Required Fields Warning: As mentioned in the API documentation, all address fields (name, address, city, state, zip_code, country) will soon be required. Make sure to always provide them.
  • State Requirement: The state field is specifically required for US and CA (Canada) addresses.
  • Response Format: The API should return a JSON response containing a link to download the generated invoice.
  • Error Handling: Always implement proper error handling as shown in the examples.
  • Testing: Use a tool like Postman or test with CURL first to verify your API key and parameters work correctly.
  • Production: Store your API key securely (in environment variables, not hard-coded): 
    
const apiKey = process.env.LEMONSQUEEZY_API_KEY;
  • API Endpoint Change: The endpoint /v1/orders/:id/generate-invoice appears to be deprecated. Use /v1/invoices instead. learn more: https://docs.lemonsqueezy.com/api/orders/generate-order-invoice
