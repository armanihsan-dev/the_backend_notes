The Checkout Object

A comprehensive guide to understanding, creating, and managing secure payment flows.

One-Line Definition

A checkout in Lemon Squeezy is a secure, hosted payment flow where Lemon Squeezy controls pricing, collects payment, and confirms transactions, while the app only initiates and verifies the purchase.

What is it?

Simple Definition

A hosted payment page that:

  • Shows the product & images
  • Calculates final price (tax, currency)
  • Collects payment details securely
  • Processes the transaction
  • Confirms the purchase

Technical Meaning

A server-side object where:

  • You send a variant_id to the API
  • The price is locked on the server
  • ❌ User cannot change amount (DevTools proof)
  • ❌ User cannot fake payment
  • ✅ Only Lemon Squeezy decides the price

Checkout vs. Payment Intent

Feature Lemon Squeezy Checkout

The Full-Stack Flow

1
User clicks "Buy" Frontend requests your backend endpoint (e.g., /api/create-checkout).
2
Backend calls Lemon Squeezy Your server talks to Lemon Squeezy API to generate the link.
3
Redirect User Frontend sends the user to the returned unique Checkout URL.
4
Payment & Webhook Payment succeeds. Lemon Squeezy sends a webhook to your server to unlock the product.

Node.js Implementation

How to create a checkout session securely from your backend. 

async function createCheckout(storeId, variantId) {
  const url = 'https://api.lemonsqueezy.com/v1/checkouts';
  
  const payload = {
    data: {
      type: "checkouts",
      attributes: {
        custom_price: 2500, // Optional dynamic price
        checkout_data: {
          email: "user@example.com"
        }
      },
      relationships: {
        store: { data: { type: "stores", id: storeId } },
        variant: { data: { type: "variants", id: variantId } }
      }
    }
  };

  const response = await fetch(url, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.LS_API_KEY}`,
      'Content-Type': 'application/vnd.api+json'
    },
    body: JSON.stringify(payload)
  });

  const data = await response.json();
  return data.data.attributes.url; // Redirect user to this URL
}
