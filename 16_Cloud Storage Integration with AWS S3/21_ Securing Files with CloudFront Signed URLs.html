CloudFront Signed URLs

CloudFront Signed URLs are a **critical security feature** used to **restrict access to private content** delivered through an Amazon CloudFront distribution. They ensure that only authorized users can view or download your files, typically for a limited time.

This guide will explain what Signed URLs are, the role of public and private keys in their creation, and how to use the @aws-sdk/cloudfront-signer package in Node.js to generate them.

1. What are CloudFront Signed URLs?

Definition

A **CloudFront Signed URL** is a standard URL with three security parameters appended to the end:

  • Expires: The time after which the URL becomes invalid.
  • Key-Pair-Id: The public key ID of the trusted signer (your AWS account) that CloudFront uses to verify the signature.
  • Signature: A hash of the access policy, digitally signed using your **private key**. This signature guarantees the authenticity and integrity of the policy parameters.

How They Work

  • Authorization Check: Your backend application (e.g., Node.js server) verifies if the user is authorized (e.g., they are a paid subscriber or have purchased the content).
  • URL Signing: If authorized, your application generates a unique URL with an expiration time and digitally signs it using your **private key** and the CloudFront signer utility.
  • Client Request: The client (user's browser) attempts to access the resource using the Signed URL.
  • CloudFront Validation: The CloudFront Edge Location inspects the URL, finds the Key-Pair-Id, and uses the corresponding **Public Key** (which you uploaded to CloudFront) to decrypt and validate the Signature.
  • Access Granted/Denied: If the signature is valid and the URL has not expired, CloudFront serves the content. Otherwise, access is denied (HTTP 403 Forbidden).

2. Public and Private Keys

The creation and validation of Signed URLs rely entirely on **Asymmetric Cryptography** (Public-Key Cryptography).

Key Purpose Storage
Private Key **Signs** the URL policy. It is used exclusively by your secure backend application to generate the unique signature. **MUST be kept secret.** Store in a secure vault like AWS Secrets Manager or an environment variable.
Public Key **Verifies** the signature. It is uploaded to CloudFront (via a **Public Key** and **Key Group**) and used by the CDN to confirm that the signature was created by the corresponding private key. Stored publicly within the AWS CloudFront service configuration.

How to Create Keys

You generate the RSA public-private key pair locally using a tool like **OpenSSL**.

Generate the Private Key (private_key.pem): 

        
openssl genrsa -out private_key.pem 2048

This file contains your secret **private key**.

Extract the Public Key (public_key.pem):

        
openssl rsa -pubout -in private_key.pem -out public_key.pem

This file contains the key you will **upload to AWS**.

Configure in AWS:

  • In the CloudFront console, navigate to **Key Management** > **Public Keys**.
  • Create a new public key, paste the content of public_key.pem. Note the generated **Key ID** (e.g., K1D2E3X4Y5Z6).
  • Add this public key to a **Key Group**.
  • In your CloudFront Distribution's **Cache Behavior**, enable **Restrict Viewer Access** and select your created **Key Group** as the **Trusted Signers**.

3. Creating Signed URLs with Node.js SDK

The @aws-sdk/cloudfront-signer package simplifies the signing process in Node.js.

📦 Installation

        
npm install @aws-sdk/cloudfront-signer

⚙️ Key Definitions

The core utility function is getSignedUrl(options).

Option Parameter Type Description
url string The full URL of the content to be signed (e.g., https://d123.cloudfront.net/videos/movie.mp4).
keyPairId string The **Key ID** (K1D2E...) you noted when uploading the public key to CloudFront.
privateKey string The **private key content** loaded directly from your secure storage (the content of private_key.pem).
dateLessThan Date **(Required)** The expiration time for the URL. CloudFront will reject the request if the current time is later than this value.
dateGreaterThan Date *(Optional)* The time when the URL becomes valid (start time).
ipAddress string *(Optional)* A CIDR IP block to restrict access to a specific IP range.

💻 Node.js Example

This example demonstrates how to create a signed URL that expires in 15 minutes. 

        
import { getSignedUrl } from "@aws-sdk/cloudfront-signer";
import * as fs from 'fs';
import * as path from 'path';

// --- Configuration ---

// 1. CloudFront Distribution Domain (e.g., the URL that points to your private content)
const CLOUDFRONT_DOMAIN = "https://d12345abcdefg.cloudfront.net";

// 2. The Key Pair ID (from AWS console after uploading public key)
const CLOUDFRONT_KEYPAIR_ID = "K1D2E3X4Y5Z6";

// 3. Load the private key content (Ensure this is loaded securely in production!)
// NOTE: Use environment variables or Secrets Manager in production, not reading a file.
const PRIVATE_KEY_PATH = path.join(process.cwd(), 'private_key.pem'); 
const PRIVATE_KEY = fs.readFileSync(PRIVATE_KEY_PATH, 'utf8');

// The file path on your distribution you want to grant access to
const RESOURCE_PATH = "/private-content/document-101.pdf"; 
const URL_TO_SIGN = `${CLOUDFRONT_DOMAIN}${RESOURCE_PATH}`;

/**
 * Generates a CloudFront Signed URL with a Canned Policy (expiration time only).
 * @param url The resource URL to sign.
 * @returns The fully signed URL string.
 */
function createSignedUrl(): string {
  // Set the expiration time to 15 minutes from now
  const expiryTime = new Date(Date.now() + 15 * 60 * 1000); 

  try {
    const signedUrl = getSignedUrl({
      url: URL_TO_SIGN,
      keyPairId: CLOUDFRONT_KEYPAIR_ID,
      privateKey: PRIVATE_KEY,
      dateLessThan: expiryTime,
    });

    return signedUrl;

  } catch (error) {
    console.error("Failed to generate Signed URL:", error);
    throw new Error("Signing failed.");
  }
}

// --- Execution ---
const finalSignedUrl = createSignedUrl();

console.log(`Resource URL: ${URL_TO_SIGN}`);
console.log(`Expiration: ${new Date(new Date().getTime() + 15 * 60 * 1000).toLocaleString()}`);
console.log("\n--- GENERATED SIGNED URL ---");
console.log(finalSignedUrl);

// Example of the final URL structure:
// https://d12345abcdefg.cloudfront.net/private-content/document-101.pdf?Expires=1678881600&Key-Pair-Id=K1D2E3X4Y5Z6&Signature=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
