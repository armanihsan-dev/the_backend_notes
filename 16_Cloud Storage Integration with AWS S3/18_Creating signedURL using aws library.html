💻 Generating AWS S3 Presigned URLs in Node.js

You can use the @aws-sdk/s3-request-presigner package along with @aws-sdk/client-s3 to generate presigned URLs for Amazon S3 objects in your Node.js application.

1. What is a Presigned URL?

A Presigned URL is a URL that you can generate using your AWS security credentials to grant temporary access to a specific S3 object.

  • Temporary Access: The URL includes parameters that sign the request and specify an expiration time. After the expiration time, the URL will no longer work.
  • Security: This allows a user who **does not** have AWS security credentials or permissions to access, upload, or download a specific object. The URL is essentially pre-signed with the permissions of the IAM user or role that generated it.

2. Installation

You need both the S3 client and the request presigner package:

Bash 
# Bash
npm install @aws-sdk/client-s3 @aws-sdk/s3-request-presigner

3. Syntax

The core function for generating a presigned URL is getSignedUrl from @aws-sdk/s3-request-presigner.

JavaScript Syntax 
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";
import { S3Client, Command } from "@aws-sdk/client-s3";

// ... Inside an async function ...
const url = await getSignedUrl(
  client: S3Client,
  command: Command, // e.g., GetObjectCommand, PutObjectCommand
  options: { expiresIn: number } // Time in seconds
);

Key Parameters

Parameter Type Description
client S3Client An instance of the S3Client configured with your AWS credentials and region.
command Command The specific AWS SDK S3 Command you want the URL to execute (GetObjectCommand for GET, PutObjectCommand for PUT, etc.).
options { expiresIn: number } An object specifying the URL expiration time in seconds. Defaults to 900 seconds (15 minutes).

4. How It Works

  1. S3 Client Initialization: You create an S3Client instance with your credentials.
  2. Command Creation: You create a Command object (e.g., GetObjectCommand) that specifies the bucket name, object key, and any other S3 parameters.
  3. Signing: The getSignedUrl function takes the command and the S3 client. It uses the client's credentials and region to calculate a **Signature Version 4** signature.
  4. URL Generation: The function then appends the signature, credentials, expiration time, and other required parameters as query string parameters to the S3 object URL.
  5. Temporary Access: The generated URL is returned. Any user who receives this URL can perform the specified action (GET or PUT) on the object for the duration set by expiresIn.

5. Node.js Example

Here is a complete Node.js example for generating both GET (download) and PUT (upload) presigned URLs.

JavaScript Example for GET and PUT 
import { S3Client, GetObjectCommand, PutObjectCommand } from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";

// ⚠️ Replace with your actual values and configure AWS credentials securely ⚠️
const REGION = "us-east-1";
const BUCKET_NAME = "your-unique-bucket-name";
const OBJECT_KEY = "path/to/my-file.txt";
const EXPIRATION_SECONDS = 3600; // 1 hour

// 1. Initialize S3 Client
const s3Client = new S3Client({ region: REGION });

/**
 * Generates a presigned URL for downloading an S3 object (GET request).
 * @param {string} key - The S3 object key (file path).
 * @returns {Promise<string>} The presigned GET URL.
 */
async function generateGetPresignedUrl(key) {
  const command = new GetObjectCommand({
    Bucket: BUCKET_NAME,
    Key: key,
  });

  const signedUrl = await getSignedUrl(s3Client, command, {
    expiresIn: EXPIRATION_SECONDS,
  });

  return signedUrl;
}

/**
 * Generates a presigned URL for uploading an S3 object (PUT request).
 * @param {string} key - The S3 object key (file path).
 * @param {string} contentType - The Content-Type of the file being uploaded (important!).
 * @returns {Promise<string>} The presigned PUT URL.
 */
async function generatePutPresignedUrl(key, contentType) {
  const command = new PutObjectCommand({
    Bucket: BUCKET_NAME,
    Key: key,
    ContentType: contentType, // Critical for client upload
  });

  const signedUrl = await getSignedUrl(s3Client, command, {
    expiresIn: EXPIRATION_SECONDS,
  });

  return signedUrl;
}

async function main() {
  try {
    const downloadUrl = await generateGetPresignedUrl(OBJECT_KEY);
    console.log(`\n✅ Download (GET) Signed URL (Expires in ${EXPIRATION_SECONDS}s):\n${downloadUrl}`);

    const uploadUrl = await generatePutPresignedUrl("uploads/new-image.jpg", "image/jpeg");
    console.log(`\n✅ Upload (PUT) Signed URL (Expires in ${EXPIRATION_SECONDS}s):\n${uploadUrl}`);

    console.log("\nUsage:");
    console.log(`– To download: Use 'curl "${downloadUrl}"'`);
    console.log(`– To upload: Use 'curl -X PUT -H "Content-Type: image/jpeg" --upload-file ./local-file.jpg "${uploadUrl}"'`);
    
  } catch (error) {
    console.error("Error generating presigned URL:", error);
  }
}

main();
