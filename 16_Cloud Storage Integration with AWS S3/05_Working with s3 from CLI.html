💾 AWS S3 CLI Commands Explained

The AWS S3 commands are executed using the structure: aws s3 <operation> [parameters].

1. Bucket Commands (Create & Delete)

These commands are used for managing the S3 containers themselves.

Command Syntax Explanation Example
List all buckets aws s3 ls Lists all S3 buckets owned by your AWS account across all regions. aws s3 ls
Create a bucket aws s3 mb s3://<bucket-name> mb stands for Make Bucket. Creates a new bucket. Bucket names must be globally unique. aws s3 mb s3://my-new-unique-bucket
Delete a bucket aws s3 rb s3://<bucket-name> rb stands for Remove Bucket (fails if not empty). aws s3 rb s3://old-empty-bucket
Delete a bucket forcefully (with all contents) aws s3 rb s3://<bucket-name> --force Use this with caution. It deletes the bucket and all objects within it, regardless of content. aws s3 rb s3://my-data-archive --force

2. Upload and Download (cp)

The cp (copy) command is used for transferring objects (files) between your local machine and S3, and vice-versa.

Command Syntax Explanation Example
Upload a file to bucket aws s3 cp <local-file> s3://<bucket-name>/ Copies a local file into the root of the specified S3 bucket. aws s3 cp notes.txt s3://project-files/
Upload a folder recursively aws s3 cp <local-folder> s3://<bucket-name>/ --recursive Copies the entire local folder structure and its contents to the S3 bucket. The --recursive flag is key for folders. aws s3 cp ./images s3://assets-bucket/ --recursive
Download a file from bucket aws s3 cp s3://<bucket-name>/<file-path> <local-destination> Copies a file from the S3 bucket to your local machine. aws s3 cp s3://reports/Q4.pdf ./data/
Download a folder recursively aws s3 cp s3://<bucket-name>/<folder-name> <local-destination> --recursive Downloads an S3 folder and all its contents, maintaining the folder structure, to your local machine. aws s3 cp s3://backup-data/logs/ ./local-logs --recursive

3. Sync Folders (sync)

The sync command efficiently synchronizes the contents of a source and destination, copying only new or modified files and deleting files that exist in the destination but not the source (if --delete is used).

Command Syntax Explanation Example
Sync local folder with S3 bucket aws s3 sync <local-folder> s3://<bucket-name>/ Compares files in the local folder and the S3 bucket, uploading only the necessary changes to S3. aws s3 sync ./website-code s3://production-site/
Sync S3 bucket with local folder aws s3 sync s3://<bucket-name>/ <local-folder> Downloads changes from S3 to the local folder, ensuring the local copy matches the S3 content. aws s3 sync s3://shared-docs/ ./team-folder

4. List Contents of a Bucket or Folder (ls)

The ls (list) command is used to view the objects (files and folders) inside a bucket.

Command Syntax Explanation Example
List files in a bucket aws s3 ls s3://<bucket-name>/ Lists the objects and common prefixes (folders) at the top level of the specified bucket. aws s3 ls s3://customer-invoices/
List files in a folder inside bucket aws s3 ls s3://<bucket-name>/<folder-name>/ Lists the objects and folders located inside the specified path within the bucket. aws s3 ls s3://media-files/thumbnails/

5. Delete Files and Folders (rm)

The rm (remove) command is used to permanently delete objects from S3.

Command Syntax Explanation Example
Delete a file aws s3 rm s3://<bucket-name>/<file-path> Permanently deletes a single specified object (file) from S3. aws s3 rm s3://temp-storage/scratch.log
Delete all files in a folder aws s3 rm s3://<bucket-name>/<folder-name>/ --recursive Deletes all objects within the specified "folder" (prefix) inside the bucket. aws s3 rm s3://backups/old-logs/ --recursive

6. Move or Rename Files (mv)

The mv (move) command is used to rename a file or move it to a different location within S3.

Command Syntax Explanation Example
Move (rename) a file aws s3 mv s3://<bucket-name>/<old-path> s3://<bucket-name>/<new-path> Copies the object from the source to the destination, then deletes the source object. aws s3 mv s3://docs/draft.docx s3://docs/final.docx
Move entire folder aws s3 mv s3://<bucket-name>/<source-folder>/ s3://<bucket-name>/<destination-folder>/ --recursive Moves all objects from one prefix (folder) to another prefix. aws s3 mv s3://archive/2023/ s3://processed/2023/ --recursive

7. Presigned URLs (presign)

The presign command generates a temporary, time-limited URL that allows anyone who holds the URL to access a specific S3 object, even if they don't have AWS credentials.

Command Syntax Explanation Example
Generate a presigned URL aws s3 presign s3://<bucket-name>/<file-path> Generates a URL with the default expiry time (usually 3600 seconds, or 1 hour). aws s3 presign s3://data/large-report.zip
Set custom expiry aws s3 presign s3://<bucket-name>/<file-path> --expires-in <seconds> Specifies a custom duration (in seconds) for which the generated URL will remain valid. aws s3 presign s3://public/video.mp4 --expires-in 900

8. Advanced Options (Global Flags)

These are options (flags) that can be appended to almost any command to customize the output or authentication context.

Command Syntax Explanation Example
Set output format aws <command> --output <format> Changes the way the CLI displays its results (e.g., json, table, or text). aws s3 ls s3://my-bucket/ --output json
Use a specific profile aws <command> --profile <name> Uses credentials and configuration stored under a specific named profile in your local AWS config files. aws s3 ls --profile dev-account
Set region explicitly aws <command> --region <region-code> Overrides the default region set during configuration, forcing the command to target a specific region (e.g., us-east-1). aws s3 ls --region us-east-1

9. Help for Each Command

The built-in help commands provide immediate, detailed documentation within your terminal.

  • Service-level Help: aws s3 help Shows a full list of all available commands (operations) under the S3 service.
  • Command-level Help: aws s3 <command> help Provides detailed usage, required parameters, and all available options for a specific operation.

💻 AWS CLI Command Breakdown

The command you provided is:

aws s3 cp "F:\Software Data\all_softwares" s3://arman-physical-computer-data/access_softwares/ --recursive

1. Purpose of the Command

The primary purpose of this command is to upload an entire folder structure from your local Windows computer (Drive F:) to a specific location within an Amazon S3 bucket.

  • Goal: To transfer a comprehensive collection of software files and folders (e.g., installers, configurations) from a local storage drive to a highly durable, scalable, and secure cloud storage location (S3).
  • Result: All files and subfolders contained within the local folder F:\Software Data\all_softwares will be replicated under the access_softwares/ path in the S3 bucket named arman-physical-computer-data.

2. Line-by-Line Explanation

Component Meaning Syntax Type Your Example
aws The main program executable. Program Call aws
s3 The AWS service target. Service Name s3 (Amazon Simple Storage Service)
cp The operation to perform. Command/Operation cp (Copy)
"F:\Software Data\all_softwares" The source path. Local Path (Source) This is the local folder on your computer that contains the files to be copied. The quotation marks are essential because the path contains spaces.
s3://arman-physical-computer-data/access_softwares/ The destination path. S3 URI (Destination) s3:// is the required protocol prefix. arman-physical-computer-data is the name of your S3 bucket. access_softwares/ is the prefix (or "folder") within the bucket where the contents will be uploaded.
--recursive A critical flag (option). Flag/Option This instructs the cp command to copy the entire folder structure and all files within it, not just the single folder itself. Without this, the command would fail.

3. How the Process Works

  • Authentication: The aws command first uses the credentials (Access Key ID and Secret Access Key) stored on your local machine (usually in ~/.aws/credentials) to securely authenticate with the AWS API.
  • Request: It sends a request to the S3 service, instructing it to begin a series of upload operations.
  • Recursion: The --recursive flag tells the CLI to walk through the source folder (F:\Software Data\all_softwares) and list every file and subdirectory inside it.
  • Transfer: For every file found (e.g., F:\Software Data\all_softwares\setup.exe), the CLI uploads that file.
  • Path Mapping: The local path is mapped to the S3 destination. For example:
    • Local File: F:\Software Data\all_softwares\Utility\tool.zip
    • S3 Object: s3://arman-physical-computer-data/access_softwares/Utility/tool.zip

In short, this command is your single-line solution for performing a complete, automated backup of a local directory to the cloud.
