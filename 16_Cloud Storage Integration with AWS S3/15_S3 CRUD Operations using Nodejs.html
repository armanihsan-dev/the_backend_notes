🪣 AWS S3 Bucket Commands

These commands manage the S3 buckets themselves, which are the top-level containers for storing objects.

1. ListBucketsCommand

Definition: Retrieves a list of all buckets owned by the authenticated sender of the request.

Syntax:

new ListBucketsCommand(input: ListBucketsCommandInput)

The input object is typically empty ({}) since this command operates on the account level, not a specific bucket.

Practical Example & How It Works:

import { S3Client, ListBucketsCommand } from '@aws-sdk/client-s3';
const s3Client = new S3Client();
const command = new ListBucketsCommand({}); // No parameters needed
const response = await s3Client.send(command);
console.log(response.Buckets); // Logs an array of bucket objects: [{ Name: '...', CreationDate: '...' }, ...]

How it Works: The client sends the command to the S3 service. S3 responds with a list of buckets, which is stored in the response.Buckets array.

2. CreateBucketCommand

Definition: Creates a new S3 bucket in a specified AWS Region. Bucket names must be globally unique.

Syntax:

new CreateBucketCommand(input: CreateBucketCommandInput)

The required input is the Bucket name. You can also specify the bucket's region (e.g., CreateBucketConfiguration).

Practical Example & How It Works:

import { S3Client, CreateBucketCommand } from '@aws-sdk/client-s3';
const s3Client = new S3Client();
const command = new CreateBucketCommand({
  Bucket: 'procodrr-nodejs-bucket', // The unique name for the new bucket
});
await s3Client.send(command); // The command is executed
console.log('Bucket created');

How it Works: The command instructs S3 to provision a new bucket with the provided name. If the name is taken or invalid, the request will fail with an error.

3. Unblock Public Access (Managing Public Access Block)

This section covers two methods for removing or modifying the Public Access Block configuration, which is a security feature that prevents a bucket from becoming publicly accessible.

A. DeletePublicAccessBlockCommand (Unblock Public Access)

Definition: Deletes the existing public access block configuration for a specific bucket, effectively resetting it to its default (unblocked) state, which allows you to make the bucket or objects public via other means (ACLs or policies).

Syntax:

new DeletePublicAccessBlockCommand(input: DeletePublicAccessBlockCommandInput)

Practical Example & How It Works:

import { S3Client, DeletePublicAccessBlockCommand } from '@aws-sdk/client-s3';
// ...
const command = new DeletePublicAccessBlockCommand({
  Bucket: 'procodrr-nodejs-bucket', // The target bucket
});
await s3Client.send(command);
console.log('✅ Public access block configuration deleted.');

How it Works: This command removes the overarching Public Access Block settings that AWS applies by default for security, permitting subsequent actions (like setting a public bucket policy) to take effect.

B. PutPublicAccessBlockCommand (Explicitly Set to Unblock)

Definition: Explicitly sets the public access block configuration for a bucket. Setting all boolean values to false is the most restrictive form of "unblocking."

Syntax:

new PutPublicAccessBlockCommand(input: PutPublicAccessBlockCommandInput)

Practical Example & How It Works:

import { S3Client, PutPublicAccessBlockCommand } from '@aws-sdk/client-s3';
// ...
const command = new PutPublicAccessBlockCommand({
  Bucket: 'procodrr-nodejs-bucket',
  PublicAccessBlockConfiguration: {
    BlockPublicAcls: false, // Allows public ACLs
    IgnorePublicAcls: false, // Does not ignore public ACLs
    BlockPublicPolicy: false, // Allows public bucket policies
    RestrictPublicBuckets: false, // Does not restrict access to only S3 policies
  },
});
await s3Client.send(command);
console.log('Unblocked public access');

How it Works: This explicitly configures S3 to not block public access, ensuring that policies or ACLs that grant public access will be enforced.

4. PutBucketPolicyCommand (Make Bucket Public)

Definition: Applies an AWS Identity and Access Management (IAM) policy to a specified bucket. This policy defines who can access the objects in the bucket and what actions they can perform.

Syntax:

new PutBucketPolicyCommand(input: PutBucketPolicyCommandInput)

Requires Bucket and a Policy string (JSON).

Practical Example & How It Works:

import { S3Client, PutBucketPolicyCommand } from '@aws-sdk/client-s3';
// ...
const policy = {
  Version: '2012-10-17',
  Statement: [
    {
      Sid: 'PublicReadGetObject',
      Effect: 'Allow',
      Principal: '*',
      Action: 's3:GetObject',
      Resource: 'arn:aws:s3:::procodrr-nodejs-bucket/*',
    },
  ],
};
const command = new PutBucketPolicyCommand({
  Bucket: 'procodrr-nodejs-bucket',
  Policy: JSON.stringify(policy), // Policy must be a stringified JSON document
});
await s3Client.send(command);
console.log('Bucket policy updated to public');

How it Works: The provided policy grants public (anonymous) read-only access ("Principal": "*" and "Action": "s3:GetObject") to all objects ("Resource": "arn:aws:s3:::procodrr-nodejs-bucket/*") in the bucket. The command overwrites any existing bucket policy.

5. DeleteBucketCommand

Definition: Deletes the specified bucket. The bucket must be empty before it can be deleted.

Syntax:

new DeleteBucketCommand(input: DeleteBucketCommandInput)

The required input is the Bucket name.

Practical Example & How It Works:

import { S3Client, DeleteBucketCommand } from '@aws-sdk/client-s3';
// ...
const command = new DeleteBucketCommand({
  Bucket: 'procodrr-nodejs-bucket', // The bucket to delete
});
await s3Client.send(command);
console.log('Bucket deleted');

How it Works: The client sends the request to S3. If the bucket is empty and the user has permission, the bucket is permanently removed.


📁 AWS S3 Object Commands

These commands manage the objects (files) stored within an S3 bucket.

1. ListObjectsV2Command

Definition: Retrieves some or all of the objects in a bucket. It's the most common and current way to list objects, replacing the older ListObjectsCommand.

Syntax:

new ListObjectsV2Command(input: ListObjectsV2CommandInput)

Requires Bucket. Optional parameters include Prefix (to filter by object key start), Delimiter (to group keys, simulating directories), and MaxKeys (limit results).

Practical Example & How It Works:

import { S3Client, ListObjectsV2Command } from '@aws-sdk/client-s3';
// ...
const command = new ListObjectsV2Command({
  Bucket: 'procodrr-nodejs-bucket',
  Prefix: 'optional/path/', // Filters objects that start with this string (e.g., 'optional/path/file.txt')
});
const response = await s3Client.send(command);
console.log(response.Contents); // Logs an array of object metadata: [{ Key: '...', LastModified: '...', Size: '...' }, ...]

How it Works: S3 scans the bucket and returns up to 1,000 objects (by default) matching the criteria. The primary data is in the response.Contents array.

2. HeadObjectCommand (Get Metadata)

Definition: Retrieves metadata about an object without actually returning the object's content (body).

Syntax:

new HeadObjectCommand(input: HeadObjectCommandInput)

Requires Bucket and Key (the object's name/path).

Practical Example & How It Works:

import { S3Client, HeadObjectCommand } from '@aws-sdk/client-s3';
// ...
const command = new HeadObjectCommand({
  Bucket: 'procodrr-nodejs-bucket',
  Key: 'file.txt', // The specific object key
});
const response = await s3Client.send(command);
console.log(response); // Metadata like ContentType, ContentLength, ETag, etc.

How it Works: This is a performance-efficient way to check if an object exists, get its size (ContentLength), or its type (ContentType) before deciding whether to download it.

3. GetObjectCommand (Download)

Definition: Retrieves an object from S3. The object's data is returned as a stream in the response body.

Syntax:

new GetObjectCommand(input: GetObjectCommandInput)

Requires Bucket and Key.

Practical Example & How It Works:

import { S3Client, GetObjectCommand } from '@aws-sdk/client-s3';
import { pipeline } from 'stream/promises';
// ...
const command = new GetObjectCommand({
  Bucket: 'procodrr-nodejs-bucket',
  Key: 'file.txt',
});
const response = await s3Client.send(command);
// Uses Node.js stream pipeline to efficiently pipe the object data
await pipeline(response.Body, process.stdout); // Pipes the content directly to the console output

How it Works: The command sends an HTTP GET request to S3. S3 returns the file content as a stream in response.Body, which is then processed (in this case, written to the console).

4. PutObjectCommand (Upload)

Definition: Adds an object to a bucket. This is the command used for basic file uploads.

Syntax:

new PutObjectCommand(input: PutObjectCommandInput)

Requires Bucket, Key (the desired name in S3), and Body (the data to upload).

Practical Example & How It Works:

import { S3Client, PutObjectCommand } from '@aws-sdk/client-s3';
import { createReadStream } from 'fs/promises';
// ...
const readStream = await createReadStream('./local-file.txt'); // Reads data from a local file
const command = new PutObjectCommand({
  Bucket: 'procodrr-nodejs-bucket',
  Key: 'upload/file.txt', // The path/name for the file in S3
  Body: readStream, // The file content (stream, buffer, or string)
  ContentType: 'text/plain', // Important: specifies the MIME type
});
await s3Client.send(command);
console.log('File uploaded');

How it Works: The command streams the data from the local file (readStream) to S3, storing it under the specified Key within the Bucket.

5. DeleteObjectCommand

Definition: Deletes a single object from a bucket.

Syntax:

new DeleteObjectCommand(input: DeleteObjectCommandInput)

Requires Bucket and Key.

Practical Example & How It Works:

import { S3Client, DeleteObjectCommand } from '@aws-sdk/client-s3';
// ...
const command = new DeleteObjectCommand({
  Bucket: 'procodrr-nodejs-bucket',
  Key: 'upload/file.txt', // The specific object to delete
});
await s3Client.send(command);
console.log('File deleted');

How it Works: The command sends a request to S3 to permanently remove the object with the matching key.

6. DeleteObjectsCommand

Definition: Deletes multiple objects from a bucket in a single request, which is much more efficient than sending individual DeleteObjectCommand requests.

Syntax:

new DeleteObjectsCommand(input: DeleteObjectsCommandInput)

Requires Bucket and a Delete object containing an array of object Keys.

Practical Example & How It Works:

import { S3Client, DeleteObjectsCommand } from '@aws-sdk/client-s3';
// ...
const command = new DeleteObjectsCommand({
  Bucket: 'your-bucket-name',
  Delete: {
    Objects: [
      { Key: 'uploads/file1.jpg' }, // Key object
      { Key: 'uploads/file2.jpg' },
      { Key: 'uploads/file3.jpg' },
    ],
    Quiet: false, // Requests a response for each object's deletion status
  },
});
const response = await s3Client.send(command);
console.log('Deleted:', response.Deleted); // Logs an array of successfully deleted objects
console.log('Errors:', response.Errors); // Logs any errors encountered during the batch operation

How it Works: S3 processes the batch delete. The response contains lists of successfully deleted objects and any objects that failed to delete, making it easy to handle exceptions.


🌐 Public URL Helper

getPublicUrl

Definition: A utility function (not an S3 SDK command) to construct the standard, virtual-hosted-style URL for a publicly accessible S3 object.

Syntax:

const getPublicUrl = (bucket: string, key: string) => { /* ... */ };

Practical Example & How It Works:

const getPublicUrl = (bucket, key) => {
  return `https://${bucket}.s3.amazonaws.com/${key}`;
};
console.log(getPublicUrl('procodrr-nodejs-bucket', 'upload/file.txt'));
// Output: https://procodrr-nodejs-bucket.s3.amazonaws.com/upload/file.txt

How it Works: This URL format is a common pattern for accessing public S3 objects directly via a browser or HTTP client, assuming the bucket's Public Access Block is removed (or set to false) and a public bucket policy (like the one in command 4) is in place.
