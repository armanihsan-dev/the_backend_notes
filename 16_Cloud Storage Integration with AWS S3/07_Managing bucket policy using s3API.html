🔒 Managing Bucket Policy using aws s3api

1. What is a Bucket Policy?

A Bucket Policy is an AWS resource-based policy written in JSON format that you attach directly to an S3 bucket.

  • Purpose: It defines who (the principal) can access the objects in the bucket, what actions they can perform (actions), and under what conditions (conditions).
  • Authorization: Bucket policies are the primary mechanism for controlling programmatic access to S3 from outside the AWS account (e.g., cross-account access or public access).
  • Effect: Unlike IAM User policies, which grant permissions to a user, a Bucket Policy grants permissions to the resource (the bucket) itself.

2. Why Use aws s3api?

The aws s3 command is designed only for file operations (cp, sync, ls). It cannot manage the security configuration of the bucket.

  • Low-Level Access: Managing security policies is an API-level configuration task, which is precisely what aws s3api is built for.
  • Direct Mapping: The specific API operations map directly to the s3api commands:
    • To Add/Update: aws s3api put-bucket-policy
    • To Retrieve: aws s3api get-bucket-policy
    • To Remove: aws s3api delete-bucket-policy

3. The Process: Managing the Policy from CLI

Managing a bucket policy via the CLI involves creating the policy document locally and then pushing it to the S3 service.

Managing Bucket Policy

🔹 1. ✅ Get Public Access Block Configuration 

aws s3api get-public-access-block --bucket my-bucket-name
📌 Shows the current public access block settings (if any).

🔹 2. 🗑️ Delete Public Access Block Configuration 

aws s3api delete-public-access-block --bucket my-bucket-name
❗ This removes the entire public access block configuration, allowing public ACLs or policies to take effect.

🔹 3. ✅ Put Public Access Block Configuration

🔒 (Block Public Access – Recommended for Private Buckets) 

aws s3api put-public-access-block \
  --bucket my-bucket-name \
  --public-access-block-configuration '{
    "BlockPublicAcls": true,
    "IgnorePublicAcls": true,
    "BlockPublicPolicy": true,
    "RestrictPublicBuckets": true
  }'

🔓 (Unblock Public Access – For Public Websites) 

aws s3api put-public-access-block \
  --bucket my-bucket-name \
  --public-access-block-configuration '{
    "BlockPublicAcls": false,
    "IgnorePublicAcls": false,
    "BlockPublicPolicy": false,
    "RestrictPublicBuckets": false
  }'

🔹 4. ✅ Get Bucket Policy 

aws s3api get-bucket-policy --bucket my-bucket-name
📌 Fetches the currently attached bucket policy (if any).

🔹 5. ✅ Put (Set/Update) Bucket Policy 

aws s3api put-bucket-policy \
  --bucket my-bucket-name \
  --policy file://policy.json
📝 policy.json should contain a valid IAM policy. Example for public read: 
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadGetObject",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::my-bucket-name/*"
    }
  ]
}

🔹 6. 🗑️ Delete Bucket Policy 

aws s3api delete-bucket-policy --bucket my-bucket-name
❌ Removes the custom bucket policy, reverting to IAM-only access rules.
