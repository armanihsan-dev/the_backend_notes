🚀 Understanding @aws-sdk/lib-storage

Definition

The @aws-sdk/lib-storage library provides the Upload and Download classes, which are high-level utilities for managing file transfers to and from Amazon S3.

  • Upload Class: It simplifies the S3 Multipart Upload process. For large files (usually over 16MB by default, but customizable), it automatically splits the file into smaller parts, uploads them in parallel, manages retries, and finally completes the upload. This parallelization significantly speeds up large file transfers.
  • Download Class (Less Common/Documented): In AWS SDK v3, file downloads are typically done with the S3 client's GetObjectCommand, which streams the body. While a Download class was introduced, direct progress reporting in Node.js for downloads is more commonly and reliably achieved by listening to events on the Body stream returned by GetObjectCommand.

The Core Mechanism: httpUploadProgress Event

The key to tracking progress for uploads is the httpUploadProgress event emitted by the Upload instance.

Event Data (Progress Object)

The progress event listener receives an object with the following crucial properties:

Property Type Description
loaded number The number of bytes uploaded so far.
total number The total number of bytes to be uploaded (the file size). (Caveat Below)
part number The current part number being uploaded in the Multipart Upload.

⚠️ Important Caveat for total in Node.js: When uploading a Node.js Stream (like a file stream), the total property on the progress event may be undefined until the entire stream size is known. If you know the file size beforehand (e.g., from fs.statSync(filePath).size), it is best to use that value for accurate percentage calculation, especially in Node.js environments.

⬆️ Implementation: File Upload Progress (Node.js/JavaScript)

To calculate percentage and bandwidth, we need to track the loaded bytes, the total bytes, and the time elapsed.

1. Setup

import { Upload } from "@aws-sdk/lib-storage";
import { S3Client } from "@aws-sdk/client-s3";
import * as fs from "fs";
import * as path from "path";

// 1. Initialize S3 Client
const s3Client = new S3Client({ region: "your-aws-region" });

// 2. Define Upload Parameters
const filePath = path.join(__dirname, "large-file.zip"); // Replace with your file path
const fileStream = fs.createReadStream(filePath);
const fileTotalSize = fs.statSync(filePath).size;

const uploadParams = {
  Bucket: "your-s3-bucket-name",
  Key: "uploads/my-file.zip",
  Body: fileStream,
};

2. Tracking Progress and Bandwidth

The logic for calculating bandwidth involves tracking the change in loaded bytes and the time interval between progress events. 

// Function to format bytes into a human-readable string (e.g., 1.5 MB)
const formatBytes = (bytes, decimals = 2) => {
  if (bytes === 0) return '0 Bytes';
  const k = 1024;
  const dm = decimals < 0 ? 0 : decimals;
  const sizes = ['Bytes', 'KB', 'MB', 'GB', 'TB', 'PB', 'EB', 'ZB', 'YB'];
  const i = Math.floor(Math.log(bytes) / Math.log(k));
  return parseFloat((bytes / Math.pow(k, i)).toFixed(dm)) + ' ' + sizes[i];
};

async function uploadFileWithProgress() {
    let lastLoaded = 0;
    let lastTime = Date.now();

    try {
        const parallelUploads3 = new Upload({
            client: s3Client,
            params: uploadParams,
            // queueSize: 4, // Number of concurrent parts to upload
            // partSize: 1024 * 1024 * 5, // 5MB part size (minimum for S3)
        });

        // 💡 The 'httpUploadProgress' event provides the progress updates
        parallelUploads3.on("httpUploadProgress", (progress) => {
            const now = Date.now();
            const loaded = progress.loaded || 0;
            const total = progress.total || fileTotalSize; // Use known size as fallback

            // --- Bandwidth Calculation ---
            const bytesSinceLastEvent = loaded - lastLoaded;
            const timeSinceLastEvent = now - lastTime; // in milliseconds
            
            // Bandwidth in Bytes per second (B/s)
            const bandwidthBps = bytesSinceLastEvent / (timeSinceLastEvent / 1000); 
            const formattedBandwidth = formatBytes(bandwidthBps) + '/s';

            // --- Percentage Calculation ---
            const percentage = total > 0 ? ((loaded / total) * 100).toFixed(2) : 'N/A';
            
            // --- Output Progress ---
            console.log(
                `Progress: ${formatBytes(loaded)}/${formatBytes(total)} ` +
                `(${percentage}%) - Bandwidth: ${formattedBandwidth}`
            );

            // Update trackers for the next event
            lastLoaded = loaded;
            lastTime = now;
        });

        const result = await parallelUploads3.done();
        console.log("\n✅ Upload Complete!", result);
    } catch (e) {
        console.error("Upload failed:", e);
    }
}

uploadFileWithProgress();

⬇️ Implementation: File Download Progress (Node.js/JavaScript)

For downloads, you use the standard S3 client's GetObjectCommand which returns a readable stream as the Body. You can track the progress by listening to the data event on the stream.

1. Setup

import { GetObjectCommand } from "@aws-sdk/client-s3";
import * as fs from "fs";
// ... (s3Client and formatBytes function from above are needed) ...
const downloadParams = {
    Bucket: "your-s3-bucket-name",
    Key: "uploads/my-file.zip", // The key of the file to download
};
const downloadFilePath = path.join(__dirname, "downloaded-file.zip");

2. Tracking Progress and Bandwidth

We need to first get the total file size from the S3 object metadata and then listen to the stream's data event. 

async function downloadFileWithProgress() {
    let loadedBytes = 0;
    let lastLoaded = 0;
    let lastTime = Date.now();

    try {
        // 1. Get the object to determine total size
        const response = await s3Client.send(new GetObjectCommand(downloadParams));
        const totalSize = response.ContentLength || 0; 
        
        if (totalSize === 0) {
            console.log("Could not determine file size. Progress will not be calculated.");
        }

        const fileWriteStream = fs.createWriteStream(downloadFilePath);
        const bodyStream = response.Body;

        if (bodyStream) {
            // 💡 The 'data' event on the stream provides chunks of the downloaded file
            bodyStream.on('data', (chunk) => {
                const now = Date.now();
                loadedBytes += chunk.length;

                // --- Bandwidth Calculation ---
                const bytesSinceLastEvent = loadedBytes - lastLoaded;
                const timeSinceLastEvent = now - lastTime; // in milliseconds
                
                // Bandwidth in Bytes per second (B/s)
                const bandwidthBps = bytesSinceLastEvent / (timeSinceLastEvent / 1000); 
                const formattedBandwidth = formatBytes(bandwidthBps) + '/s';

                // --- Percentage Calculation ---
                const percentage = totalSize > 0 ? ((loadedBytes / totalSize) * 100).toFixed(2) : 'N/A';

                // --- Output Progress ---
                // \r is used to overwrite the current line in the console for a clean progress bar look
                process.stdout.write(
                    `\rProgress: ${formatBytes(loadedBytes)}/${formatBytes(totalSize)} ` +
                    `(${percentage}%) - Bandwidth: ${formattedBandwidth}`
                );

                // Update trackers for the next event
                lastLoaded = loadedBytes;
                lastTime = now;
            });

            // Pipe the stream to the local file writer and wait for it to finish
            await new Promise((resolve, reject) => {
                bodyStream.on('error', reject);
                fileWriteStream.on('finish', resolve);
                bodyStream.pipe(fileWriteStream);
            });
            
            console.log("\n✅ Download Complete!");
            console.log(`File saved to: ${downloadFilePath}`);
        }
    } catch (e) {
        console.error("Download failed:", e);
    }
}

downloadFileWithProgress();

🛠️ Summary of How It Works

Metric How It Works Calculation
Loaded Bytes The loaded property from the httpUploadProgress event (Upload) or accumulating chunk.length from the stream's data event (Download). progress.loaded or loadedBytes += chunk.length
Total Size The total property on the progress event (Upload) or the ContentLength property from the S3 response metadata (Download). progress.total or response.ContentLength
Percentage Standard ratio calculation. $100 \times \frac{\text{Loaded Bytes}}{\text{Total Size}}$
Bandwidth The transfer rate calculated by dividing the bytes transferred since the last event by the time elapsed between events. $\frac{\text{Loaded Bytes} - \text{Last Loaded Bytes}}{\text{Current Time} - \text{Last Time}} \text{ in B/ms}$ (then convert to B/s)
