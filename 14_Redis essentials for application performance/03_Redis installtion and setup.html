⚙️ Redis Installation and Basic Setup

1. Redis Components Explained

Think of Redis like a car:

  • redis-server (The Engine)

    This is the **main application**. It runs in the background, holds the data in **RAM**, and processes requests. If this isn't running, nothing works.

  • redis-cli (The Dashboard/Steering Wheel)

    This stands for **Command Line Interface**. It is a terminal tool installed with Redis. You type commands here (like SET, GET) to talk directly to the redis-server.

  • redis-client (The Driver)

    This refers to the **library used in your code** (Node.js, Python, Java) to talk to the server. For example, the npm install redis package in Node.js is a "redis client."

  • Redis Insight (The GPS/Diagnostic Tablet)

    This is a separate **GUI** (Graphical User Interface) software you download on your computer. It lets you **visualize your Redis data**, view charts, edit values using a mouse, and debug performance without typing terminal commands.

2. How to Install Redis on WSL Ubuntu

The commands below are the correct official commands from Redis to get the latest version. Here is the step-by-step execution:

Step 1: Add the GPG Key

This ensures your Linux system trusts the package from Redis.

Bash
curl -fsSL https://packages.redis.io/gpg | sudo gpg --dearmor -o /usr/share/keyrings/redis-archive-keyring.gpg

Step 2: Add the Repository

This tells your system where to download Redis from.

Bash
echo "deb [signed-by=/usr/share/keyrings/redis-archive-keyring.gpg] https://packages.redis.io/deb $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/redis.list

Step 3: Update and Install

Refresh your package list and install the software.

Bash
sudo apt-get update
sudo apt-get install redis

Note: In the official repo, the package is named redis.

3. How to Start Redis as a Background Service

In WSL, you typically use the service command (SysVinit) instead of systemd (though service is more reliable across different WSL configurations).

To start Redis in the background (daemon mode):

Bash
sudo service redis-server start

Note: Even though the package is named redis, the service executable is named redis-server.

To stop Redis:

Bash
sudo service redis-server stop

To restart Redis:

Bash
sudo service redis-server restart

4. How to Check Status

Method A: Check the service status

This tells you if the background process is active.

Bash
sudo service redis-server status

Output should say active (running).

Method B: Ping the server (The best test)

Use the redis-cli to ping the server. If it's working, it replies **"PONG"**. 

Bash
redis-cli ping
Output: PONG

Method C: Connect to the console

Enter the interactive mode.

Bash
redis-cli
Output: 127.0.0.1:6379> (You are now inside Redis).
