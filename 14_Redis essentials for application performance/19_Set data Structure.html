Redis Sets Data Structure 💾

Redis Sets are an **unordered collection of unique strings**, perfect for tasks like tracking unique visitors or storing tags.

1. Redis Sets Overview 📚

Structure: An unordered collection of unique strings (members).

Key Use Cases:

  • Tracking unique users (e.g., users who viewed a page).
  • Storing and managing tags associated with an entity.
  • Performing quick set operations (union, intersection, difference).

Time Complexity: Most operations (add, check for membership, remove) are $O(1)$ (constant time), making them **extremely fast**.

2. Working with Redis Sets via redis-cli

These commands allow you to interact directly with the Redis server.

Command Action Syntax Example
SADD Add one or more members to a set. If a member already exists, it is ignored. SADD key member1 [member2 ...] SADD colors red green blue
SMEMBERS Get all members of the set. (Note: This can be slow for very large sets.) SMEMBERS key SMEMBERS colors
SISMEMBER Check if a member exists in the set (returns 1 or 0). SISMEMBER key member SISMEMBER colors red
SCARD Get the number of members in the set (cardinality). SCARD key SCARD colors
SREM Remove one or more members from the set. SREM key member1 [member2 ...] SREM colors blue
SPOP Remove and return a random member from the set. SPOP key [count] SPOP colors

Example Flow in redis-cli:

# Bash 
> SADD users:online "user:101" "user:102" "user:103"
(integer) 3
> SMEMBERS users:online
1) "user:101"
2) "user:103"
3) "user:102"
> SADD users:online "user:102" "user:104"
(integer) 1 # Only "user:104" was added
> SISMEMBER users:online "user:104"
(integer) 1
> SCARD users:online
(integer) 4
> SREM users:online "user:101"
(integer) 1
> SMEMBERS users:online
1) "user:104"
2) "user:103"
3) "user:102"

3. Working with Redis Sets in Node.js (using ioredis)

First, ensure you have a Redis client installed and connected:

# Bash 
npm install ioredis

Node.js Syntax Example:

# JavaScript 
const Redis = require('ioredis');
const redis = new Redis(); // Connects to 127.0.0.1:6379 by default

async function handleRedisSets() {
    const setKey = 'product:tags:shirt';

    // 1. SADD: Add members to the set
    console.log("--- SADD ---");
    // Returns the number of elements that were actually added.
    let addedCount = await redis.sadd(setKey, 'cotton', 'unisex', 'long-sleeve');
    console.log(`Added ${addedCount} new tags.`); // Output: Added 3 new tags.

    // Adding an existing member is ignored
    addedCount = await redis.sadd(setKey, 'cotton', 't-shirt');
    console.log(`Added ${addedCount} new tags.`); // Output: Added 1 new tag. (only 't-shirt')

    // 2. SCARD: Get the number of members
    console.log("\n--- SCARD ---");
    let count = await redis.scard(setKey);
    console.log(`Total tags for shirt: ${count}`); // Output: 4

    // 3. SISMEMBER: Check for membership (returns 1 or 0)
    console.log("\n--- SISMEMBER ---");
    let isCotton = await redis.sismember(setKey, 'cotton');
    console.log(`Is 'cotton' a tag? ${isCotton ? 'Yes' : 'No'}`); // Output: Yes

    let isWool = await redis.sismember(setKey, 'wool');
    console.log(`Is 'wool' a tag? ${isWool ? 'Yes' : 'No'}`); // Output: No

    // 4. SMEMBERS: Get all members
    console.log("\n--- SMEMBERS ---");
    let allTags = await redis.smembers(setKey);
    console.log("All tags:", allTags); // Output: [ 'cotton', 'unisex', 'long-sleeve', 't-shirt' ] (order is not guaranteed)

    // 5. SREM: Remove a member
    console.log("\n--- SREM ---");
    // Returns the number of members removed
    let removedCount = await redis.srem(setKey, 'long-sleeve', 'unisex');
    console.log(`Removed ${removedCount} tags.`); // Output: Removed 2 tags.

    // Check the remaining members
    allTags = await redis.smembers(setKey);
    console.log("Remaining tags:", allTags); // Output: [ 'cotton', 't-shirt' ]

    redis.quit();
}

handleRedisSets();

4. Advanced Set Operations (Set Algebra)

The power of Redis Sets comes from its ability to perform operations between multiple sets.

Command Action Description redis-cli Syntax
SINTER Intersection Returns members common to all sets. SINTER key1 key2 [key3 ...]
SUNION Union Returns all members in all sets combined. SUNION key1 key2 [key3 ...]
SDIFF Difference Returns members in the first set that are **not** present in any of the subsequent sets. SDIFF key1 key2 [key3 ...]

Example (Finding common users):

  • Set A (page:viewers:a): user1, user2, user3
  • Set B (page:viewers:b): user2, user4, user5
# Bash 
> SINTER page:viewers:a page:viewers:b
1) "user2"

Node.js (Intersection Example):

# JavaScript 
// ... (assuming redis client is connected)
const usersWhoLikeA = ['user:1', 'user:3', 'user:5'];
const usersWhoLikeB = ['user:2', 'user:3', 'user:6'];

await redis.sadd('likes:category:A', ...usersWhoLikeA);
await redis.sadd('likes:category:B', ...usersWhoLikeB);

// SINTER (Find users who like both A AND B)
const commonUsers = await redis.sinter('likes:category:A', 'likes:category:B');

console.log(`Users who like both: ${commonUsers}`);
// Output: Users who like both: [ 'user:3' ]
