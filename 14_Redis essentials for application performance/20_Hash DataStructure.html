Redis Hashes Data Type 🧩

1. Redis Hashes Overview 🧩

Definition

A **Redis Hash** is essentially a **map (or dictionary)** that stores a collection of **field-value pairs** under a single key.

  • Key: The name of the Redis Hash (e.g., user:101).
  • Field: A unique string within the Hash (e.g., username, email, last_login).
  • Value: The data associated with the field (e.g., "alice", "a@example.com", "2025-11-28").

How It Works

  • Modeling Objects: Hashes are perfect for storing a **record or object**, such as a user profile, a product, or a configuration block. Instead of creating separate Redis keys for user:101:name and user:101:email, you store them all under the single key user:101.
  • Efficiency: From a memory perspective, bundling many related fields into a single Hash key is generally more **memory-efficient** than storing them as separate String keys, especially for small hashes.
  • Time Complexity: Basic operations like setting or getting a single field are $O(1)$ (**constant time**), making them **extremely fast**.

2. Working with Redis Hashes via redis-cli

These commands are used for direct interaction with the Redis server.

Command Action Syntax Example
HSET Set a single field-value pair. Creates the Hash if it doesn't exist. HSET key field value HSET user:201 name "Bob" email "b@test.com"
HGET Get the value associated with a specific field. HGET key field HGET user:201 name
HMSET [Deprecated] Set multiple field-value pairs at once. **HSET is now preferred.** HMSET key field1 val1 field2 val2 ... -
HMGET Get the values for multiple fields at once. HMGET key field1 field2 ... HMGET user:201 name email
HGETALL Get all fields and values in the Hash. (Use with caution on very large hashes.) HGETALL key HGETALL user:201
HDEL Delete one or more fields from the Hash. HDEL key field1 [field2 ...] HDEL user:201 email
HEXISTS Check if a specific field exists in the Hash. (Returns 1 or 0). HEXISTS key field HEXISTS user:201 name
HLEN Get the number of fields in the Hash. HLEN key HLEN user:201

redis-cli Example Flow

# Bash 
> HSET product:456 name "Wireless Mouse" price 25.99 stock 100
(integer) 3
> HGET product:456 name
"Wireless Mouse"
> HMGET product:456 price stock
1) "25.99"
2) "100"
> HGETALL product:456
1) "name"
2) "Wireless Mouse"
3) "price"
4) "25.99"
5) "stock"
6) "100"
> HLEN product:456
(integer) 3
> HDEL product:456 stock
(integer) 1
> HEXISTS product:456 stock
(integer) 0

3. Working with Redis Hashes in Node.js

We'll use the popular **ioredis** library for the Node.js examples.

First, install the library:

# Bash 
npm install ioredis

Node.js Syntax Example

# JavaScript 
const Redis = require('ioredis');
const redis = new Redis();

async function handleRedisHashes() {
    const hashKey = 'user:999';

    // 1. HSET: Set multiple field-value pairs (ioredis supports setting multiple pairs directly with HSET)
    console.log("--- HSET ---");
    // Syntax: HSET key field1 value1 field2 value2 ...
    let setResponse = await redis.hset(hashKey, 
        'id', '999', 
        'username', 'AlexK', 
        'status', 'active',
        'points', 500
    );
    console.log(`Fields set: ${setResponse}`); // Output: (Number of fields added/updated)

    // 2. HGET: Get a single field
    console.log("\n--- HGET ---");
    let username = await redis.hget(hashKey, 'username');
    console.log(`Username: ${username}`); // Output: AlexK

    // 3. HMGET: Get multiple fields
    console.log("\n--- HMGET ---");
    // Returns an array: [value1, value2, ...]
    let [status, points] = await redis.hmget(hashKey, 'status', 'points');
    console.log(`Status: ${status}, Points: ${points}`); // Output: active, 500

    // 4. HGETALL: Get all fields and values
    console.log("\n--- HGETALL ---");
    // Returns a JavaScript object {field1: value1, field2: value2, ...}
    let userProfile = await redis.hgetall(hashKey);
    console.log("Full Profile:", userProfile); 

    // 5. HDEL: Delete a field
    console.log("\n--- HDEL ---");
    let deletedCount = await redis.hdel(hashKey, 'points');
    console.log(`Fields deleted: ${deletedCount}`); // Output: 1

    // 6. HINCRBY: Increment a field's integer value (Atomically)
    console.log("\n--- HINCRBY ---");
    // Note: HINCRBY initializes the field to 0 if it doesn't exist
    let newPoints = await redis.hincrby(hashKey, 'score', 10);
    console.log(`New score: ${newPoints}`); // Output: 10
    
    newPoints = await redis.hincrby(hashKey, 'score', 5);
    console.log(`New score: ${newPoints}`); // Output: 15 (10 + 5)
    
    redis.quit();
}

handleRedisHashes();

4. Advanced Hash Operations

Command Action Description
HINCRBY Increment Atomically increments the integer value of a field by the given number (e.g., increasing a score).
HINCRBYFLOAT Increment Float Atomically increments the float value of a field by the given float number (e.g., updating a balance).
HKEYS Get Fields Returns a list of all field names in the Hash (no values).
HVALS Get Values Returns a list of all values in the Hash (no field names).
HSETNX Set If Not Exist Sets a field and value only if the field **does not already exist** in the Hash.

Redis Hashes are a fantastic way to keep your data organized and your Redis commands clean.
