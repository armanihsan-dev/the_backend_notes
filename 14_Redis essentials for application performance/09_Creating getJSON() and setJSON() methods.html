♻️ Reusable JSON Functions for Redis in Node.js

You can easily create reusable functions for getting and setting JSON data by leveraging the modern Node-Redis client's ability to handle custom commands and by using a technique called **prototype extension**.

This approach allows you to attach custom methods (like setJSON and getJSON) directly to the Redis client object, making them feel like built-in client methods.

1. Defining the Reusable Functions

We'll define two core functions that handle the serialization (JSON.stringify) before a SET and deserialization (JSON.parse) after a GET.

Function Operation Purpose
setJSON $\text{Key, Object} \rightarrow \text{JSON.stringify} \rightarrow \text{SET}$ Stores an object under a key.
getJSON $\text{Key} \rightarrow \text{GET} \rightarrow \text{JSON.parse} \rightarrow \text{Object}$ Retrieves and reconstructs the object from the stored JSON string.

2. Attaching Methods to the Redis Client

The node-redis client allows you to pass a functions object during client creation. This is the **cleanest and recommended way** to extend the client's prototype without polluting global classes.

💻 JS Example: Client Extension

import { createClient } from 'redis';

/**
 * 💡 Custom function definitions for the Redis client.
 * All functions receive the Redis client instance as the 'this' context.
 */
const jsonFunctions = {
    /**
     * Sets a key with a JSON stringified value.
     * @param {string} key - The Redis key.
     * @param {object} object - The JavaScript object to store.
     * @param {object} options - Optional parameters like { EX: 3600 }.
     * @returns {Promise<string>} The Redis reply ('OK').
     */
    async setJSON(key, object, options = {}) {
        const value = JSON.stringify(object);
        return this.set(key, value, options);
    },

    /**
     * Gets a key and parses the result back into a JavaScript object.
     * Returns null if the key doesn't exist.
     * @param {string} key - The Redis key.
     * @returns {Promise<object|null>} The parsed JavaScript object.
     */
    async getJSON(key) {
        const value = await this.get(key);
        if (value === null) {
            return null;
        }
        try {
            return JSON.parse(value);
        } catch (error) {
            console.error(`Error parsing JSON for key ${key}:`, error);
            // Optionally throw or return raw value, depending on error policy
            return null; 
        }
    }
};


async function runExtendedClientExample() {
    // 1. Create client and pass the custom functions object
    const client = createClient({
        functions: jsonFunctions 
    });

    client.on('error', err => console.error('Redis Client Error', err));
    await client.connect();

    // Data to store
    const userProfile = {
        id: 101,
        username: "developer_2025",
        lastLogin: new Date().toISOString(),
        settings: { theme: 'dark', notifications: true }
    };
    
    const jsonKey = 'user:101:profile';

    // 2. Use the custom setJSON method
    console.log(`Setting JSON for key: ${jsonKey}`);
    const setReply = await client.setJSON(jsonKey, userProfile, { EX: 60 });
    console.log(`-> Set Reply: ${setReply}`); // >>> -> Set Reply: OK

    // 3. Use the custom getJSON method
    console.log(`\nGetting JSON for key: ${jsonKey}`);
    const retrievedProfile = await client.getJSON(jsonKey);
    
    if (retrievedProfile) {
        console.log("-> Retrieved Object:");
        console.log(retrievedProfile);
        // Verify it's an object, not a string
        console.log(`-> Verified Type: ${typeof retrievedProfile}`); 
        console.log(`-> Nested setting: ${retrievedProfile.settings.theme}`); 
    } else {
        console.log("Key not found or error occurred.");
    }
    
    await client.quit();
}

runExtendedClientExample();

🔑 Key Concepts Explained

  • this Context: When defining functions in the functions object passed to createClient(), the this keyword inside those functions automatically refers to the **Redis client instance itself**. This allows you to call native client methods like this.set() and this.get().
  • JSON.stringify(object): This is the **serialization** step. Redis only stores strings (or buffers), so the JavaScript object must be converted into its string representation before storage.
  • JSON.parse(value): This is the **deserialization** step. The string retrieved from Redis is converted back into a runnable JavaScript object, allowing you to access properties like retrievedProfile.settings.theme.
  • Error Handling: The getJSON function includes a try...catch block to handle potential issues if the data stored under the key is not a valid JSON string (e.g., if another part of the application used a simple SET instead of setJSON). This makes the reusable function **robust**.
