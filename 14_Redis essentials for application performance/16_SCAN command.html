Redis SCAN Command: Incremental Iteration

The SCAN command in Redis is used to incrementally iterate over keys in the current database. It's a cursor-based iteration that avoids the performance issues of commands like KEYS when dealing with large datasets, as it returns a small number of elements at a time.

Here's a breakdown of the command, its syntax, and examples in redis-cli and Node.js.

SCAN Command Definition

SCAN is designed to be used in a **loop** by the client, where the previous call's **cursor** is passed as an argument to the next call.

  • It starts with a cursor of 0.
  • Each call returns a **new cursor value** and a batch of elements.
  • The iteration is complete when the returned cursor is 0.
  • It provides **best-effort guarantees**—meaning an element might be returned multiple times, or not at all, during the entire iteration if the dataset is constantly changing. However, under stable conditions, it guarantees all elements are iterated over.

SCAN Syntax

The basic syntax for the SCAN command is:

SCAN cursor [MATCH pattern] [COUNT count] [TYPE type]

Arguments

Argument Description Required Default
cursor The cursor returned by the previous call. Start with 0 for the first call. Yes -
MATCH pattern Only return keys matching the specified glob-style pattern (e.g., user:*). No No filtering
COUNT count A hint for the number of elements to return in one go (Redis might return more or less). No 10
TYPE type Only return keys of the specified Redis data type (e.g., string, hash, list). No All types

redis-cli Example

Let's assume we have a few keys in Redis:

SET user:1 "Alice"
SET product:101 "Laptop"
SET user:2 "Bob"
SET order:500 "Pending"

1. Initial Call (Cursor 0)

To start the iteration, we use a cursor of 0. 

127.0.0.1:6379> SCAN 0

Example Output:

1) "4"  // This is the new cursor value
2) 1) "user:1"
   2) "product:101"

"4" is the **new cursor**. We must use this in the next call.

The array contains the keys found in this batch.

2. Next Call (Using the new cursor)

Now, we use the returned cursor (4) for the next iteration. 

127.0.0.1:6379> SCAN 4

Example Output:

1) "0"  // The iteration is complete!
2) 1) "user:2"
   2) "order:500"

The new cursor is "0", indicating that the iteration is **complete**.

3. Using MATCH and COUNT

To find only keys starting with user: and suggesting a batch size of 2: 

127.0.0.1:6379> SCAN 0 MATCH user:* COUNT 2

Example Output (Iteration 1):

1) "4"
2) 1) "user:1"

Next Call:

127.0.0.1:6379> SCAN 4 MATCH user:* COUNT 2

Example Output (Iteration 2 - Complete):

1) "0"
2) 1) "user:2"

Node.js (JavaScript) Example

In a Node.js environment, you typically use a library like **ioredis** or **node-redis**. The logic involves a while loop to continuously call SCAN until the cursor returns to 0.

Using ioredis

const Redis = require('ioredis');
const redis = new Redis();

/**
 * Iterates over all keys matching a pattern using SCAN
 * @param {string} pattern - The key pattern (e.g., 'user:*')
 */
async function scanKeys(pattern) {
    let cursor = '0';
    const keys = [];

    console.log(`Starting SCAN for pattern: ${pattern}`);
    
    do {
        // [cursor, array_of_keys]
        const reply = await redis.scan(
            cursor, 
            'MATCH', pattern, 
            'COUNT', 100 // Adjust COUNT as a hint for batch size
        );

        cursor = reply[0]; // Get the new cursor
        const batchKeys = reply[1]; // Get the array of keys

        keys.push(...batchKeys);
        console.log(`Keys found in batch (cursor ${cursor !== '0' ? cursor : 'end'}): ${batchKeys.length}`);

    } while (cursor !== '0'); // Loop until the cursor is '0'

    console.log('\n--- SCAN Complete ---');
    console.log(`Total keys found: ${keys.length}`);
    // console.log(keys); 
    
    redis.quit(); // Close the connection
}

// Example usage: Scan all keys
scanKeys('*');

Using recursion

const fetchKeys = async (cursor = "0") => {
const { cursor: nextCursor, keys } = await redisClient.scan(cursor);
console.log("Fetched keys:", keys);
if (nextCursor === "0") {
  console.log("Scan completed");
  return;
}
await fetchKeys(nextCursor); // recursion with updated cursor
};
