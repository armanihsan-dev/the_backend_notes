Working with Redis Lists

Working with the **Redis List** data type is a fundamental task, as it allows you to create **ordered collections of strings**. Unlike a set, lists can contain duplicate elements and elements are inserted in the order you specify. They are implemented as a **linked list**, which makes operations like adding elements to the head or tail very fast (**constant time, $O(1)$**).

Here is a breakdown of how to work with Redis Lists using both the redis-cli and a Node.js client (using the popular ioredis library).

📚 Redis List: Definition and Key Commands

A Redis List is a sequence of elements that are inserted in the order they are added. Think of it like a **log**, a **queue**, or a **stack**.

Command Definition Use Case
LPUSH key value [value ...] Inserts a new element at the **head (left)** of the list. Building a **Stack** or a **most recent items feed**.
RPUSH key value [value ...] Inserts a new element at the **tail (right)** of the list. Building a **Queue (First-In, First-Out)**.
LPOP key Removes and returns the element at the **head (left)** of the list. Consuming items from a **Stack** or **Queue**.
RPOP key Removes and returns the element at the **tail (right)** of the list. Consuming items from the end of a list.
LRANGE key start stop Returns a range of elements from the list. Viewing the contents of the list.
LLEN key Returns the length of the list. Checking the list's size.

💻 Working with Redis Lists via redis-cli

1. 📝 Basic Syntax and Insertion

You'll typically start by pushing elements onto the list.

Example: Creating a Queue of Tasks

Insert (RPUSH - Right Push): Add elements to the right side (tail).

Bash 
# Syntax: RPUSH list_name element1 [element2 ...]
RPUSH mytasks "Task A"
RPUSH mytasks "Task B" "Task C"

View the List (LRANGE): Check the contents. The index starts at 0. Use 0 -1 to get all elements.

Bash 
# Syntax: LRANGE list_name start_index end_index
LRANGE mytasks 0 -1

Output:

"Task A"
"Task B"
"Task C"

Insert (LPUSH - Left Push): Add an element to the left side (head).

Bash 
# This task gets the highest priority (head of the queue)
LPUSH mytasks "URGENT Task 0"

View the List (LRANGE):

Bash 
LRANGE mytasks 0 -1

Output:

"URGENT Task 0"
"Task A"
"Task B"
"Task C"

2. 🗑️ Retrieval and Deletion

Use LPOP and RPOP to retrieve and simultaneously remove elements.

Remove from Head (LPOP):

Bash 
# Syntax: LPOP list_name
LPOP mytasks

Output: "URGENT Task 0" (The element is removed from the list)

Remove from Tail (RPOP):

Bash 
# Syntax: RPOP list_name
RPOP mytasks

Output: "Task C" (The element is removed from the list)

Check Length (LLEN):

Bash 
# Syntax: LLEN list_name
LLEN mytasks

Output: (integer) 2 (The remaining elements are "Task A" and "Task B")

🟢 Working with Redis Lists in Node.js

We'll use the popular promise-based ioredis client for this example.

1. ⚙️ Setup

First, install the library and create a client instance:

Bash 
npm install ioredis

JavaScript:

JavaScript 
// file: redis_list_example.js
const Redis = require('ioredis');
// Connect to a local Redis instance (default host: 127.0.0.1, port: 6379)
const redis = new Redis();

async function runListExample() {
    const listKey = 'user_activity_log';

    console.log(`\n--- Starting List Example: Key = ${listKey} ---`);
    
    // 1. Clean up old list for a fresh start
    await redis.del(listKey);

    // 2. Add elements using RPUSH (to model a log where new entries go to the end)
    console.log('Adding new activity to the log using RPUSH...');
    // RPUSH returns the new length of the list (4)
    const newLength = await redis.rpush(listKey, 
        'user:1 logged in', 
        'user:2 viewed product page', 
        'user:1 added item to cart',
        'user:2 checked out'
    );
    console.log(`List length after RPUSH: ${newLength}`);
    
    // 3. View the entire log (LRANGE 0 -1)
    let log = await redis.lrange(listKey, 0, -1);
    console.log('\nCurrent Log Contents (LRANGE 0 -1):');
    log.forEach((item, index) => {
        console.log(`  ${index}: ${item}`);
    });

    // 4. Implement a Stack: Add a high-priority message using LPUSH
    console.log('\nAdding high-priority notification using LPUSH...');
    await redis.lpush(listKey, 'SYSTEM: High Priority Alert!');
    
    // 5. Read the most recent item (head of the list) and process/remove it (LPOP)
    const processedItem = await redis.lpop(listKey);
    console.log(`\nProcessed (LPOP): ${processedItem}`);
    
    // 6. View remaining log
    log = await redis.lrange(listKey, 0, -1);
    console.log('\nRemaining Log Contents:');
    log.forEach((item, index) => {
        console.log(`  ${index}: ${item}`);
    });
    console.log(`Final list length (LLEN): ${await redis.llen(listKey)}`);

    redis.quit();
}

runListExample().catch(err => {
    console.error('An error occurred:', err);
    redis.quit();
});
