RedisJSON & JSONPath in Node.js

RedisJSON (provided by the Redis Stack or the ReJSON module) allows you to store, update, and retrieve JSON documents inside Redis, leveraging its speed while enabling complex document manipulation via JSONPath.
Here is a comprehensive guide on working with RedisJSON in Node.js using the modern node-redis client.

💾 Setting Up RedisJSON

Before you start, ensure your Redis server is running the Redis Stack (which includes the ReJSON module).

JavaScript
import { createClient } from "redis";

// Connect to Redis
async function connectClient() {
    const client = createClient();
    client.on('error', err => console.error('Redis Client Error:', err));
    await client.connect();
    return client;
}

1. Basics: Setting and Getting JSON

The core commands are JSON.SET and JSON.GET. In the Node.js client, these are accessed via client.json.set() and client.json.get().

📌 Syntax & Definition

client.json.set(key, path, value): Sets the value at a specific path within the JSON document stored at key.

Path: This is a JSONPath expression that indicates where in the document to place the value. For setting the **entire document**, you must use the root path dollar sign: $ or . (dot).

📝 Example: Setting Data

JavaScript
async function setJsonExample(client) {
    const key = 'user:201';
    const userProfile = {
        name: "Alice",
        age: 30,
        address: {
            city: "New York",
            zip: 10001
        },
        skills: ["Node.js", "Redis", "JSONPath"]
    };

    // Store the entire object at the root path '$'
    const setResult = await client.json.set(key, '$', userProfile);
    console.log(`JSON SET result: ${setResult}`);
    // Output: JSON SET result: OK
}

📝 Example: Getting Data (Entire Document)

JavaScript
async function getJsonExample(client) {
    const key = 'user:201';

    // Retrieve the entire document. The path is optional here,
    // but internally it defaults to the root path '$'.
    const profile = await client.json.get(key);
    console.log(`Full Profile:`, profile);
    // Output: Full Profile: { name: 'Alice', age: 30, address: { city: 'New York', zip: 10001 }, skills: [ 'Node.js', 'Redis', 'JSONPath' ] }
}

2. Deep Dive: JSONPath

JSONPath is an expression language for addressing specific elements, or nodes, in a JSON document. It's the key to working efficiently with RedisJSON.

🔑 Key JSONPath Syntax Elements

Element Definition Example Path Resulting Element
$ Root object/element. $ The whole JSON object.
.name Property selector (dot notation). $.name The value of the name key at the root.
['name'] Property selector (bracket notation). $.['name'] Same as above.
[index] Array index selector. $.skills[0] The first element in the skills array.
.* All elements/properties at the current level. $.address.* Values of city and zip.
.. Deep scan/recursive descent. ..zip Finds the zip property anywhere in the document.

📝 Example: Getting Specific Properties

You provide the key and the path (or an array of paths) in the get options:

JavaScript
async function getSpecificPathsExample(client) {
    const key = 'user:201';

    // 1. Get a single property (Name)
    const nameResult = await client.json.get(key, { path: '$.name' });
    console.log(`Name:`, nameResult);
    // Output: Name: "Alice"

    // 2. Get a nested property (City)
    const cityResult = await client.json.get(key, { path: '$.address.city' });
    console.log(`City:`, cityResult);
    // Output: City: "New York"

    // 3. Get an array element (First skill)
    const skillResult = await client.json.get(key, { path: '$.skills[0]' });
    console.log(`First Skill:`, skillResult);
    // Output: First Skill: "Node.js"
}

3. Modifying Data with JSONPath

RedisJSON provides commands for **atomic modification** without retrieving and re-setting the entire document.

📌 Key Modification Commands

Command Node.js Method Purpose
JSON.SET client.json.set(key, path, value) Update or create a specific value at a path.
JSON.DEL client.json.del(key, path) Delete a specific value/element at a path.
JSON.ARRAPPEND client.json.arrAppend(key, path, ...values) Append elements to an array at a path.
JSON.NUMINCRBY client.json.numIncrBy(key, path, value) Increment a number at a path.

📝 Example: Modifying Data

JavaScript
async function modifyJsonExample(client) {
    const key = 'user:201';

    // 1. Increment a value (Age)
    const ageResult = await client.json.numIncrBy(key, '$.age', 5);
    console.log(`New Age (after +5): ${ageResult}`);
    // Output: New Age (after +5): [ 35 ]

    // 2. Update a nested value (City)
    const updateResult = await client.json.set(key, '$.address.city', 'San Francisco');
    console.log(`City Update Result: ${updateResult}`);
    // Output: City Update Result: OK

    // 3. Append to an array (Add a skill)
    const appendResult = await client.json.arrAppend(key, '$.skills', 'GraphQL');
    console.log(`New Skills Array Length: ${appendResult}`);
    // Output: New Skills Array Length: 4

    // 4. Delete an element (Remove the first skill)
    const delResult = await client.json.del(key, '$.skills[0]');
    console.log(`Delete Result (1=success): ${delResult}`);
    // Output: Delete Result (1=success): 1
}

🚀 Putting It All Together

Here is a complete, runnable example (assuming you have a Redis server running locally).

JavaScript
import { createClient } from "redis";

async function runRedisJsonDemo() {
    const client = createClient();
    client.on('error', err => console.error('Redis Client Error:', err));
    await client.connect();

    const key = 'employee:123';
    
    console.log('--- 1. SET Initial Data ---');
    const employeeData = {
        name: "Bob",
        department: "Engineering",
        salary: 80000,
        projects: ["Project Alpha", "Project Beta"]
    };
    await client.json.set(key, '$', employeeData);

    console.log('\n--- 2. GET Specific Path (Department) ---');
    // Using JSONPath '$.department' to select the value of the 'department' key
    const dept = await client.json.get(key, { path: '$.department' });
    console.log(`Employee's Department: ${dept}`);
    // Output: "Engineering"

    console.log('\n--- 3. Array APPEND (Add a Project) ---');
    await client.json.arrAppend(key, '$.projects', 'Project Gamma');
    
    console.log('\n--- 4. Number INCREMENT (Give a Raise) ---');
    // Increment salary by 5000
    await client.json.numIncrBy(key, '$.salary', 5000);
    
    console.log('\n--- 5. GET Final Document ---');
    const finalData = await client.json.get(key);
    console.log('Final Employee Data:', finalData);
    /*
        Output: Final Employee Data: {
          name: 'Bob',
          department: 'Engineering',
          salary: 85000,
          projects: [ 'Project Alpha', 'Project Beta', 'Project Gamma' ]
        }
    */

    await client.del(key); // Clean up the key
    await client.quit();
}

This covers the essential concepts of RedisJSON, its syntax in Node.js, and the power of JSONPath for granular data access and manipulation.

The following sections cover **advanced features** of JSONPath: filtering arrays and the deep scan operator (..). These are powerful tools for retrieving specific data without knowing the exact structure or index.

🔎 Advanced JSONPath Features

1. Array Filtering ([?(<expression>)])

This feature allows you to select only the array elements that satisfy a specific condition. It's often referred to as a **filter expression**.

📌 Syntax & Definition

  • [?(<expression>)]: The filter expression always starts with ?() and uses the current element (@) to check a condition.
  • @: Represents the current node being processed by the filter.

📝 Example Setup

Let's assume we have a key named inventory storing a list of products:

JavaScript
const inventoryKey = 'store:inventory';
const inventoryData = {
    products: [
        { id: 101, name: "Laptop", price: 1200, stock: 5 },
        { id: 102, name: "Mouse", price: 25, stock: 50 },
        { id: 103, name: "Keyboard", price: 80, stock: 12 },
        { id: 104, name: "Monitor", price: 300, stock: 0 } // Out of stock
    ]
};
await client.json.set(inventoryKey, '$', inventoryData);

📝 Example: Filtering

Goal: Retrieve all products that are currently **in stock** (where stock is greater than 0).

JSONPath Expression Explanation
$.products[?(@.stock > 0)] Selects all elements in the products array where the stock property of the current element (@.stock) is greater than 0.
JavaScript
async function filterArrayExample(client) {
    const inventoryKey = 'store:inventory';
    
    // Path: $.products[?(@.stock > 0)]
    const inStockProducts = await client.json.get(inventoryKey, {
        path: '$.products[?(@.stock > 0)]'
    });
    
    console.log('In-Stock Products:', inStockProducts);
    /* Output: 
    [
        {"id":101,"name":"Laptop","price":1200,"stock":5},
        {"id":102,"name":"Mouse","price":25,"stock":50},
        {"id":103,"name":"Keyboard","price":80,"stock":12}
    ] 
    */
}

2. Deep Scan Operator (..)

The deep scan operator allows you to search for a property anywhere in the document's hierarchy, regardless of its depth.

📌 Syntax & Definition

  • ..: Searches for the subsequent element/property name **recursively** from the current point downward.

📝 Example Setup

Let's assume a nested structure for an organization's employee list:

JavaScript
const orgKey = 'org:structure';
const orgData = {
    company: "TechCorp",
    teams: [
        { 
            name: "Backend",
            members: [{ id: 1, role: "Engineer" }] 
        },
        { 
            name: "Frontend",
            members: [{ id: 2, role: "Lead" }, { id: 3, role: "Engineer" }] 
        }
    ]
};
await client.json.set(orgKey, '$', orgData);

📝 Example: Deep Scan

Goal: Retrieve all employee **IDs** regardless of which team they belong to.

JSONPath Expression Explanation
$.teams..id Starts at $.teams, then recursively searches (..) for any nested property named id.
JavaScript
async function deepScanExample(client) {
    const orgKey = 'org:structure';

    // Path: $..id
    const allIds = await client.json.get(orgKey, {
        path: '$..id'
    });
    
    console.log('All IDs found:', allIds);
    // Output: [ 1, 2, 3 ]
    
    // Note: The Deep Scan can also be used with filtering!
    // Path: $..[?(@.role == "Lead")]
    const leadEmployee = await client.json.get(orgKey, {
        path: '$..[?(@.role == "Lead")]'
    });

    console.log('Lead Employee:', leadEmployee);
    /* Output:
    [
      { id: 2, role: 'Lead' }
    ]
    */
}

🛠️ Combined Usage Example

You can combine these features to perform powerful queries.

Goal: Find the **price** of any product with a **stock count greater than 10**, anywhere in the inventory structure.

JSONPath Expression Breakdown
$.products[?(@.stock > 10)].price 1. $.products: Start with the products array. 2. [?(@.stock > 10)]: Filter array to items where stock > 10. 3. .price: Select the price property from the filtered items.
JavaScript
async function combinedExample(client) {
    const inventoryKey = 'store:inventory';
    
    const highStockPrices = await client.json.get(inventoryKey, {
        path: '$.products[?(@.stock > 10)].price'
    });
    
    console.log('Prices of high-stock items:', highStockPrices);
    // Output: [ 25, 80 ] (From Mouse and Keyboard)
}

Common Array Operations in RedisJSON

Working with arrays in RedisJSON documents is extremely efficient, as it provides dedicated commands for managing arrays atomically—meaning you can modify the array without reading, deserializing, modifying, and rewriting the entire JSON document.

1. Array Setup and Core Operations

We will use a common JSON structure for demonstration:

JavaScript
// Key: 'user:tasks'
const initialData = {
    user: "Charlie",
    todos: ["Buy groceries", "Finish report", "Call plumber"],
    completed: []
};
// client.json.set('user:tasks', '$', initialData);

✅ client.json.arrAppend(key, path, ...values)

Definition: Appends one or more values to the **end** of the array located at the specified path.

Path: Targets the array itself (e.g., $.todos).

Action Code Result (Length)
Append one item client.json.arrAppend('user:tasks', '$.todos', 'Email boss') 4
Append multiple items client.json.arrAppend('user:tasks', '$.completed', 'Nap', 'Eat') 2

✅ client.json.arrInsert(key, path, index, ...values)

Definition: Inserts one or more values into the array at a specified **zero-based** index.

  • An index of 0 inserts at the beginning.
  • An index of -1 inserts **before** the last element.
  • An index equal to the current array length inserts at the end (same as arrAppend).
Action Code Array State ($.todos)
Insert at start client.json.arrInsert('user:tasks', '$.todos', 0, 'New priority task') ["New priority task", "Buy groceries", ...]
Insert in middle client.json.arrInsert('user:tasks', '$.todos', 2, 'Mid-task break') [..., "Finish report", "Mid-task break", "Call plumber"]

✅ client.json.arrPop(key, path, index?)

Definition: **Removes and returns** the element at a specific index. If index is omitted, it defaults to the **last** element (pop from the end).

Action Code Returned Value
Pop last item client.json.arrPop('user:tasks', '$.todos') "Call plumber" (original value)
Pop first item client.json.arrPop('user:tasks', '$.todos', 0) "Buy groceries"

✅ client.json.arrTrim(key, path, start, stop)

Definition: **Trims** the array to contain only the elements between the start and stop indices (**inclusive**). Elements outside this range are removed.

Array State Start Stop Result ($.todos)
["A", "B", "C", "D"] 1 2 ["B", "C"]
["A", "B", "C", "D"] 0 0 ["A"]
["A", "B", "C", "D"] 1 -1 ["B", "C", "D"]

2. Array Metadata and Utility

✅ client.json.arrLen(key, path)

Definition: Returns the **length** (number of elements) of the array located at the path.

JavaScript
// If $.todos has 3 items
const len = await client.json.arrLen('user:tasks', '$.todos'); 
console.log(len); // Output: [ 3 ] (note: array response, even for a single value)

✅ client.json.arrIndex(key, path, value, start?, stop?)

Definition: Returns the zero-based **index** of the **first appearance** of value in the array. Optional start and stop indices for search range.

JavaScript
// Assume $.todos is ["Buy groceries", "Finish report", "Call plumber"]
const index = await client.json.arrIndex('user:tasks', '$.todos', 'Finish report');
console.log(index); // Output: [ 1 ]

3. Deleting Elements

✅ client.json.del(key, path)

Definition: Deletes the value/element located at the specified path. When targeting an array element (e.g., $.todos[1]), that element is removed, and the array is shifted.

Path Action Effect
$.todos[1] client.json.del('user:tasks', '$.todos[1]') Deletes "Finish report" (index 1). The array shrinks.
$.completed client.json.del('user:tasks', '$.completed') Deletes the entire completed array property.

🚀 Complete Array Example

JavaScript
async function arrayWorkflow(client) {
    const key = 'list:demo';
    
    // START: [10, 20, 30]
    await client.json.set(key, '$', { numbers: [10, 20, 30] });

    console.log(`Initial Array: ${JSON.stringify(await client.json.get(key, { path: '$.numbers' }))}`);
    
    // 1. ARRAPPEND: Add 40 to the end
    await client.json.arrAppend(key, '$.numbers', 40);
    console.log(`After Append: ${JSON.stringify(await client.json.get(key, { path: '$.numbers' }))}`);
    // Array is now: [10, 20, 30, 40]

    // 2. ARRINSERT: Insert 15 at index 1
    await client.json.arrInsert(key, '$.numbers', 1, 15);
    console.log(`After Insert: ${JSON.stringify(await client.json.get(key, { path: '$.numbers' }))}`);
    // Array is now: [10, 15, 20, 30, 40]

    // 3. ARRPOP: Remove the element at index 3 (which is 30)
    const poppedValue = await client.json.arrPop(key, '$.numbers', 3);
    console.log(`Popped Value: ${poppedValue}`);
    console.log(`After Pop: ${JSON.stringify(await client.json.get(key, { path: '$.numbers' }))}`);
    // Array is now: [10, 15, 20, 40]

    // 4. ARRLEN: Get the new length
    const length = await client.json.arrLen(key, '$.numbers');
    console.log(`Final Length: ${length[0]}`);
    
    await client.del(key);
}
