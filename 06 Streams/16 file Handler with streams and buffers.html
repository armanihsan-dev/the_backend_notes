What is a FileHandle in fs/promises?

A FileHandle is an object representing an open file descriptor, returned by fs.promises.open(). It acts as a handle to the file, allowing you to perform operations on it until you explicitly close it.

Using FileHandle with Streams

Using FileHandle with streams is the recommended approach for handling large files efficiently. A FileHandle object provides methods to create readable or writable streams directly from the opened file.

Key Methods

  • fileHandle.createReadStream(): Creates a Readable Stream to read data from the file.
  • fileHandle.createWriteStream(): Creates a Writable Stream to write data to the file.
  • fileHandle.close(): Asynchronously closes the file, freeing up system resources. This is crucial and must always be called.

Example: Reading a File with FileHandle + Stream

This example demonstrates how to open a file, create a readable stream from the handle, and read its contents.

import { open } from 'fs/promises';
import { finished } from 'stream/promises'; // Correct for async/await

async function readFileWithStream() {
  let fileHandle;
  try {
    fileHandle = await open('input.txt', 'r');
    const readStream = fileHandle.createReadStream({ encoding: 'utf-8' });

    readStream.on('data', chunk => {
      console.log('Chunk:', chunk);
    });

    await finished(readStream); // Await the promise from finished()
    console.log('Reading completed!');
  } catch (error) {
    console.error('An error occurred:', error);
  } finally {
    if (fileHandle) {
      await fileHandle.close();
      console.log('File closed.');
    }
  }
}
readFileWithStream().catch(console.error);

Example: Writing to a File with FileHandle + Stream

This example shows how to open a file in write mode, create a writable stream, and write data to it.

import { open } from 'fs/promises';
import { finished } from 'stream/promises';

async function writeFileWithStream() {
  let fileHandle;
  try {
    fileHandle = await open('output.txt', 'w');
    const writeStream = fileHandle.createWriteStream();

    writeStream.write('Hello, world!\n');
    writeStream.write('This is written using a stream from FileHandle.\n');

    writeStream.end(); // Signal that no more data will be written
    await finished(writeStream);
    console.log('Writing completed!');
  } catch (error) {
    console.error('An error occurred:', error);
  } finally {
    if (fileHandle) {
      await fileHandle.close();
      console.log('File closed.');
    }
  }
}
writeFileWithStream().catch(console.error);

Example: Copying a File with FileHandle + Streams

This is a powerful use case, using pipeline from stream/promises to copy a file efficiently without loading its entire content into memory.

import { open } from 'fs/promises';
import { pipeline } from 'stream/promises';

async function copyFile() {
  let srcHandle, destHandle;
  try {
    srcHandle = await open('input.txt', 'r');
    destHandle = await open('output.txt', 'w');

    await pipeline(
      srcHandle.createReadStream(),
      destHandle.createWriteStream()
    );
    console.log('File copied successfully!');
  } catch (error) {
    console.error('An error occurred:', error);
  } finally {
    if (srcHandle) await srcHandle.close();
    if (destHandle) await destHandle.close();
    console.log('Both files closed.');
  }
}
copyFile().catch(console.error);

Important Note on Imports

Using await finished(readStream) requires importing finished from stream/promises, not stream. The latter is for the callback-based API, which does not return a promise.
