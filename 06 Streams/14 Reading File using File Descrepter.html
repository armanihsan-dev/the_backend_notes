fs.read() Method in Node.js

To read a file in Node.js using fs.read(), you need to first open the file to get a file descriptor. This method provides low-level, fine-grained control over the reading process, allowing you to specify exactly how many bytes to read and where to start reading from within the file.

Definition and Syntax

The fs.read() method reads data from the file specified by the file descriptor.

Asynchronous Syntax:

fs.read(fd, buffer, offset, length, position, callback)
  • fd: The file descriptor of the opened file.
  • buffer: The buffer where the data will be written.
  • offset: The offset within the buffer to begin writing the data.
  • length: The number of bytes to read.
  • position: The position in the file to begin reading from. If null, Node.js will read from the current file position and update it.
  • callback: A function that executes after the read operation, with the signature (err, bytesRead, buffer). bytesRead is the number of bytes actually read.

Promise-based Syntax:

fs.promises.read(fd, buffer, offset, length, position)

This version returns a promise that resolves with an object { bytesRead, buffer }.

Step-by-Step Example

Here's a complete example demonstrating how to read a file using fs.promises.read() for a more modern approach.

  1. Open the file: First, use fs.promises.open() to get a file descriptor.
  2. Create a buffer: Allocate a Buffer to hold the data you're about to read.
  3. Read the file: Call fs.promises.read() with the file descriptor and buffer.
  4. Process the data: The returned object contains bytesRead (how many bytes were actually read) and the buffer itself. You can then convert the buffer to a string or use it directly.
  5. Close the file: Always close the file descriptor using filehandle.close() to release system resources.

Let's use a file named sample.txt with the content: "Hello, fs.read() is great!".

read_file.js

const fs = require('fs/promises'); async function readFileWithFsRead(filePath) { let filehandle; try { // Step 1: Open the file to get a file handle (which contains the file descriptor) filehandle = await fs.open(filePath, 'r'); console.log('File opened with descriptor:', filehandle.fd); // Step 2: Create a buffer to hold the data const buffer = Buffer.alloc(20); // Allocate a buffer of 20 bytes // Step 3: Read 10 bytes from the beginning of the file (position 0) console.log('\nReading the first 10 bytes...'); let result = await filehandle.read(buffer, 0, 10, 0); console.log(`Bytes read: ${result.bytesRead}`); console.log('Data:', result.buffer.slice(0, result.bytesRead).toString()); // Step 4: Read the next 10 bytes, starting at file position 10 console.log('\nReading the next 10 bytes...'); result = await filehandle.read(buffer, 0, 10, 10); console.log(`Bytes read: ${result.bytesRead}`); console.log('Data:', result.buffer.slice(0, result.bytesRead).toString()); } catch (err) { console.error('An error occurred:', err); } finally { // Step 5: Always close the file handle if (filehandle) { await filehandle.close(); console.log('\nFile closed.'); } } } // Ensure you have a file named 'sample.txt' with some content readFileWithFsRead('sample.txt');

When you run this code, it will first read "Hello, fs.r" from the file, and then "ead() is grea". This demonstrates the granular control you have over which parts of the file you read.
