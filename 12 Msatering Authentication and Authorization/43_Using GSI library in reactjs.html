Implementation using @react-oauth/google

1. Prerequisites

Before you start coding, you need to set up your Google Cloud Project:

  • Get a Google Client ID: Go to the Google Cloud Console, create or select a project, navigate to APIs & Services > Credentials, and create a new OAuth client ID for a Web application.
  • Configure Origins: Crucially, add your development server URL (e.g., http://localhost:5173) to the Authorized JavaScript origins field.
  • Get Your ID: Copy the resulting Client ID.

2. Installation

Install the main package and, optionally, jwt-decode to easily read the user data from the token on the client side (though the token must always be verified on the backend for production apps).

Bash
npm i @react-oauth/google jwt-decode

3. Configure the Provider (Client ID Setup)

The entire application needs access to the Google OAuth context. This is done by wrapping your main application with the GoogleOAuthProvider and supplying your Client ID.

src/main.jsx

JavaScript
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App.jsx';
// 1. Import the provider
import { GoogleOAuthProvider } from '@react-oauth/google';
// Load the client ID from environment variables (Vite-specific syntax)
const CLIENT_ID = import.meta.env.VITE_GOOGLE_CLIENT_ID;

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    {/* 2. Wrap your application with the provider */}
    <GoogleOAuthProvider clientId={CLIENT_ID}>
      <App />
    </GoogleOAuthProvider>
  </React.StrictMode>,
);

.env File (in your project root)

Plain Text (Environment Variable)
# Ensure you prefix the variable with VITE_ for Vite to expose it to the client
VITE_GOOGLE_CLIENT_ID="YOUR_GOOGLE_CLIENT_ID_HERE.apps.googleusercontent.com"

4. Create the Login Component

Use the GoogleLogin component to render the button. It automatically injects the official "Sign in with Google" button and handles the entire authentication flow (popup/redirect).

src/components/GoogleAuth.jsx

JavaScript
import React, { useState } from 'react';
// 1. Import GoogleLogin and jwt_decode
import { GoogleLogin } from '@react-oauth/google';
import { jwtDecode } from 'jwt-decode'; // Recommended library
const GoogleAuth = () => {
  const [userProfile, setUserProfile] = useState(null);

  // 2. Define the success callback function
  const onSuccess = (credentialResponse) => {
    // The credential is a JWT (JSON Web Token)
    const jwtToken = credentialResponse.credential;
    
    // Decode the token to get user info (client-side viewing only)
    const decodedProfile = jwtDecode(jwtToken);
    
    console.log('Login Successful!');
    console.log('JWT Token (Send to Backend):', jwtToken);
    console.log('Decoded User Profile:', decodedProfile);
    
    setUserProfile(decodedProfile);
    
    // 💡 IMPORTANT: You MUST send the `jwtToken` to your **backend**
    // server for verification before creating a user session.
    // fetch('/api/auth/google', {
    //   method: 'POST',
    //   headers: { 'Content-Type': 'application/json' },
    //   body: JSON.stringify({ token: jwtToken }),
    // });
  };

  // 3. Define the error callback function
  const onError = () => {
    console.error('Login Failed');
  };

  const handleLogout = () => {
    setUserProfile(null);
  };

  if (userProfile) {
    return (
      <div style={{ padding: '20px', border: '1px solid #ccc', borderRadius: '8px' }}>
        <h3>Welcome, {userProfile.name}!</h3>
        <p>Email: {userProfile.email}</p>
        <img src={userProfile.picture} alt="Profile" style={{ width: '50px', borderRadius: '50%' }} />
        <p>This data is from the decoded JWT on the frontend.</p>
        <button onClick={handleLogout} style={{ marginTop: '10px' }}>
          Logout
        </button>
      </div>
    );
  }

  return (
    <div>
      <h3>Sign In with Google</h3>
      {/* 4. Render the GoogleLogin component with callbacks */}
      <GoogleLogin
        onSuccess={onSuccess}
        onError={onError}
        // Optional: Customize the button appearance
        theme="outline"
        size="large"
        text="signin_with"
      />
    </div>
  );
};
export default GoogleAuth;

5. Use the Component

In your main application component (src/App.jsx):

JavaScript
import React from 'react';
import GoogleAuth from './components/GoogleAuth';
function App() {
  return (
    <div style={{ textAlign: 'center', marginTop: '50px' }}>
      <h1>React Google OAuth Demo</h1>
      <hr style={{ margin: '20px auto', width: '300px' }}/>
      <GoogleAuth />
    </div>
  );
}
export default App;

💡 How it Works Behind the Scenes (JavaScript)

The @react-oauth/google library is essentially a React wrapper for the low-level Google Identity Services (GSI) SDK.

  • The Provider (GoogleOAuthProvider): This component internally ensures that the official Google GSI JavaScript script (https://accounts.google.com/gsi/client) is loaded into the HTML page, making the global window.google.accounts.id object available. It also uses this object to call the initialize() method, passing your clientId and setting up the basic configuration for all child components.
  • The Component (GoogleLogin): When this component mounts, it uses a React useEffect hook to call the GSI SDK's button rendering function: window.google.accounts.id.renderButton(document.getElementById('div-id'), {...}).
    This function dynamically injects an <iframe> into the target DOM element (the one rendered by the GoogleLogin component).
    This iframe is hosted on Google's domain, which is a crucial security feature. It handles all direct interaction with Google's servers.
  • Authentication and Callback:
    • When a user clicks the button inside the iframe, the GSI library handles the OAuth 2.0 Implicit Flow.
    • Upon successful sign-in, Google issues a JSON Web Token (JWT), called an ID Token.
    • The GSI library then communicates the JWT back to your React application via a safe method (like postMessage or a redirect), triggering the onSuccess function you defined.
  • Token Handling (JWT): The credentialResponse.credential is the JWT.
    • Client Side (Frontend): You can use jwtDecode to read the public user data (name, email, picture) for UX purposes.
    • Server Side (Backend - Required): For security, the raw JWT must be sent to your backend. The backend must use a library like Google's google-auth-library to verify the token's signature against Google's public keys. This ensures the token is genuine and wasn't forged. After verification, a secure session (e.g., using a custom application JWT or cookies) is created for the user.
