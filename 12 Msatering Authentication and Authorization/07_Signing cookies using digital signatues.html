Blackish Signed Token Notes

🧱 **What do we use to sign?**

Node’s built-in **crypto module**.

Token Structure

We follow a simple structure:

            token = base64(payload) + "." + signature
            Payload = JSON object
            Signature = Hash( secret + payload + secret )

We **never** store **secret** in cookie.

---

✅ Step 1: Login Route (Sign & Set Cookie) 

            import crypto from "crypto";
            import User from "../models/User.js";
            const secretKey = "my_super_secret_key_786"; // long & private
            
            export const login = async (req, res) => {
              const { email, password } = req.body;
            
              const user = await User.findOne({ email, password }).lean();
              if (!user) {
                return res.status(401).json({ error: "Invalid credentials" });
              }
            
              // Step A: Create payload
              const payload = {
                uid: user._id.toString(),
                exp: Math.floor(Date.now() / 1000) + 60 // expires in 60 seconds
              };
            
              const jsonPayload = JSON.stringify(payload);
            
              // Step B: Base64URL encode payload
              const base64Payload = Buffer.from(jsonPayload).toString("base64url");
            
              // Step C: Create signature
              const signature = crypto
                .createHash("sha256")
                .update(secretKey + base64Payload + secretKey)
                .digest("base64url");
            
              // Step D: Final Token
              const token = `${base64Payload}.${signature}`;
            
              // Step E: Store token in httpOnly cookie
              res.cookie("token", token, {
                httpOnly: true,
                sameSite: "strict"
              });
            
              res.json({ message: "Logged in ✅" });
            };

Cookie now contains an **untouchable signed token**.

Let someone edit **uid** or **expiry**… **signature breaks** 🔥

✅ Step 2: Auth Check Middleware

            import crypto from "crypto";
            import User from "../models/User.js";
            const secretKey = "my_super_secret_key_786";
            
            export default async function checkAuth(req, res, next) {
              const { token } = req.cookies;
            
              if (!token) {
                return res.status(401).json({ error: "Not logged in!" });
              }
            
              // Split payload & signature
              const [payloadB64, oldSignature] = token.split(".");
              const jsonPayload = Buffer.from(payloadB64, "base64url").toString();
            
              const payload = JSON.parse(jsonPayload);
              const { uid, exp } = payload;
            
              // 1️⃣ Verify Signature
              const newSignature = crypto
                .createHash("sha256")
                .update(secretKey + payloadB64 + secretKey)
                .digest("base64url");
            
              if (oldSignature !== newSignature) {
                res.clearCookie("token");
                return res.status(401).json({ error: "Cookie has been modified!" });
              }
            
              // 2️⃣ Check expiry
              const currentTime = Math.floor(Date.now() / 1000);
              if (exp < currentTime) {
                res.clearCookie("token");
                return res.status(401).json({ error: "Session expired!" });
              }
            
              // 3️⃣ Attach user in request
              const user = await User.findById(uid).lean();
              if (!user) {
                res.clearCookie("token");
                return res.status(401).json({ error: "User deleted!" });
              }
            
              req.user = user;
              next();
            }

Now the user is properly verified.

  • Any attack? **Signature fails** ✅
  • Expired? **Logout** ✅
  • User removed? **Logout** ✅

🧠 What Did You Just Learn?

Feature Purpose
**Base64URL** Safe encoding to store in cookie
**Hashing** Signature that proves data wasn’t changed
**Secret Key** Only server can verify token
**Expiry Field** Auto logout when time ends
**HTTP-only cookie** Prevents browser JS from stealing token
**Middleware** Protects restricted routes

This is the foundation of web authentication 🔒
