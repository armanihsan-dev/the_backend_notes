Cryptography Notes 🔐

Cryptography is the science and art of securing communications and data, often through **encryption**1, so that only the intended recipient can read and process the information. It is crucial in networking for establishing **trust and security** over untrusted channels like the internet2.

Types of Cryptography in Networking

The three main types of cryptographic schemes used in networking are:

  • Symmetric-Key Cryptography (or Secret-Key Cryptography)3

    **Mechanism:** Uses a **single, secret key** for both **encryption** (converting readable data, or *plaintext*, into unreadable data, or *ciphertext*) and **decryption** (reversing the process)4.

    **Characteristics:** It is very fast and efficient, making it ideal for encrypting large amounts of data5.

    **Challenge:** Securely sharing the secret key between the sender and receiver is a problem, known as the *key distribution problem*6.

    **Examples:** **Advanced Encryption Standard (AES)**, **Data Encryption Standard (DES)**7.

  • Asymmetric-Key Cryptography (or Public-Key Cryptography - PKC)8

    **Mechanism:** Uses a pair of mathematically linked keys: a **Public Key** for encryption (which can be shared openly) and a **Private Key** for decryption (which must be kept secret)9. Data encrypted with the public key can *only* be decrypted with the corresponding private key10.

    **Characteristics:** Solves the *key distribution problem* as the public key can be freely distributed11. It is computationally much slower than symmetric-key cryptography.

    **Use Cases:** Secure key exchange (to set up a symmetric key session), **Digital Signatures**, and encrypting small amounts of data.

    **Examples:** **RSA**, **Elliptic Curve Cryptography (ECC)**12.

  • Hash Functions (or One-Way Cryptography)13

    **Mechanism:** An algorithm that takes an input (data of any size) and produces a fixed-size of bits, unique string of characters called a **hash value** or *message digest*14. The process is **one-way**; it's computationally infeasible to reverse the hash to find the original input data15.

    **Characteristics:** Ensures **data integrity** (if even a single bit of the input data changes, the resulting hash is completely different) and is often used for password storage16. It does **not** use keys for encryption/decryption.

    **Examples:** **SHA-256**, **MD5** (though MD5 is now considered insecure for many uses)17.

Introduction and Pre-Cryptography Problem

Cryptography was introduced to solve the fundamental problem of **secure communication over an insecure or public channel**18.

The Problem Before Cryptography

Before the widespread use of modern cryptography, especially in digital networks, the primary security concerns were:

  • **Lack of Confidentiality (Eavesdropping):** Any message sent over a public network (like the early internet) could be intercepted and read by an unauthorized party (*eavesdropper* or *man-in-the-middle*)19. The communication was in **plaintext**, completely exposed.
  • **Lack of Integrity (Tampering):** There was no way to guarantee that a message hadn't been modified, corrupted, or tampered with during transmission by an attacker.
  • **Lack of Authenticity:** It was difficult to verify the true identity of the sender or to confirm that you were communicating with the legitimate server (e.g., your bank's website) and not an impostor.
  • **Key Exchange:** Even with traditional secret codes, securely exchanging the secret key required for communication was a major vulnerability, often needing a secure physical courier.

The introduction of modern cryptography, particularly **Public-Key Cryptography** in the 1970s, addressed these issues by providing mathematical ways to ensure **confidentiality, integrity, and authenticity** without needing a prior secure channel to exchange secret keys20.

Securing the Internet and Importance for Authentication

How Cryptography Makes the Internet Secure

Cryptography, primarily through protocols like **TLS/SSL** (Transport Layer Security/Secure Sockets Layer), secures the internet by ensuring the following core services, often referred to as the **CIA Triad** (Confidentiality, Integrity, Availability) plus Non-repudiation21:

Service Cryptographic Tool How it Secures the Internet
Confidentiality Encryption (Symmetric & Asymmetric) Data (like passwords, credit card numbers, and emails) is scrambled into ciphertext, making it unreadable to eavesdroppers.
Integrity Hashing and Digital Signatures Ensures that data hasn't been altered during transmission. The recipient recalculates the hash and compares it to the hash sent by the sender.
Authenticity Digital Certificates and Digital Signatures Verifies the identity of the sender and the server, ensuring you are talking to the legitimate party.
Non-Repudiation Digital Signatures Provides proof of the data's origin and integrity, preventing the sender from falsely denying they sent the message.

Importance for Authentication

Cryptography is **essential** for authentication on the internet because it provides a reliable, mathematical proof of identity22.

  • **Digital Certificates (PKI):** When your browser connects to a secure website (**HTTPS**), the server presents a **Digital Certificate** signed by a trusted third party (Certificate Authority) using the server's **Private Key**. Your browser uses the corresponding **Public Key** to verify this signature, confirming the server's identity. This proves you are talking to the real website.
  • **Digital Signatures:** A sender uses their **Private Key** to 'sign' a message (encrypt a hash of the message)23. The receiver uses the sender's **Public Key** to decrypt the hash24. If the decryption succeeds, it proves the message came from the owner of that private key, thereby authenticating the sender.
  • **Password Storage:** **Hash functions** are used to store passwords securely25. When a user logs in, the system hashes the entered password and compares it to the stored hash. Since the hash is **one-way**, an attacker stealing the database only gets the hash, not the actual password26.

Common Cryptography Terminologies

Terminology Definition
Plaintext The original, readable form of data or a message.
Ciphertext The encrypted, unreadable form of the data.
Encryption The process of converting plaintext into ciphertext using an algorithm and a key.
Decryption The process of converting ciphertext back into plaintext.
Key A secret value (a string of bits) used with a cipher algorithm to encrypt and decrypt data.
Algorithm (or Cipher) The mathematical procedure or set of rules used for encryption and decryption.
Hash Value A fixed-size output (or message digest) generated by a hash function. Used for integrity checks.
Cryptanalysis The study of methods for obtaining the meaning of encrypted information without access to the secret key; the "code-breaking" aspect.
Digital Signature A mathematical technique used to validate the authenticity and integrity of a message or document.
TLS/SSL Transport Layer Security (Secure Sockets Layer is its predecessor); the cryptographic protocol that secures communication over a computer network (e.g., in HTTPS).
