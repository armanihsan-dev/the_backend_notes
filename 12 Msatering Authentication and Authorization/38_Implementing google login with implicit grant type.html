Google Implicit Grant Implementation (Deprecated)

This is an excellent practical request! You are correct that the **Implicit Grant Flow** delivers the token directly to the client, which is then responsible for passing it to the server for validation.

⚠️ **IMPORTANT SECURITY WARNING:**

Before diving in, please be aware that the **Implicit Grant Flow** is **deprecated** by the **OAuth 2.0 Security Best Current Practice** and is considered **insecure for production use**. It has been replaced by the **Authorization Code Flow with PKCE (Proof Key for Code Exchange)** for all public clients (like SPAs).

However, since you requested it for learning purposes, I will show you the exact implementation of the Implicit Flow.

Implementation Structure Overview

We will build this in three parts:

  • **Google Cloud Setup**: Setting up the credentials.
  • **Client** (index.html): Initiates the login and extracts the token from the URL fragment.
  • **Server** (server.js): Receives the token from the client, verifies its authenticity with Google, and returns the verified user profile.

I will generate the files for the client and server below.

Part 1: Prerequisites and Setup

1. Google Console Setup

  • **Create a Project**: In Google Cloud Console, create a new project.
  • **Configure Consent Screen**: Go to "OAuth consent screen" and set up basic app information.
  • **Create Credentials**: Go to "Credentials" -> "Create Credentials" -> "OAuth client ID."
    • Select Application Type: **Web application**.
    • Set **Authorized JavaScript origins** to: http://localhost:3000 (or whatever port you use).
    • Set **Authorized redirect URIs** to: http://localhost:3000/ (or the exact path your HTML page is served from).
    • **Crucially, note down your YOUR_GOOGLE_CLIENT_ID**.

2. Server Setup

For the server, you will need Node.js and the following dependencies. Create a directory for your project, and save the following files inside it.

Part 2 & 3: Code Implementation (Client and Server)

We will use port **3000** for the server in this example.

The Express Server (server.js)

This server will:

  • Serve the static index.html file from a public directory.
  • Listen for a **POST** request on /api/verify-token.
  • Use the **GoogleAuthLibrary** to verify the ID Token against Google's public keys.
  • Return the verified user data.

Replace YOUR_GOOGLE_CLIENT_ID with the ID you obtained from the Google Cloud Console:

server.js (Node.js/Express)
const express = require('express');
const { OAuth2Client } = require('google-auth-library');
const path = require('path');
const cors = require('cors');

// ⚠️ Replace this with your actual Google Client ID
const CLIENT_ID = 'YOUR_GOOGLE_CLIENT_ID'; 

// Initialize the Google OAuth2 client for token verification
const client = new OAuth2Client(CLIENT_ID);

const app = express();
const PORT = 3000;

// Middleware setup
app.use(cors()); // Enable CORS if client runs on a different port/domain (though here they are the same)
app.use(express.json()); // To parse JSON bodies from client POST requests
app.use(express.static(path.join(__dirname, 'public'))); // Serve the static index.html

// --- ID TOKEN VERIFICATION ENDPOINT ---
app.post('/api/verify-token', async (req, res) => {
    const { id_token } = req.body;

    if (!id_token) {
        return res.status(400).send({ error: 'ID Token is missing in the request body.' });
    }

    try {
        // 1. Verify the ID token using the official Google library
        const ticket = await client.verifyIdToken({
            idToken: id_token,
            audience: CLIENT_ID, // Ensure the token is intended for our app
        });

        // 2. Extract the payload (verified user data)
        const payload = ticket.getPayload();
        
        // 3. Extract the relevant user information for the client profile
        const profile = {
            id: payload['sub'],
            email: payload['email'],
            name: payload['name'],
            picture: payload['picture'],
            isVerified: payload['email_verified']
        };

        console.log(`Token verified successfully for user: ${profile.email}`);
        
        // 4. Send the verified, clean user profile back to the client
        res.status(200).json({ success: true, profile });

    } catch (error) {
        console.error('Token verification failed:', error.message);
        res.status(401).send({ success: false, error: 'Invalid or expired ID Token.' });
    }
});

// Serve the index.html from the root path
app.get('/', (req, res) => {
    res.sendFile(path.join(__dirname, 'public', 'index.html'));
});

app.listen(PORT, () => {
    console.log(`Server running on http://localhost:${PORT}`);
    console.log(`Static files served from: ${path.join(__dirname, 'public')}`);
});

    <script>
        // ⚠️ Replace this with your actual Google Client ID
        const CLIENT_ID = 'YOUR_GOOGLE_CLIENT_ID';
        // This must match the Authorized redirect URI set in the console (http://localhost:3000/)
        const REDIRECT_URI = 'http://localhost:3000/'; 
        const SCOPES = 'profile email';
        const SERVER_VERIFY_ENDPOINT = '/api/verify-token';

        const appContent = document.getElementById('app-content');

        // Helper to parse the URL fragment (the part after #)
        function parseFragment(hash) {
            const params = {};
            if (hash.startsWith('#')) {
                hash = hash.substring(1);
            }
            hash.split('&').forEach(pair => {
                const [key, value] = pair.split('=');
                if (key && value) {
                    params[decodeURIComponent(key)] = decodeURIComponent(value);
                }
            });
            return params;
        }

        // Function to initiate the Implicit Grant flow (available globally for the button)
        function login() {
            const authUrl = `https://accounts.google.com/o/oauth2/v2/auth?` +
                `client_id=${CLIENT_ID}&` +
                `redirect_uri=${REDIRECT_URI}&` +
                `response_type=id_token token&` + // Key for Implicit Flow
                `scope=${SCOPES}&` +
                `state=random_state_string&` + // State parameter for CSRF protection
                `nonce=${Math.random().toString(36).substring(2, 15)}`; // Nonce for replay attack prevention
            
            // Redirect the user
            window.location.href = authUrl;
        }

        // Function to send the token to the backend for verification
        async function verifyTokenWithServer(idToken) {
            try {
                appContent.innerHTML = `
Verifying token with server...
`;
                
                const response = await fetch(SERVER_VERIFY_ENDPOINT, {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({ id_token: idToken })
                });

                const data = await response.json();

                if (data.success && data.profile) {
                    renderProfile(data.profile);
                } else {
                    console.error('Server verification failed:', data.error);
                    renderError('Token verification failed. ' + (data.error || 'Server error.'));
                }

            } catch (error) {
                console.error('Network error during token verification:', error);
                renderError('Could not reach the server for verification. Check server.js console.');
            }
        }

        // UI rendering functions
        function renderLogin() {
            appContent.innerHTML = `
                <p>Click below to log in with Google and receive an ID token via the URL fragment.</p>
                <button class="login-button" onclick="login()">Sign in with Google</button>
                <div class="status-message" id="message-box">Awaiting user login...</div>
            `;
        }

        function renderProfile(profile) {
            appContent.innerHTML = `
                <h2>Welcome, ${profile.name}!</h2>
                <div class="profile-card">
                    <img src="${profile.picture || 'https://placehold.co/80x80/cccccc/333333?text=User'}" 
                         alt="User Profile Picture" onerror="this.onerror=null;this.src='https://placehold.co/80x80/cccccc/333333?text=User'">
                    <p><strong>Email:</strong> ${profile.email}</p>
                    <p><strong>Google ID:</strong> ${profile.id}</p>
                    <p><strong>Status:</strong> <span style="color: green;">Verified by Server</span></p>
                </div>
                <button class="login-button" onclick="window.location.href='${REDIRECT_URI}'" style="margin-top: 20px;">Logout (Clear URL)</button>
                <div class="status-message" style="background-color: #e6ffed; color: #1e8449;">
                    The server successfully validated the token and provided this clean profile data.
                </div>
            `;
        }

        function renderError(message) {
            appContent.innerHTML = `
                <h2>Authentication Failed</h2>
                <div class="status-message" style="background-color: #ffe6e6; color: #c0392b; border: 1px solid #c0392b;">
                    <strong>Error:</strong> ${message}
                </div>
                <button class="login-button" onclick="login()" style="margin-top: 20px;">Try Again</button>
            `;
        }

        // Main initialization logic to check the URL fragment on load
        function init() {
            const fragment = window.location.hash;

            if (fragment) {
                appContent.innerHTML = `
Token detected in URL fragment. Processing...
`;
                const params = parseFragment(fragment);
                const idToken = params['id_token'];

                if (idToken) {
                    // We successfully received the token. Send it to the server for verification.
                    verifyTokenWithServer(idToken);
                    
                    // Clean the URL fragment to prevent re-triggering on refresh
                    window.history.replaceState(null, '', window.location.pathname);
                    
                } else if (params['error']) {
                    renderError(`Google returned an error: ${params['error_description'] || params['error']}`);
                } else {
                    renderError('Fragment detected but no ID token found.');
                    console.warn('URL fragment parameters:', params);
                    renderLogin(); // Show login button if token is missing but fragment exists
                }

            } else {
                // No token in the URL fragment, show the login button
                renderLogin();
            }
        }

        window.onload = init;
    </script>

How to Run This Example

  1. **Save Files:** Create a main directory. Save the `server.js` and `package.json` code above directly into the main directory. Create a subdirectory named `public` and save the `index.html` code block into it.
  2. **Install Dependencies:** Open your terminal in the main directory and run `npm install`.
  3. **Replace Placeholders:** Critically, replace all instances of `YOUR_GOOGLE_CLIENT_ID` in **both** `server.js` and the JavaScript section of `public/index.html` with your actual Google Client ID.
  4. **Start Server:** Run `node server.js` or `npm start`.
  5. **Test:** Open `http://localhost:3000` in your browser. Click the "Sign in with Google" button and follow the flow.
