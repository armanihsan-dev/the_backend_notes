SCP (Secure Copy Protocol)

Secure Copy Protocol (SCP) is a network protocol that enables secure file transfer between a local host and a remote host, or between two remote hosts. It uses SSH (Secure Shell) for data transfer and authentication, which ensures the data is encrypted and secure.

Definition

SCP (Secure Copy Protocol)
A command-line utility for securely copying files and directories between different hosts on a network. It uses SSH for security, meaning all data transferred is encrypted.
Local Host (Client)
The computer you are currently working on.
Remote Host (Server)
The computer you are connecting to, which is typically a server.

General Syntax

The basic syntax for the scp command is:

scp [options] [source] [destination]
  • options: Various flags to modify the command's behavior (e.g., -r for recursive copy, -P for a specific port).
  • source: The file or directory you want to copy.
  • destination: The location where you want to copy the file or directory.

When specifying a remote location, the format is [user]@[host]:[path].

  • user: The username on the remote host.
  • host: The IP address or hostname of the remote host.
  • path: The directory path on the remote host.

Copying a File from a Server to a Client

This is often referred to as a "pull" operation. You are pulling a file from the remote server to your local machine.

Syntax:

scp [options] [user]@[server]:[remote_file_path] [local_destination_path]

Example:

Let's say you want to copy a file named report.txt from the /home/john/documents/ directory on the server with IP address 192.168.1.100 to your local home directory (~/). Your username on the server is john. 

scp john@192.168.1.100:/home/john/documents/report.txt ~/

After running this command, you will be prompted for john's password on the remote server. Once authenticated, the report.txt file will be copied to your local home directory.

Copying a File from a Client to a Server

This is often referred to as a "push" operation. You are pushing a file from your local machine to the remote server.

Syntax:

scp [options] [local_file_path] [user]@[server]:[remote_destination_path]

Example:

Let's say you want to copy a file named presentation.pptx from your local documents folder (~/documents/) to the /home/john/projects/ directory on the server with IP address 192.168.1.100. Your username on the server is john. 

scp ~/documents/presentation.pptx john@192.168.1.100:/home/john/projects/

Upon execution, you will be prompted for john's password on the remote server. After successful authentication, the presentation.pptx file will be copied from your local machine to the specified directory on the server.
