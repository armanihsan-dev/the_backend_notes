The Story of the World Wide Web

The **World Wide Web** is one of the most transformative inventions in human history. To understand its story, it's important to differentiate it from the **internet**.

  • **Internet**: A vast network of interconnected computers.
  • **World Wide Web (WWW)**: An information-sharing system that sits on top of the internet.

The Birth of the Web: A "Vague but Exciting" Idea

The story begins in **1989** at **CERN**. British computer scientist **Tim Berners-Lee** was frustrated by the difficulty of sharing information among scientists using different systems. He proposed a "universal linked information system."

His memo, "Information Management: A Proposal," was famously annotated with the words: **"Vague but exciting."**

By the end of **1990**, he had developed the three foundational technologies:

  • **HTML** (HyperText Markup Language): For creating web pages.
  • **URI** (Uniform Resource Identifier): A unique web address (URL).
  • **HTTP** (Hypertext Transfer Protocol): For communication between browsers and servers.

He also built the first browser, **WorldWideWeb**, and the first web server. In **1993**, CERN made the web software royalty-free, allowing it to flourish as an open platform.

The Evolution of the Web

Web 1.0: The "Read-Only" Web (1991-2004)

  • **Static pages**: Users were primarily consumers of information.
  • **Limited interactivity**: Little opportunity to create or contribute content.
  • **Directories**: Early sites acted as portals to navigate pages.
  • **The Dot-Com Boom**: Commercialization led to the "dot-com bubble."

Key moment: The release of the **Mosaic browser in 1993**, the first graphical browser, making the web user-friendly.

Web 2.0: The "Read-Write" or Social Web (2004-Present)

  • **User-generated content**: Users became active creators.
  • **Social networking**: Rise of platforms like Facebook, YouTube, and Twitter.
  • **Interactive applications**: Dynamic and responsive web apps.

This phase transformed the web into a collaborative and social space.

Web 3.0: The "Semantic" or Decentralized Web (Future-Focused)

  • **Decentralization**: Moving away from large tech companies using technologies like **blockchain**.
  • **Semantic Web**: Data is structured so machines can understand it.
  • **AI & Machine Learning**: More effective and personalized experiences.
  • **Immersive experiences**: Integration of VR and AR.

Pre-Web Document Access

Before the WWW, there was no single universal system. Accessing documents was complex and fragmented.

The Pre-Web Document Access Process

  • **File Transfer Protocol (FTP)**: Required specific addresses and credentials to manually transfer files.
  • **Gopher**: A menu-driven system for hierarchical document access.
  • **Telnet**: Allowed remote login to a computer, requiring knowledge of that specific system's commands.
  • **Email Attachments**: Simple but limited to person-to-person exchange.

These methods were all disconnected. The WWW solved this by creating a unified way to link documents seamlessly.
