Networking Topics

Tunneling

Think of tunneling as creating a secret, secure passage through a public space. In networking, it's a way of wrapping one type of data packet inside another so it can travel safely and secretly over a public network like the internet. It's like putting a letter inside another sealed envelope before you drop it in the mail.

VPN (Virtual Private Network)

A VPN is an encrypted tunnel between your device and a server. It makes it look like you're accessing the internet from the server's location, hiding your real IP address and protecting your data from anyone who might be watching your network traffic.

NSP (Network Service Provider) or ISP (Internet Service Provider)

These are the companies you pay to get internet access. They own and manage the large networks that connect you to the rest of the world.

PDU (Protocol Data Unit)

A PDU is a unit of data that is created at a specific layer of the network stack. As data moves down the layers, it's encapsulated into different PDUs. For example, a packet is a PDU at the network layer (Layer 3) and a frame is a PDU at the data link layer (Layer 2).

Dark Web

The dark web is a part of the internet that is intentionally hidden. You can't access it with a normal browser or search engine; it requires special software, like the Tor browser, to find and access. It's often used for anonymity.

ICMP (Internet Control Message Protocol)

ICMP is a protocol used by network devices to send error messages and operational information. A common use is to check if a device is active and reachable on the network.

Networking Terms

  • Bandwidth: The maximum capacity of a network connection. Think of it as the width of a water pipe; a wider pipe (more bandwidth) can theoretically handle more water (data) at once.
  • Throughput: The actual amount of data that successfully transfers over a network in a given time. This is often less than the bandwidth due to factors like network congestion and latency. It's the actual amount of water that comes out of the pipe.
  • Latency: The delay it takes for a data packet to travel from its source to its destination. It's like the time it takes for a ping pong ball to go from one side of the table to the other.
  • WLAN (Wireless Local Area Network): A network that uses wireless communication to connect devices within a small, localized area, such as a home or office. It's the WiFi network in your house.

Practical Command Usage

All these commands are used in a terminal or command prompt.

Ping 🧪

Use ping to check if a device is reachable and to measure the latency to that device.

ping google.com sends a series of packets to Google's server and reports how long they take to come back. A successful ping means the device is online and you have a connection to it.

Traceroute 🗺️

Use traceroute (or tracert on Windows) to see the path data packets take to get to a destination.

traceroute google.com shows the series of routers (or "hops") that a packet travels through from your computer to Google's server. This is useful for figuring out where a connection is failing.

Curl 🌐

Use curl to transfer data with URLs. It's an extremely versatile tool for making requests to web servers. 

curl https://example.com

downloads the HTML source code of the example.com website and prints it to the terminal. 

curl -O https://example.com/file.zip

downloads a file and saves it with the same filename.

Wget ⬇️

Use wget to download files directly from the web. It's simpler than curl for basic file downloads and is excellent for scripting. 

wget https://example.com/document.pdf

downloads the PDF file to your current directory. wget is very useful for downloading many files from a website, as it supports recursive downloading.
