MongoDB Create Operation Notes

The **Create operation** in MongoDB (often referred to as **Insert**) is used to add **new documents** to a collection. If the target collection does not exist, MongoDB creates it implicitly upon the first insertion. The primary methods for this are insertOne() for a single document and insertMany() for multiple documents.

1. MongoDB Shell (mongosh)

You interact with MongoDB using the mongosh terminal utility. The commands operate on the currently selected database (db).

Syntax and Definition

Method Definition Syntax
db.collection.insertOne() Inserts a **single** document into a collection. db.collection.insertOne( <document>, <options> )
db.collection.insertMany() Inserts **multiple** documents (an array of documents) into a collection. db.collection.insertMany( [ <document 1>, <document 2>, ... ], <options> )

db: Refers to the current database.
collection: The name of the collection you're inserting into.
<document>: The data to insert, represented as a JSON-like object (BSON in MongoDB).
_id: If you don't provide an _id field, MongoDB automatically adds a unique ObjectId for you.

Practical Example (Shell)

Select a database (or create it if it doesn't exist):

JavaScript

use universityDB

Insert a Single Document (using insertOne):

JavaScript

db.students.insertOne(
  {
    name: "Alice Johnson",
    studentId: 1001,
    major: "Computer Science",
    gpa: 3.8
  }
)

Output (Example):

{
  acknowledged: true,
  insertedId: ObjectId("...") // Unique ID generated by MongoDB
}

Insert Multiple Documents (using insertMany):

JavaScript

db.students.insertMany([
  {
    name: "Bob Williams",
    studentId: 1002,
    major: "History",
    gpa: 3.2
  },
  {
    name: "Charlie Brown",
    studentId: 1003,
    major: "Biology",
    gpa: 4.0
  }
])

Output (Example):

{
  acknowledged: true,
  insertedIds: [
    ObjectId("..."),
    ObjectId("...")
  ]
}

2. Node.js (with MongoDB Driver)

In a Node.js application, you use the official mongodb driver to connect and perform operations. These methods are typically asynchronous (return Promises).

Setup (Node.js)

Assuming you have Node.js and the mongodb package installed (npm install mongodb), you'd set up a basic connection:

JavaScript

const { MongoClient }  = require('mongodb');

// Replace with your MongoDB connection string
const uri = "mongodb://localhost:27017"; 
const client = new MongoClient(uri);

async function run() {
  try {
    await client.connect();
    const database = client.db('universityDB');
    const students = database.collection('students');
    
    // --- Insert Operations will go here ---
    
  } finally {
    // Ensures that the client will close when you finish/error
    await client.close();
  }
}
run().catch(console.dir);

Practical Example (Node.js)

We'll place the following code inside the try block of the run function above.

Insert a Single Document (using insertOne):

JavaScript

// 1. Insert a Single Document
const alice = {
  name: "Alice Johnson (Node)",
  studentId: 2001,
  major: "Art",
  gpa: 3.9
};

const insertOneResult = await students.insertOne(alice);

console.log(`1 document inserted with the _id: ${insertOneResult.insertedId}`);

Insert Multiple Documents (using insertMany):

JavaScript

// 2. Insert Multiple Documents
const newStudents = [
  {
    name: "David Lee",
    studentId: 2004,
    major: "Math",
    gpa: 3.5
  },
  {
    name: "Eve Green",
    studentId: 2005,
    major: "Physics",
    gpa: 3.1
  }
];

const insertManyResult = await students.insertMany(newStudents);

console.log(`${insertManyResult.insertedCount} documents inserted.`);
console.log("Inserted IDs:", insertManyResult.insertedIds);
