MongoDB Data Management: mongoimport & mongoexport

Perfect — this is a smart question because mongoimport and mongoexport are essential MongoDB tools for data backup, migration, and integration.

Let’s go step by step so you know exactly what to learn and practice 👇

⚙️ 1. What are mongoimport and mongoexport?

mongoimport → used to insert or restore data into MongoDB from JSON, CSV, or TSV files.

mongoexport → used to extract or back up data from MongoDB into JSON or CSV files.

👉 Think of it like:

mongoexport = export data out of MongoDB

mongoimport = import data into MongoDB

🧠 2. Key Topics You Should Learn

Here’s a roadmap of what to cover for both commands:

🔹 A. mongoimport — Importing Data

🧩 Basic Syntax:

mongoimport --db <database> --collection <collection> --file <path/to/file> [options]

🧠 Learn These Options:

Option Description
--db Target database name
--collection Collection name
--file Path to your data file
--jsonArray Use when importing a JSON array (like [ {...}, {...} ])
--type File type: json, csv, or tsv
--fields Specify CSV/TSV column names
--headerline Use first line of CSV as field names
--drop Drop the existing collection before importing
--uri Use connection string (e.g., mongodb://localhost:27017)

🧪 Practice These Examples:

1️⃣ JSON array format

mongoimport --db shop --collection products --file products.json --jsonArray

2️⃣ NDJSON format (no --jsonArray)

mongoimport --db shop --collection products --file products.json

3️⃣ CSV format

mongoimport --db shop --collection users --type csv --file users.csv --headerline

4️⃣ Drop before importing (to reset collection)

mongoimport --db shop --collection products --drop --file products.json --jsonArray
🔹 B. mongoexport — Exporting Data

🧩 Basic Syntax:

mongoexport --db <database> --collection <collection> --out <output-file> [options]

🧠 Learn These Options:

Option Description
--db Database name
--collection Collection name
--out Output file path
--type Output format: json or csv
--fields Fields to export (comma-separated)
--query Export only matching documents
--pretty Make JSON human-readable
--uri Use MongoDB connection string

🧪 Practice These Examples:

1️⃣ Export collection to JSON

mongoexport --db shop --collection products --out products.json

2️⃣ Export specific fields

mongoexport --db shop --collection products --out products.json --fields name,price,category

3️⃣ Export to CSV

mongoexport --db shop --collection users --type=csv --fields name,email,age --out users.csv

4️⃣ Export with filter (query)

mongoexport --db shop --collection products --query '{"category": "Electronics"}' --out electronics.json

🔍 3. Learn the Difference Between Formats

Format Use Case mongoimport Syntax mongoexport Syntax
JSON Array Easy to view, multiple docs in one array --jsonArray Default JSON output
NDJSON Each document on new line (best for pipelines) (no flag) --type=json
CSV For spreadsheets, Excel, or data tools --type=csv --headerline --type=csv

💾 4. Practice Backup and Restore Workflow

1️⃣ Export your MongoDB data

mongoexport --db shop --collection products --out backup.json

2️⃣ Drop the collection

mongosh
use shop
db.products.drop()

3️⃣ Re-import it

mongoimport --db shop --collection products --file backup.json

🎯 This gives you real experience in backing up and restoring data.

🧰 5. Optional Advanced Topics (for deeper mastery)

Use gzip compressed imports/exports

mongoexport --db shop --collection products --out products.json.gz --gzip
mongoimport --db shop --collection products --file products.json.gz --gzip

Use --uri for remote databases (Atlas or Docker)

Automate exports with cron jobs or shell scripts

Combine with mongodump / mongorestore for full database backups
