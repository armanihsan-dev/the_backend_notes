MongoDB & Node.js Connection Guide (Native Driver)

Understood. If you don't want to use Mongoose, you should use the official MongoDB Node.js Driver. This driver provides the low-level functions to connect to MongoDB and perform operations directly.

Here is the complete guide for setting up your MongoDB server and connecting your Node.js client using the native driver.

1. Project Setup and Installation

First, set up your Node.js project and install the necessary package.

Initialize Project:

Bash

mkdir node-mongo-driver-app
cd node-mongo-driver-app
npm init -y

Install the MongoDB Driver:

Bash

npm install mongodb

Create the Application File:

Create an index.js file for your application code.

2. Node.js Client Connection Logic

The connection is handled by the MongoClient class from the installed driver. You will use async/await to ensure the connection is established before running database operations.

Create and edit your index.js file:

// index.js
import { MongoClient } from 'mongodb';

// 1. Connection URI (Replace with your actual string)
// Local: 'mongodb://127.0.0.1:27017' (for localhost)
// Atlas: 'mongodb+srv://<user>:<password>@cluster0.abcde.mongodb.net'
const uri = "mongodb://127.0.0.1:27017";

// 2. Create a new MongoClient
const client = new MongoClient(uri);

async function run() {
    try {
        // 3. Connect the client to the server (Awaits the asynchronous connection)
        await client.connect();
        console.log("&#9989; Successfully connected to MongoDB!");

        // 4. Specify the database to use
        const database = client.db('myFirstDatabase');

        // 5. Specify the collection to use
        const collection = database.collection('users');

        // 6. Perform a CRUD Operation (Example: Insert One Document)
        const doc = { name: "Alice", email: "alice@example.com", age: 30 };
        const result = await collection.insertOne(doc);
        console.log("&#128109; New document inserted with ID: ${result.insertedId}");

        // 7. Perform a Read Operation (Example: Find the document we just created)
        const query = { name: "Alice" };
        const foundUser = await collection.findOne(query);
        console.log("&#128269; Found document:", foundUser);

    } catch (e) {
        // Log any errors that occur during connection or operations
        console.error("&#10060; An error occurred:", e);
    } finally {
        // 8. Close the connection when done (Always important!)
        await client.close();
        console.log("&#128279; Connection closed.");
    }
}

run();

3. Running the Application

Execute your Node.js script from the terminal:

Bash

node index.js

Key Connection Points

  • import { MongoClient } from 'mongodb';: Imports the core class from the driver, which is your entry point to the database.
  • const client = new MongoClient(uri);: Creates a Client Instance. At this point, the connection is not yet established. It just sets up the connection parameters.
  • await client.connect();: This is the crucial step. It is an asynchronous network operation that establishes the physical connection to the MongoDB server. The await keyword ensures the code execution waits until the handshake is complete and the connection is confirmed.
  • client.db('myFirstDatabase'): Once connected, you get a reference to a specific database. If the database doesn't exist, MongoDB will create it implicitly upon first data write.
  • database.collection('users'): You then get a reference to a specific collection (like a table in SQL).
