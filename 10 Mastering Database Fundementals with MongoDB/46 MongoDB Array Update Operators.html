MongoDB Array Update Operators

Understanding the core array operators in MongoDB is key to effective data manipulation.

Here is a clear breakdown of the differences between $pull, $push, and $addToSet, complete with syntax, definitions, and how they work with the same example document structure you shared.

📚 MongoDB Array Update Operators

Operator Action Definition
$pull Remove Removes all array elements that match a specified query condition.
$push Add Appends an item (or multiple items) to the end of an array.
$addToSet Add Unique Adds an item to an array only if the item is not already present in the array.

1. $pull (Removal)

📝 Definition & Purpose

The $pull operator is used to remove elements from an existing array. It is the opposite of $push. When the array contains objects (like your cart array), you provide a query object to match the element(s) you want to remove.

🖥️ Syntax

JavaScript

{ $pull: { <array_field>: <condition> } }

💡 How It Works (Example)

Let's remove the course with courseId: "690710af466326f7b4d984b0".

JavaScript

db.sessions.updateOne(
  { _id: sid }, // Query: Find the session document
  {
    $pull: {
      "data.cart": { // Target the 'data.cart' array
        courseId: "690710af466326f7b4d984b0" // Condition: Remove element(s) matching this courseId
      }
    }
  }
)
Result: MongoDB scans the data.cart array and permanently deletes any object that satisfies the criteria.

2. $push (Addition)

📝 Definition & Purpose

The $push operator is used to add a new element to the end of an existing array. If you need to add multiple elements, you can use the $each modifier within $push. It allows for duplicates.

🖥️ Syntax

JavaScript

{ $push: { <array_field>: <value_to_add> } }

💡 How It Works (Example)

Let's add a new course to the cart.

JavaScript

const newCourse = {
  courseId: "a1b2c3d4e5f67890abcdef12",
  qty: 1
}

db.sessions.updateOne(
  { _id: sid }, // Query: Find the session document
  {
    $push: {
      "data.cart": newCourse // Action: Add the newCourse object to the end of the array
    }
  }
)
Result: The newCourse object is appended to the end of the data.cart array. If you run this operation again, the array will contain two identical newCourse objects (it allows duplicates).

3. $addToSet (Unique Addition)

📝 Definition & Purpose

The $addToSet operator is a special form of $push. It adds an element to an array only if the element does not already exist in the array. This is useful when you want the array to behave like a mathematical set, where all members are unique.

🖥️ Syntax

JavaScript

{ $addToSet: { <array_field>: <value_to_add> } }

💡 How It Works (Example)

Let's attempt to add the same new course to the cart using $addToSet.

JavaScript

const newCourse = {
  courseId: "a1b2c3d4e5f67890abcdef12",
  qty: 1
}

db.sessions.updateOne(
  { _id: sid }, // Query: Find the session document
  {
    $addToSet: {
      "data.cart": newCourse // Action: Add the newCourse object if it's not already in the array
    }
  }
)
Result:
  • First time: The newCourse object is added to the array.
  • Second time (and subsequent times): MongoDB checks if an identical object already exists in the data.cart array. Since it does, no change is made to the array, ensuring the course is not duplicated.

🎯 Key Takeaway

  • Use $pull when you need to **remove** an item (or group of items) from an array.
  • Use $push when you need to **add** an item and **allow duplicates**.
  • Use $addToSet when you need to **add** an item but **prevent duplicates**.
