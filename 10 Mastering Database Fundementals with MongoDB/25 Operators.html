MongoDB Operators

MongoDB operators are what give it its power and flexibility. They are special keywords that start with a dollar sign ($) and are used in queries, updates, aggregations, and projections to define conditions or perform transformations.

Here's a breakdown of MongoDB operators, focusing on the most commonly used categories and examples in Node.js.

1. Query Operators (Selection) 🔎

These are the most common operators, used in the find() or findOne() methods to select documents based on criteria.

CategoryOperatorUsage (Node.js/Shell)Explanation
Comparison$eq{ "field": { "$eq": "value" } }Matches values that are **equal** to a specified value. (Often implied, i.e., { "field": "value" } is equivalent).
Comparison$ne{ "field": { "$ne": "value" } }Matches values that are **not equal** to a specified value.
Comparison$gt{ "age": { "$gt": 25 } }Matches values that are **greater than** the specified value.
Comparison$lt{ "age": { "$lt": 30 } }Matches values that are **less than** the specified value.
Comparison$gte, $lte{ "price": { "$gte": 10 } }Matches values **greater than or equal to** (or less than or equal to).
Comparison$in{ "status": { "$in": ["A", "D"] } }Matches any of the values specified in an array (e.g., status is "A" **OR** "D").
Comparison$nin{ "size": { "$nin": ["S", "M"] } }Matches none of the values specified in an array (e.g., size is **NOT** "S" **AND** **NOT** "M").
Logical$and{ "$and": [ { "qty": 10 }, { "price": 5 } ] }Joins query clauses with a logical **AND** (implied default).
Logical$or{ "$or": [ { "qty": 10 }, { "price": 5 } ] }Joins query clauses with a logical **OR**.
Logical$not{ "field": { "$not": { "$gt": 10 } } }Inverts the effect of a query expression (e.g., not greater than 10).
Logical$nor{ "$nor": [ { "price": 1.99 }, { "sale": true } ] }Joins query clauses with a logical **NOR** (returns documents that fail both conditions).
Element$exists{ "rating": { "$exists": true } }Matches documents that have the specified field, including fields whose value is null.
Element$type{ "field": { "$type": "string" } }Matches documents where the field is of a specified BSON type.
Array$all{ "tags": { "$all": ["blue", "sale"] } } }Matches documents where the array field contains **all** the specified elements.
Array$size{ "items": { "$size": 3 } }Matches arrays that have a specified number of elements.

Node.js Example using Logical Operators:

// Find documents where status is 'A' AND (qty is less than 10 OR price is 5)
const query = {
  status: 'A',
  $or: [
    { qty: { $lt: 10 } },
    { price: 5 }
  ]
};

const result = await collection.find(query).toArray();

2. Update Operators (Modification) 🛠️

These operators are used in the second parameter of methods like updateOne(), updateMany(), and findOneAndUpdate() to specify how to modify the fields.

CategoryOperatorUsage (Node.js/Shell)Explanation
Field$set{ "$set": { "name": "New Name", "price": 20 } }**Sets** the value of a field. **Most used** update operator.
Field$unset{ "$unset": { "oldField": "" } }**Removes** the specified field from a document.
Field$inc{ "$inc": { "views": 1 } }**Increments** a field by a specified value. Great for counters.
Field$mul{ "$mul": { "price": 0.9 } }**Multiplies** the value of a field by a specified number.
Field$rename{ "$rename": { "oldField": "newField" } }**Renames** a field.
Field$setOnInsert{ "$setOnInsert": { "createdAt": new Date() } }Sets the value of a field **only if** the update operation performs an **upsert** (insert).
Array$push{ "$push": { "scores": 89 } }**Appends** a specified value to an array.
Array$pull{ "$pull": { "tags": "obsolete" } }**Removes** all instances of a value (or documents matching a criteria) from an array.
Array$addToSet{ "$addToSet": { "tags": "new" } }**Adds** a value to an array only if the value is **not already present** (maintains uniqueness).

Node.js Example using Update Operators:

// Update a user: set last active time, increment login count, and add a tag if it doesn't exist
const updateOperation = {
  $set: { lastActive: new Date() },
  $inc: { loginCount: 1 },
  $addToSet: { roles: "authenticated" }
};

const result = await collection.updateOne({ email: 'user@example.com' }, updateOperation);

3. Aggregation Operators (Data Transformation) 📊

These operators are used within the MongoDB Aggregation Pipeline (using the aggregate() method) to transform documents, calculate values, and restructure the data.

OperatorUsage (Node.js/Shell)Explanation
$match{ "$match": { "status": "A" } }**Filters** the documents (uses Query Operators). Typically the first stage.
$group{ "$group": { "_id": "$dept", "total": { "$sum": "$salary" } } }**Groups** documents by a specified field and performs calculations (e.g., $sum, $avg, $max). **Most used** aggregation operator.
$project{ "$project": { "_id": 0, "name": 1, "totalPrice": { "$multiply": ["$qty", "$price"] } } }**Reshapes** each document in the stream, creating new fields, renaming fields, or suppressing existing fields.
$sort{ "$sort": { "price": -1 } }**Orders** the documents (1 for ascending, -1 for descending).
$limit, $skip{ "$limit": 10 }Restricts the number of documents passed to the next stage (pagination).
$unwind{ "$unwind": "$items" }**Deconstructs** an array field from the input documents to output a document for each element.

Node.js Aggregation Example:

// Calculate the average price grouped by category
const pipeline = [
  { $match: { status: 'available' } },
  { $group: {
      _id: "$category",
      averagePrice: { $avg: "$price" },
      count: { $sum: 1 }
  }}
];

const results = await collection.aggregate(pipeline).toArray();

4. Geospatial Operators (Location) 🗺️

Used for querying location data stored in GeoJSON format.

OperatorUsage (Node.js/Shell)Explanation
$near{ "loc": { "$near": { "$geometry": { ... } } } }Returns documents ordered by proximity to a specified point.
$geoWithin{ "loc": { "$geoWithin": { "$geometry": { ... } } } }Selects documents whose geospatial data is entirely within a specified shape (e.g., a polygon).

Summary of Most Used Operators

If you only learn five operators, focus on these, as they cover 90% of basic MongoDB interactions:

  • $set: To change a field's value (Update).
  • $inc: To increment a numeric field (Update).
  • $or: To combine multiple query conditions (Query).
  • $in: To check if a field's value is in a list of possibilities (Query).
  • $group: To summarize and aggregate data (Aggregation).
