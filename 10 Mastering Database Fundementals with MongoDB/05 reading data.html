MongoDB Querying Guide: Reading Documents

1. Reading Documents via MongoDB Shell (Terminal) 💻

The MongoDB Shell uses the db.collection.find() method to query and retrieve documents.

Basic Syntax

The find() method takes up to two arguments:

  • Query Criteria (Filter): An optional document that specifies the selection filter. This is where you put your conditions (e.g., { price: 10 }).
  • Projection (Fields): An optional document that specifies which fields to return. (e.g., { name: 1, _id: 0 }). 
db.collectionName.find(
    // 1. Query Criteria (Filter)
    { <field>: <value> }, 
    // 2. Projection (Fields to include/exclude)
    { <field>: 1 } 
)

Practical Example

Assume we have a collection called products with documents like this: 

{ name: "Laptop", price: 999, stock: 15, tags: ["electronics", "tech"] }
{ name: "Mouse", price: 25, stock: 50, tags: ["electronics"] }
{ name: "Coffee Maker", price: 120, stock: 5, tags: ["home", "kitchen"] }
Query Goal Shell Syntax Explanation
Read All db.products.find({}) Retrieves all documents in the products collection. An empty filter {} matches everything.
Simple Filter db.products.find({ name: "Laptop" }) Finds documents where the name field is exactly "Laptop".
Projection db.products.find({ name: "Laptop" }, { price: 1, _id: 0 }) Finds the Laptop, but only returns the price field. _id: 0 explicitly hides the default _id field.

Advanced Filtering with Query Operators

Query operators always start with a **dollar sign ($)** and are used inside the query criteria document.

Operator Definition Query Goal Shell Syntax
$gt Greater Than Find products with price **over 100**. db.products.find({ price: { $gt: 100 } })
$lt Less Than Find products with stock **less than 10**. db.products.find({ stock: { $lt: 10 } })
$gte Greater Than or Equal To Find products with price **120 or more**. db.products.find({ price: { $gte: 120 } })
$lte Less Than or Equal To Find products with price **up to 50**. db.products.find({ price: { $lte: 50 } })
$in In an array Find items with name "Mouse" **or** "Laptop". db.products.find({ name: { $in: ["Mouse", "Laptop"] } })
$and AND logic Find items where price is **> 20** AND stock is **< 20**. db.products.find({ price: { $gt: 20 }, stock: { $lt: 20 } })
$or OR logic Find items that are > 900 OR have stock < 10. db.products.find({ $or: [{ price: { $gt: 900 } }, { stock: { $lt: 10 } }] })

2. Reading Documents via Node.js (Driver) 🌐

When using Node.js, you interact with the database using the official mongodb NPM package (driver). The equivalent method for db.collection.find() is collection.find(), which returns a Cursor.

Prerequisites

const { MongoClient } = require("mongodb");
const uri = "mongodb://localhost:27017";
const client = new MongoClient(uri);

async function run() {
    await client.connect();
    const database = client.db("myStore"); // Select database
    const products = database.collection("products"); // Select collection
    
    // --- Querying Logic Goes Here ---
}
run().catch(console.error);

The find() and Cursor Methods

The find() method returns a **Cursor**, which is an object that points to the result set. You use specific methods on the cursor to get the data:

Method Use Case Description
find({ ... }).toArray() Most common for small to medium results. Loads all documents into memory as a JavaScript array.
find({ ... }).limit(N) To fetch only the top N results. Limits the number of documents returned.
findOne({ ... }) To retrieve a single document. Returns the first document that matches the criteria, or null. Does not require await ... .toArray().

Practical Node.js Examples

Example 1: Simple Filter and toArray()

Find all products with a price greater than 100, returning them as a single array. 

// Filter: price > 100
const query = { price: { $gt: 100 } }; 

const productsList = await products.find(query).toArray();
console.log("Expensive Products:", productsList);

Example 2: Advanced Filtering with $and, $lte, and Projection

Find a specific document that matches two conditions: **price is less than or equal to 100** AND **stock is greater than or equal to 20**. Only return the **name** and **stock** fields. 

// 1. Query Criteria (Filter)
const advancedFilter = {
    // $and is implicit when using multiple field: value pairs, 
    // but useful for multiple conditions on the same field or $or logic
    $and: [
        { price: { $lte: 100 } }, // Less than or equal to 100
        { stock: { $gte: 20 } } // Greater than or equal to 20
    ]
};

// 2. Projection: Include 1 (or true) for fields you want, 0 (or false) to exclude.
const projection = { name: 1, stock: 1, _id: 0 }; 

const filteredProducts = await products
    .find(advancedFilter)
    .project(projection) // Node.js driver uses .project() for the projection argument
    .toArray();

console.log("Filtered Results (Name and Stock only):", filteredProducts);

Example 3: Using findOne() with $in

Find a single product that is either a "Mouse" or a "Keyboard."

const item = await products.findOne({ 
    name: { $in: ["Mouse", "Keyboard"] } 
});

if (item) {
    console.log("Found a single accessory:", item.name, "at $", item.price);
} else {
    console.log("No matching item found.");
}
