MongoDB Update Operations in Node.js

A MongoDB update operation in Node.js modifies existing documents in a collection. You'll primarily use the updateOne(), updateMany(), and findOneAndUpdate() methods from the official MongoDB Node.js driver or a tool like Mongoose.

All update operations use update operators (like $set, $inc, $unset) to specify the changes.

1. Prerequisites (Setup)

To run the examples, ensure you have the MongoDB Node.js driver installed and a connection established.

JavaScript

// index.js (Setup)
const { MongoClient } = require('mongodb');

// Replace with your MongoDB connection string
const uri = "mongodb://localhost:27017"; 
const client = new MongoClient(uri);

// Sample data to ensure a collection exists for testing
async function setupTestData(collection) {
    await collection.deleteMany({});
    await collection.insertMany([
        { name: "Laptop X", quantity: 5, price: 1200, tags: ["electronics", "best-seller"] },
        { name: "Laptop Y", quantity: 15, price: 900, tags: ["electronics"] },
        { name: "Mouse A", quantity: 30, price: 25, tags: ["peripherals"] }
    ]);
    console.log("Test data inserted.");
}

async function runUpdateOperation(operation) {
    try {
        await client.connect();
        const database = client.db("inventoryDB"); // Your database name
        const collection = database.collection("products"); // Your collection name
        await setupTestData(collection);

        console.log(`\n--- Running ${operation.name} ---`);
        await operation.func(collection);
        console.log("--- Collection after update ---");
        const results = await collection.find({}).toArray();
        console.log(results);

    } finally {
        await client.close();
    }
}

2. Update a Single Document: updateOne()

Definition

The updateOne() method updates a **single** document that matches the specified filter. If multiple documents match, only the first one found is updated.

Syntax

JavaScript

collection.updateOne(filter, update, options)
Parameter Type Description
filter Object A query document that selects the document to update.
update Object A document specifying the modifications to apply using update operators (e.g., $set, $inc).
options Object Optional. Can include upsert: true (creates a new document if no match is found).

Practical Example (Using $set)

This example updates the price and adds a status field for the document named "Laptop X".

JavaScript

const updateOneExample = {
    name: "updateOne",
    func: async (collection) => {
        const filter = { name: "Laptop X" };
        const updateDoc = {
            $set: {
                price: 1250, // Change price
                status: "Updated" // Add new field
            }
        };
        const result = await collection.updateOne(filter, updateDoc);
        console.log(`Matched ${result.matchedCount} document(s) and modified ${result.modifiedCount} document(s).`);
    }
};

// To run: runUpdateOperation(updateOneExample).catch(console.dir);

3. Update Multiple Documents: updateMany()

Definition

The updateMany() method updates **all** documents that match the specified filter.

Syntax

JavaScript

collection.updateMany(filter, update, options)
Parameter Type Description
filter Object A query document that selects the documents to update.
update Object A document specifying the modifications to apply using update operators (e.g., $set, $inc).
options Object Optional. Can include upsert: true.

Practical Example (Using $inc)

This example increases the quantity by 10 for all products that have a price less than or equal to $1000.

JavaScript

const updateManyExample = {
    name: "updateMany",
    func: async (collection) => {
        const filter = { price: { $lte: 1000 } }; // Price <= 1000
        const updateDoc = {
            $inc: {
                quantity: 10 // Increment quantity by 10
            }
        };
        const result = await collection.updateMany(filter, updateDoc);
        console.log(`Matched ${result.matchedCount} document(s) and modified ${result.modifiedCount} document(s).`);
    }
};

// To run: runUpdateOperation(updateManyExample).catch(console.dir);

4. Find One and Update: findOneAndUpdate()

Definition

The findOneAndUpdate() method is an **atomic operation** that performs the following three actions in a single step:

  1. Finds a single document matching the filter.
  2. Applies the update.
  3. Returns the document (either the original or the updated one, depending on options).

This is useful when you need to use the document data immediately after the update (e.g., showing a user's updated profile).

Syntax

JavaScript

collection.findOneAndUpdate(filter, update, options)
Parameter Type Description
filter Object A query document that selects the document to update.
update Object A document specifying the modifications to apply using update operators.
options Object Optional. Key options include:
  • returnDocument: 'after' to return the updated document.
  • returnDocument: 'before' (default) to return the original document.
  • upsert: true to insert a new document if no match is found.

Practical Example (Return Updated Document)

This example finds "Mouse A", changes its price, and immediately returns the updated document.

JavaScript

const findOneAndUpdateExample = {
    name: "findOneAndUpdate",
    func: async (collection) => {
        const filter = { name: "Mouse A" };
        const updateDoc = {
            $set: { price: 30 }
        };
        const options = {
            returnDocument: 'after' // Return the document *after* the update
        };
        
        const result = await collection.findOneAndUpdate(filter, updateDoc, options);
        console.log("Updated document returned:", result.value); // result.value is the updated document
    }
};

// To run: runUpdateOperation(findOneAndUpdateExample).catch(console.dir);

5. Replacing a Document: replaceOne()

Definition

The replaceOne() method replaces an **entire existing document** that matches the filter with a new replacement document. The replacement document must **not contain any update operators** (like $set), and it will completely overwrite all existing fields (except the _id).

Syntax

JavaScript

collection.replaceOne(filter, replacement, options)
Parameter Type Description
filter Object A query document that selects the document to replace.
replacement Object The new document that will completely replace the matched document.
options Object Optional. Can include upsert: true.

Practical Example

This example finds "Laptop X" and replaces its structure entirely.

JavaScript

const replaceOneExample = {
    name: "replaceOne",
    func: async (collection) => {
        const filter = { name: "Laptop X" };
        const replacementDoc = {
            name: "Laptop X - V2",
            quantity_v2: 10, // Old fields (quantity, price, tags) are gone
            retired: true
        };
        const result = await collection.replaceOne(filter, replacementDoc);
        console.log(`Matched ${result.matchedCount} document(s) and modified ${result.modifiedCount} document(s).`);
    }
};

// To run: runUpdateOperation(replaceOneExample).catch(console.dir);

Key Concept: Update Operators

In MongoDB, to modify fields within a document without replacing the entire document, you must use update operators.

Operator Description Example
$set Sets the value of a field. If the field doesn't exist, it's added. {$set: {price: 99.99}}
$inc Increments the value of a field by the specified amount. {$inc: {quantity: 5}}
$unset Removes the specified field from a document. {$unset: {tags: ""}}
$push Adds an item to an array field. {$push: {tags: "new"}}
$addToSet Adds a value to an array unless the value is already present. {$addToSet: {tags: "unique"}}

Note: Always wrap your modifications inside an update operator (e.g., {$set: ...}) when using updateOne(), updateMany(), or findOneAndUpdate(). The replaceOne() method is the only one that uses a plain document.
