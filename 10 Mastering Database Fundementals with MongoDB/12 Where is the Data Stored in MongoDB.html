MongoDB Storage Overview

MongoDB stores its data in **documents** (in **BSON** format, a binary form of JSON) which are organized into **collections**. Physically, these are stored in **data files** on the filesystem of the server where the `mongod` process is running. (Query successful)

Physical Storage Location

The physical location on the disk where MongoDB stores its data files is determined by the **dbPath** setting.

Default Location:

  • **Linux/macOS:** /data/db
  • **Windows:** \data\db on the drive from which the mongod process is started.

Custom Location: You can specify a different storage directory by:

  • Using the **--dbpath** option when starting the mongod server (e.g., mongod --dbpath /srv/mongodb).
  • Setting the **storage.dbPath** configuration in the MongoDB configuration file (e.g., /etc/mongod.conf on Linux).

The directory contains various files, including:

  • **Data Files:** These hold the collections and indexes (often with a .wt extension for the default WiredTiger storage engine).
  • **Journal Files:** These ensure data durability and recoverability in case of a crash.

Internal Storage Structure

Within the data files, MongoDB stores its data using a specific structure:

  • **Document:** This is the **basic unit of data**, similar to a row in a relational database, but with a **flexible schema**.
  • **BSON (Binary JSON):** Documents are stored using BSON, a **binary-encoded serialization format** that is lighter, faster to traverse, and includes more data types than JSON.
  • **Collection:** A **group of documents**, similar to a table in a relational database.
  • **WiredTiger Storage Engine:** Since MongoDB version 3.2, WiredTiger is the **default storage engine**. It manages data on disk and in memory, supporting features like **compression** and an **internal cache** to reduce disk I/O.
  • **Memory/Cache:** The storage engine maintains an **in-memory cache** for frequently accessed data. MongoDB relies on the operating system to manage much of the overall memory-mapped file usage, but WiredTiger manages its own internal cache to speed up operations.
