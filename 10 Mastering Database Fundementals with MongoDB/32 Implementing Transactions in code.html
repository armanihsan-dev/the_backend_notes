This is a **comprehensive guide** to implementing **multi-document transactions** in Node.js using the **native MongoDB driver**, without Mongoose.

Multi-document transactions in MongoDB ensure **ACID properties (Atomicity, Consistency, Isolation, Durability)** across multiple operations, even across different collections.

First Step: Setup Replica Setup

Let’s go step-by-step so you can enable and initialize a replica set on your local MongoDB server.

🧩 Step 1: Locate your mongod.cfg file

This config file is usually at:

Windows:

C:\Program Files\MongoDB\Server\<version>\bin\mongod.cfg

Linux/macOS (default installation):

/etc/mongod.conf

⚙️ Step 2: Edit the config file to enable replica set

Open the file in a text editor with admin rights and add this section (or modify if already present):

replication:
  replSetName: "rs0"

👉 "rs0" is a common default replica set name — you can use any name, but keep it consistent later.

🚀 Step 3: Restart MongoDB service

After saving the config file, restart the MongoDB server so the new replica set config takes effect.

Windows:
Open Command Prompt (Admin) and run:

net stop MongoDB
net start MongoDB

Linux/macOS:

sudo systemctl restart mongod

🧠 Step 4: Initialize the replica set from mongosh

Now open your Mongo shell (mongosh) and connect:

mongosh

Then run the initialization command:

rs.initiate({
  _id: "rs0",
  members: [
    { _id: 0, host: "127.0.0.1:27017" }
  ]
})

If you see:

{ ok: 1 }

✅ Congrats! Your replica set is active.

🧩 Step 5: Verify the replica set status

Run:

rs.status()

You should see something like:

{
  set: 'rs0',
  members: [
    {
      _id: 0,
      name: '127.0.0.1:27017',
      stateStr: 'PRIMARY'
    }
  ]
}

🧰 Step 6: Update your connection string

Now that your server is a replica set, connect to it using:

const client = new MongoClient('mongodb://127.0.0.1:27017/?replicaSet=rs0');

✅ This tells MongoDB to use transaction-capable connections.

⚡ Optional: If mongod fails to start

If it fails after adding the replica set line, check:

  • YAML indentation is 2 spaces, not tabs.
  • The replication: section must be under the root of the config file (not inside net: or storage:).

Implementing Transactions in Node.js

This is a comprehensive guide to implementing **multi-document transactions** in Node.js using the **native MongoDB driver**, without Mongoose.

Multi-document transactions in MongoDB ensure **ACID properties (Atomicity, Consistency, Isolation, Durability)** across multiple operations, even across different collections.

1. Prerequisites and Setup

Before writing any Node.js code, you must ensure your MongoDB instance is running as a **Replica Set**. Transactions are **not supported** on a standalone MongoDB server.

1.1 MongoDB Replica Set Requirement

  • A **Replica Set** is a group of mongod processes that maintain the same data set. It provides redundancy and high availability.
  • **Requirement:** Your MongoDB deployment **must** be a replica set (even a single-node replica set for local development is sufficient).
  • **MongoDB Version:** Must be MongoDB **4.0** or higher.

1.2 Node.js Setup

Initialize Project:

npm init -y

Install MongoDB Driver:

npm install mongodb

Basic File Structure:

Create a file, e.g., transaction.js.

2. MongoDB Driver and Connection

Use the MongoClient from the mongodb package to establish a connection. The connection string must include the replicaSet name.

2.1 Definitions and Syntax

Element Definition Syntax
MongoClient The client interface for connecting to MongoDB. const { MongoClient } = require('mongodb');
Connection URI Specifies the database location and Replica Set name. mongodb://localhost:27017/?replicaSet=rs0
client.connect() Establishes the connection to the database. await client.connect();

2.2 Connection Example

In transaction.js:

const { MongoClient } = require('mongodb');
// ⚠️ Replace 'rs0' with your actual replica set name and update the host/port if needed.
const uri = "mongodb://localhost:27017/?replicaSet=rs0";
const client = new MongoClient(uri);
const DB_NAME = "transactionDemoDB";

async function connectClient() {
    try {
        await client.connect();
        console.log("Connected successfully to server with replicaSet.");
        return client;
    } catch (error) {
        console.error("Connection failed:", error);
        throw error;
    }
}

3. Implementing the Transaction (Core API)

The recommended approach for transactions is to use a **Client Session**, which allows you to group related operations. The "Core API" is the most explicit way to manage the transaction lifecycle.

3.1 Key Transaction Concepts and Methods

Method Definition Syntax
client.startSession() Creates a new **Client Session** required for transactions. const session = client.startSession();
session.startTransaction() Initiates the transaction block. session.startTransaction();
{ session } Option passed to all operations (CRUD) to include them in the transaction. collection.insertOne(doc, { session });
session.commitTransaction() Makes all operations within the transaction **permanent**. await session.commitTransaction();
session.abortTransaction() **Reverts** all operations if an error occurs. await session.abortTransaction();
session.endSession() Closes the session, releasing resources. **Always call this.** session.endSession();

3.2 Practical Example: Fund Transfer

This example simulates a bank transfer: **debiting** an amount from one account and **crediting** it to another. Both operations must succeed or fail together.

// --- Continuation of transaction.js ---

async function runTransaction() {
    let session;
    try {
        const client = await connectClient();
        session = client.startSession(); // 1. Start a Session
        session.startTransaction({
            // Optional: specify transaction options
            readConcern: { level: 'majority' },
            writeConcern: { w: 'majority' }
        }); // 2. Start the Transaction

        const db = client.db(DB_NAME);
        const accountsCollection = db.collection("accounts");

        // --- Transaction Operations ---
        const amount = 100;
        const senderId = "user123";
        const receiverId = "user456";

        // 3a. Debit: Decrease balance in the sender's account
        const debitResult = await accountsCollection.updateOne(
            { accountId: senderId, balance: { $gte: amount } }, // Check for sufficient balance
            { $inc: { balance: -amount } },
            { session } // 3. Pass the session to the operation
        );

        if (debitResult.matchedCount === 0) {
            // Insufficient funds or sender not found
            throw new Error(`Transaction aborted: Sender ${senderId} not found or insufficient funds.`);
        }

        // 3b. Credit: Increase balance in the receiver's account
        const creditResult = await accountsCollection.updateOne(
            { accountId: receiverId },
            { $inc: { balance: amount } },
            { session } // 3. Pass the session to the operation
        );

        if (creditResult.matchedCount === 0) {
             // Receiver not found - this will trigger the abort!
            throw new Error(`Transaction aborted: Receiver ${receiverId} not found.`);
        }

        // 4. Commit the Transaction
        await session.commitTransaction();
        console.log("✅ Transaction successfully committed: Funds transferred.");

    } catch (error) {
        // 5. Abort the Transaction if any operation failed
        if (session && session.inTransaction()) {
            await session.abortTransaction();
            console.log("❌ Transaction aborted. Database state rolled back.");
        }
        console.error("Transaction Error:", error.message);
    } finally {
        // 6. End the Session and Close the Client
        if (session) {
            session.endSession();
        }
        if (client) {
            await client.close();
        }
    }
}

// Initial setup to run the example
async function setupAndRun() {
    const client = new MongoClient(uri);
    try {
        await client.connect();
        const db = client.db(DB_NAME);
        const accountsCollection = db.collection("accounts");

        // Cleanup and initial data
        await accountsCollection.deleteMany({});
        await accountsCollection.insertMany([
            { accountId: "user123", balance: 500 }, // Sender
            { accountId: "user456", balance: 200 } // Receiver
        ]);
        console.log("Initial data loaded.");

    } finally {
        await client.close();

        // Now run the transaction
        console.log("\n--- Running Transaction ---\n");
        await runTransaction();
    }
}

setupAndRun().catch(console.error);
