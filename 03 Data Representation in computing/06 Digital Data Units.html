Digital Data Units, SI, and IEC: Complete Notes

Let's break down digital data units, SI, and IEC, and how computers store data.

Digital Data Units

Digital data units are the standardized measurements used to quantify digital information. They are built upon the fundamental concept of the bit and the byte.

  • Bit (b): The smallest unit of data, representing a single binary digit (either 0 or 1). This corresponds to the ON/OFF state of a transistor.
  • Byte (B): A group of 8 bits. A byte is typically the smallest addressable unit of data in a computer and can represent a single character (like a letter, number, or symbol).

Larger units are multiples of bytes:

  • Kilobyte (KB): Historically and commonly understood as 1,024 bytes.
  • Megabyte (MB): Historically and commonly understood as 1,024 kilobytes.
  • Gigabyte (GB): Historically and commonly understood as 1,024 megabytes.
  • Terabyte (TB): Historically and commonly understood as 1,024 gigabytes.
  • Petabyte (PB), Exabyte (EB), Zettabyte (ZB), Yottabyte (YB): Even larger units, each approximately 1,024 of the previous unit.

What is SI?

SI stands for Système International d'Unités, which is the International System of Units. It's the modern form of the metric system and is the world's most widely used system of measurement for various physical quantities like length (meter), mass (kilogram), time (second), etc.

In the context of data, the SI system uses prefixes (kilo, mega, giga, etc.) to denote powers of 1000 (10^3).

  • 1 kilobyte (KB) = 103 bytes = 1,000 bytes
  • 1 megabyte (MB) = 106 bytes = 1,000,000 bytes
  • 1 gigabyte (GB) = 109 bytes = 1,000,000,000 bytes

What is IEC?

IEC stands for the International Electrotechnical Commission. It's a global organization that develops and publishes international standards for electrical, electronic, and related technologies.

The IEC recognized the ambiguity caused by using SI prefixes (which are base-10) for computer data (which is base-2). To address this, in 1998, the IEC introduced a new set of binary prefixes:

  • Kibibyte (KiB): 210 bytes = 1,024 bytes
  • Mebibyte (MiB): 220 bytes = 1,048,576 bytes
  • Gibibyte (GiB): 230 bytes = 1,073,741,824 bytes
  • Tebibyte (TiB): 240 bytes = 1,099,511,627,776 bytes

These prefixes are formed by taking the first two letters of the corresponding SI prefix and adding "bi" (for binary).

Which system does the computer use for storing data?

Computers fundamentally store and process data using the binary number system (0s and 1s). This means that when computers group bits together, they naturally do so in powers of 2. For example, 8 bits make a byte, and the next natural grouping for computers is 210 bytes (1,024 bytes), not 103 bytes (1,000 bytes).

However, there's a distinction in how these units are advertised and interpreted:

  • Computer Hardware Manufacturers (e.g., hard drives, SSDs): Often use the SI (decimal) system when marketing their storage capacities. So, a 1 TB hard drive is typically 1,000,000,000,000 bytes (1012 bytes). This can lead to users feeling like they have slightly less space than advertised when their operating system reports it.
  • Operating Systems and Software: Historically and often still, operating systems (like Windows) and software use the binary (base-2) interpretation for file sizes and memory. So, when your computer reports a file size of 1 KB, it usually means 1,024 bytes.
  • The IEC system was created to bring clarity and specifically address this discrepancy. While the IEC units (KiB, MiB, GiB) are the technically accurate way to express powers of two, the traditional SI prefixes (KB, MB, GB) are still widely used by consumers and in general marketing, even when referring to binary quantities.

In summary, computers operate on binary (base-2), so the IEC system (kibibyte, mebibyte, etc.) is the technically correct way to describe memory and data storage in terms of powers of 2. However, the SI system (kilobyte, megabyte, etc., meaning powers of 10) is often used for marketing storage capacity, leading to the common confusion.
