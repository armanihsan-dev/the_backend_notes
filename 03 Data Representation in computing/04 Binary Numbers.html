Understanding Binary Numbers and Computer Fundamentals

How 0b111 Returns 7 in JavaScript

In JavaScript, the prefix 0b indicates a binary literal. This means the number following it is in base 2.

What does 0b111 mean?

Binary 111 is converted to decimal as follows:

1 × 2² + 1 × 2¹ + 1 × 2&sup0;
= 4 + 2 + 1
= 7 (in decimal)

You can verify this in JavaScript:

console.log(0b111); // Output: 7

So, 0b111 is simply the binary representation of the decimal number 7.

Understanding Powers of Zero (e.g., 2&sup0;)

Does 2&sup0; refer to 0?

No. 2&sup0; means "2 raised to the power of 0".

2 ** 0 === 1

Rule: Any non-zero number raised to the power of 0 is always 1.

Expression Value
2&sup0; 1
5&sup0; 1
10&sup0; 1
100&sup0; 1

This rule is crucial for understanding binary, octal, and hexadecimal number systems, as well as exponents in general.

So, for 0b111:

  • 1 × 2² = 4
  • 1 × 2¹ = 2
  • 1 × 2&sup0; = 1 ← This is from 2&sup0;, not 0!
  • Total = 4 + 2 + 1 = 7

Binary Number System: A Comprehensive Guide

1. What Is a Binary Number?

Binary is a base-2 number system that uses only two digits: 0 and 1.

Each digit (called a bit) represents a power of 2, from right to left.

Example: Binary 1011

Powers of 2 → 2³  2²  2¹  2&sup0;
                   ↓
                   1    0   1   1
  • 1 × 2³ = 8
  • 0 × 2² = 0
  • 1 × 2¹ = 2
  • 1 × 2&sup0; = 1
  • Total = 11

So, 1011 in binary = 11 in decimal.

2. How to Write Binary in JavaScript

Use the 0b prefix:

console.log(0b1011); // Output: 11

Other examples:

0b1       // 1
0b10      // 2
0b100     // 4
0b1000    // 8

3. Convert Binary ↔ Decimal

a) Binary to Decimal (Manual)

Binary: 1101

1 × 2³ = 8
1 × 2² = 4
0 × 2¹ = 0
1 × 2&sup0; = 1
------------
Total = 13

a) Binary to Decimal (JavaScript)

const decimal = parseInt('1101', 2);
console.log(decimal); // 13

b) Decimal to Binary (Manual)

Decimal: 13

Keep dividing by 2 and writing the remainders from bottom to top:

13 ÷ 2 = 6  remainder 1
6 ÷ 2  = 3  remainder 0
3 ÷ 2  = 1  remainder 1
1 ÷ 2  = 0  remainder 1
→ Binary = 1101

b) Decimal to Binary (JavaScript)

const binary = (13).toString(2);
console.log(binary); // '1101'

4. Why Do Computers Use Binary?

Computers are made of electronic circuits that understand two states:

  • ON (has voltage) → 1
  • OFF (no voltage) → 0

This directly matches the hardware: every transistor is either ON or OFF, making it easy to store, process, and transmit data.

5. Where Is Binary Used in Computers?

Binary is fundamental to almost every aspect of computer operation:

Use Case Binary Example/Explanation
CPU operations (machine code) Instructions like 10101010 are executed by the CPU.
Memory storage (RAM, ROM) Data is stored as sequences of 0s and 1s.
Disk storage (HDD, SSD) Binary bits are written magnetically or electronically.
Networking (packets, IPs) IP addresses (e.g., 192.168.1.1) and data packets are in binary format.
Images, audio, video All multimedia content is encoded and stored in binary.
Programming logic Bitwise operators (e.g., &, |, ^) work directly on binary representations.
File formats (PDF, DOCX, EXE) All file types are fundamentally binary-encoded.
Boolean logic (true/false) Internally, true = 1, false = 0.

What Is a Transistor?

A transistor is a tiny electronic switch that can turn ON or OFF, controlling the flow of electricity.

  • ON = current flows → represents 1
  • OFF = current blocked → represents 0

Transistors are the fundamental building blocks of all modern computers.

Why Are Transistors So Important?

They form the logic for everything a computer does, including:

  • Calculations (math)
  • Storing data (memory)
  • Making decisions (if/else statements)
  • Processing images, videos, and applications

Your computer's CPU has billions of transistors packed into a tiny chip.

Types of Transistors

The most common type in modern electronics is the MOSFET (Metal-Oxide-Semiconductor Field-Effect Transistor), found in CPUs, RAM, and SSDs.

Real-Life Analogy

Imagine a valve controlling water in a pipe:

  • Valve closed → no water = 0
  • Valve open → water flows = 1

This is analogous to how transistors control electricity.

How It All Comes Together

Transistors are used to build:

  1. Logic gates (AND, OR, NOT)
  2. Logic gates make circuits
  3. Circuits make processors
  4. Processors + memory = computers

All applications, games, and AI work because of these tiny ON/OFF switches.

How 0 and 1 are Represented by a Transistor

A transistor itself doesn't "know" 0 or 1. It simply controls the flow of electricity (voltage).

The presence or absence of voltage is then interpreted as binary.

Transistor State Voltage Output Binary Interpretation
OFF 0 volts (or very low) 0
ON ~5 volts (or 3.3V, etc.) 1

Computer's Logic

The entire computer system (CPU, memory, motherboard) agrees on this standard:

"If voltage is HIGH → that's a 1. If voltage is LOW (or 0 volts) → that's a 0."

The Role of the Transistor

A field-effect transistor (FET) like a MOSFET has a Gate, Source, and Drain:

  • When voltage is applied to the Gate: The transistor switches ON → current flows → output = HIGH voltage → interpreted as 1.
  • When Gate voltage is 0: The transistor is OFF → no current flows → output = 0 volts → interpreted as 0.

The transistor itself is a physical component that reacts to voltage and physics. It doesn't "know" anything; it just conducts or doesn't conduct based on the input voltage.

Who Assigns 0 and 1 Values to On/Off States?

The assignment of 0 and 1 to high and low voltages was a convention (rule) set by early digital logic design engineers.

1. It's a Convention Set by Engineers

When computers were invented, engineers decided:

  • High voltage = 1
  • Low voltage = 0

This became the standard for all digital electronics, known as Positive Logic.

2. Why Was This Rule Chosen?

Because it is:

  • Easy to implement with transistors.
  • Reliable to detect the difference between high and low voltage.
  • Consistent across all circuits.

3. Could It Have Been the Opposite?

Yes. There is a concept called Negative Logic, where Low voltage = 1 and High voltage = 0. However, Positive Logic is almost universally adopted in modern digital systems.

4. Who Enforces This?

  • Hardware designers (e.g., Intel, AMD) follow this convention.
  • Chip manufacturers build circuits based on this standard.
  • Programming languages and software are built on top of this fundamental assumption.

Everything from the lowest transistor level to your browser obeys this convention.

How 0s and 1s Travel to the CPU

The question of how 0s and 1s "reach" the CPU is about how data physically travels as electrical signals.

Step 1: Everything Becomes Binary Data

Any input (keyboard press, mouse click, file, image, program) is converted into its binary form — a stream of 0s and 1s (low/high voltages).

Step 2: Binary Travels Through Wires and Buses

Once in binary form, data moves as electrical signals through specialized pathways:

  • Data bus: Carries the actual data (0s and 1s).
  • Address bus: Specifies the memory location where data should go or come from.
  • Control bus: Manages operations like reading, writing, or executing data.

These buses are made of metal traces on the motherboard and inside chips. A voltage ON (e.g., 3.3V or 5V) represents 1, and voltage OFF (0V) represents 0.

Step 3: CPU Receives and Processes the 0s and 1s

The CPU reads the data from the data bus. It interprets these binary signals based on:

  • Instructions (machine code)
  • Input/output control
  • Memory read/write operations
  • Logic operations (performed by the Arithmetic Logic Unit - ALU)

Inside the CPU, the Instruction Decoder directs these 0s and 1s to various parts of the chip (ALU, registers, cache) for processing. The CPU is constantly transforming these voltages (0s and 1s) at billions of times per second.

How the CPU Physically Understands 0 and 1

This goes beyond "who assigned" and into the electrical and physical reality inside the chip.

1. Everything Is Voltage — Not Actual Numbers

Inside the CPU, there are no "numbers" like 0 or 1 written. Instead, there are tiny electrical voltages in metal circuits.

Voltage Level Interpreted As
~0 volts 0
~3.3 or 5 volts 1

When the CPU "sees a 1," it's detecting: "This wire has electricity (voltage)" → that means 1.

2. How Does the CPU Detect That Voltage?

The CPU contains millions of tiny voltage-sensitive circuits made of transistors, resistors, and capacitors. These circuits:

  • Measure the voltage at specific points (wires or "lines").
  • If the voltage is above a certain threshold (e.g., 2V), it's treated as a 1.
  • If it's below the threshold (e.g., < 0.8V), it's treated as a 0.

This voltage detection occurs via CMOS logic gates, which are built using transistors.

Example: A NOT Gate (Inverter)

INPUT: 3.3V  → transistor switches ON → OUTPUT: 0V  → CPU sees "0"
INPUT: 0V    → transistor stays OFF   → OUTPUT: 3.3V → CPU sees "1"

The CPU doesn't "understand" in a human sense; it's just physics and circuits reacting to voltage.

3. No “Knowledge” — Just Electrical Reaction

A CPU doesn't think, "Oh, this is a 1." It operates based on electrical reactions:

  • Electricity ON: Signal continues → circuit activates → specific output occurs.
  • Electricity OFF: No signal → circuit remains idle → a different output (or no output) occurs.

This is why digital electronics are so fast and predictable: they are merely reacting to voltage levels at electromagnetic speed.

The "understanding" of 0 and 1 is purely hardware reacting to electricity. It's not decoding numbers like a human; it's simply: "Is there voltage on this wire? Yes → 1. No → 0."
