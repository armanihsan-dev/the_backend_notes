Deep Dive into Character Sets

What is meant by a character set?

A character set (also known as a repertoire or coded character set) is a defined collection of characters (like letters, numbers, punctuation marks, symbols, and whitespace) that a computer can recognize and use.

It provides a standard for computers to communicate and exchange information by associating each character with a unique numeric value.

In simpler terms, it's like a dictionary where each "word" is a character, and each "definition" is a specific number assigned to that character.

A set of characters(a,b,_,*,3,|,/,~) in which we assign number to each character

Why do we need to assign numbers to characters?

Computers fundamentally operate on binary data, meaning they only understand 0s and 1s. They cannot directly understand human-readable characters like "A" or "hello."

To enable computers to process, store, and display text, each character must be represented by a unique numerical value. This numerical representation can then be converted into binary for computer manipulation.

Without assigning numbers, computer systems might interpret bit sequences differently, leading to garbled or incomprehensible text (often called "mojibake").

What are the types of character sets?

Historically, various character sets were developed, often specific to certain languages, leading to compatibility issues. Key types include:

  • ASCII (American Standard Code for Information Interchange): Early, fundamental character set, primarily for English.
  • Extended ASCII: 8-bit extensions of ASCII to represent more characters (symbols, accented letters), but not standardized ("code pages").
  • ISO/IEC 8859: A series of standardized character sets for various language groups (e.g., ISO 8859-1 for Western European languages).
  • EBCDIC (Extended Binary Coded Decimal Interchange Code): An alternative encoding mainly used on IBM mainframe systems.
  • Unicode: The most comprehensive and widely adopted character set, designed to include all characters from all written languages, scripts, symbols, and emojis.

What is the ASCII table?

The ASCII table is a character encoding standard that assigns a unique numerical value (from 0 to 127) to 128 characters.

These include:

  • 95 printable characters: Uppercase/lowercase English letters (A-Z, a-z), digits (0-9), and common punctuation/symbols (e.g., !, @, #).
  • 33 control characters: Non-printable characters for controlling devices or providing meta-information (e.g., carriage return, line feed, tab).

Each ASCII character is represented by a 7-bit binary number.

What is the need for the ASCII table?

The ASCII table was created to standardize text representation and exchange between computers and devices.

Before ASCII, incompatible character representations made sharing text documents and communication difficult.

ASCII provided a common language for computers to interpret and display text consistently, forming the foundation for modern digital communication.

Why does the ASCII table have a length of 128?

The ASCII table has a length of 128 characters because it uses 7 bits to represent each character. With 7 bits, $2^7$ unique combinations are possible, which equals 128.

At the time of its development, minimizing data transmission and storage was critical. 7 bits were sufficient for English text and basic control, allowing an eighth bit for purposes like a "parity bit" (error checking).

What is Unicode? What numbering system does it use?

Unicode is an international character encoding standard that aims to provide a unique numerical value (a code point) for every character in the world's languages and scripts. It overcomes limitations of older character sets.

Unicode doesn't specify a "numbering system" directly (though code points are often in hexadecimal with a "U+" prefix, e.g., U+0041 for "A"). Instead, it assigns a vast range of integer values (code points) to characters.

These code points are then implemented and stored using various character encoding schemes (like UTF-8, UTF-16, UTF-32), which translate numerical code points into byte sequences.

The Unicode standard's codespace can represent over 1.1 million characters (from U+0000 to U+10FFFF).

What is character encoding?

Character encoding is the process of converting a character's unique numerical representation (its code point) into a sequence of bytes for computer storage and transmission. It's the practical implementation of a character set.

Different encoding schemes exist for the same character set. For Unicode, common encodings include:

  • UTF-8: Variable-width (1-4 bytes/character). Backward-compatible with ASCII (1 byte for ASCII chars). Most common on the internet.
  • UTF-16: Variable-width (2 or 4 bytes/character). Often used internally by OS like Windows.
  • UTF-32: Fixed-width (4 bytes/character). Simpler, but less space-efficient than UTF-8/16 for most text.

The correct character encoding choice is crucial for displaying text correctly. Mismatched encoding (e.g., UTF-8 file read as Extended ASCII) results in "mojibake."
