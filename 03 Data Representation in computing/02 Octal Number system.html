The octal numbering system

The octal numbering system is a base-8 system, meaning it uses eight distinct symbols: 0, 1, 2, 3, 4, 5, 6, and 7. Each position in an octal number represents a power of 8.

Learning Octal for Node.js Developers 🤔

For most Node.js developers, deep knowledge of the octal numbering system isn't a high priority or a strict requirement. You'll encounter it far less frequently than decimal (base-10) or hexadecimal (base-16).

Here's why:

  • Common Use Cases: Octal is primarily used in computing for representing file permissions in Unix-like operating systems (e.g., chmod 755).
  • Abstraction: JavaScript and Node.js generally abstract away low-level number representations. You typically work with numbers in their decimal form.
  • Less Common in Web Development: In typical web development (front-end or back-end with Node.js), you're rarely manipulating raw binary or octal data directly. Hexadecimal is much more common for colors, hashes, and IDs.

How much to learn?

A basic understanding of what octal is and how it relates to file permissions is sufficient. You don't need to memorize conversion tables or become proficient in manual octal arithmetic.

Using Octal in JavaScript 💻

JavaScript does not have a direct literal for octal numbers in strict mode (which is almost always used in modern development). Previously, a leading zero (0) was used to denote an octal literal, but this practice is deprecated and will cause errors in strict mode.

However, you can represent octal numbers using a prefix 0o (zero followed by a lowercase 'o'). This is part of the ES6 (ECMAScript 2015) specification.

JavaScript

const octalNumber = 0o123; // Represents octal 123
console.log(octalNumber);  // Output: 83 (decimal equivalent)
Important Note: Even when you use 0o to define an octal literal, JavaScript internally stores and processes the number as its decimal equivalent. So, octalNumber above is just the decimal number 83.

Converting Octal to Decimal in JavaScript 🔄

JavaScript provides built-in methods for number base conversions.

To convert an octal string to a decimal number, use parseInt():

JavaScript

const octalString = "123";
const decimalNumber = parseInt(octalString, 8); // The '8' specifies the radix (base)
console.log(`Octal ${octalString} is Decimal ${decimalNumber}`); // Output: Octal 123 is Decimal 83

Converting Decimal to Octal in JavaScript 🔄

To convert a decimal number to an octal string, use the toString() method of a number object and pass 8 as the radix:

JavaScript

const decimalNumber = 83;
const octalString = decimalNumber.toString(8); // The '8' specifies the radix (base)
console.log(`Decimal ${decimalNumber} is Octal ${octalString}`); // Output: Decimal 8
